## Job Search Strategy

### Kahan Apply Karein?

| Platform | Best For | Tips |
|----------|----------|------|
| LinkedIn | Product companies, MNCs | Profile complete karo, daily activity |
| Naukri.com | Indian IT companies | Keywords match karo job description se |
| Internshala | Internships, fresher jobs | Good for first break |
| AngelList (Wellfound) | Startups | Direct founders se baat hoti hai |
| Instahyre | Mid-level positions | Profile-based matching |
| GitHub Jobs | Remote, international | Open source profile zaroori |
| Twitter/X | Networking, referrals | Tech community follow karo |
| Company Career Pages | Direct apply | Targeted applications |

### Application Strategy

```
GALAT Approach:
- 100 companies mein same resume bhejo
- "Apply" button dabaao aur bhool jao
- Sirf online apply karo

SAHI Approach:
- 10 companies ko target karo weekly
- Har company ke liye resume customize karo
- LinkedIn pe employees se connect karo
- Referral maango (politely!)
- Follow up karo 1 week baad
- Portfolio link ZAROOR daalo application mein
```

> **Socho Aise:** Job search ek marketing campaign hai — tum product ho, company customer hai. Marketing mein targeted approach kaam karta hai, spray-and-pray nahi. 10 quality applications > 100 random applications!

```

### Repository Best Practices

```
Har project repository mein ye hona chahiye:

README.md:
├── Project title + description (1-2 lines)
├── Screenshots / GIFs of working app
├── Tech stack list
├── Features list
├── Installation steps (copy-paste friendly)
├── API documentation (endpoints list)
├── Environment variables needed
├── Folder structure
├── Live demo link
└── License

Code Quality:
├── .gitignore proper hai
├── .env.example file hai (bina secrets ke)
├── Consistent code style
├── Meaningful commit messages
├── No console.log left in code
└── Comments where needed
```

> **Yaad Rakho:** Recruiter pehle README dekhta hai, phir code. Agar README impressive nahi hai toh code tak pohochega hi nahi. 5 minutes README pe invest karo — ye tumhara first impression hai!

## LinkedIn Profile Tips

### Profile Optimization Checklist

```
[x] Professional photo (clear face, decent background)
[x] Headline: "Backend Developer | Node.js | Express | MongoDB"
    (NOT "Aspiring Developer" ya "Looking for opportunities")
[x] About section — 3-4 paragraphs:
    - Kya karte ho (backend development)
    - Kya technologies jaante ho
    - Kya projects banaye hain
    - Kya dhundh rahe ho (open to work)
[x] Experience section — projects as experience daalo
[x] Skills section — top skills add karo, endorsements lo
[x] Featured section — project links, articles, certifications
[x] Activity — weekly posts, comments, shares
```

### Content Ideas for LinkedIn Posts

```
Week 1: "Just completed my 90-day Full Stack journey! Here's what I learned..."
Week 2: Share a technical tip — "5 Express.js middleware patterns every developer should know"
Week 3: Project showcase — "Built KisanMart with real-time features. Here's the architecture..."
Week 4: Learning journey — "From zero to deploying on AWS — my Docker learning experience"
```

> **Tip:** LinkedIn pe consistent posting karo — week mein 2-3 posts. Technical content share karo, projects dikhao, learnings batao. Ye organic visibility badhata hai aur recruiters notice karte hain!

## Open Source Contribution

### Kyu Zaroori Hai?

```
1. Real-world codebase experience — production code padho aur samjho
2. Collaboration skills — code review, Git workflow, communication
3. Resume booster — "Contributed to XYZ open source project"
4. Network — maintainers aur contributors se connections
5. Learning — senior developers ka code padho, best practices seekho
```

### Kaise Start Karein?

```
Step 1: "Good first issue" labeled issues dhundho
  - GitHub Explore → Trending repositories
  - https://goodfirstissue.dev
  - https://up-for-grabs.net

Step 2: Chhoti cheezein se start karo
  - Typo fix in documentation
  - Test cases add karo
  - README improve karo
  - Bug fix (chhota sa)

Step 3: Dhire dhire bade contributions karo
  - New feature implement karo
  - Performance improvement
  - Code refactoring

Node.js Ecosystem Projects to Contribute:
  - Express.js ecosystem packages
  - Mongoose plugins
  - Jest testing utilities
  - Popular npm packages
```

> **Socho Aise:** Open source aise hai jaise community kitchen mein kaam karna. Pehle bartan dhoo (small fixes), phir sabzi kaato (medium tasks), phir khud recipe banao (features). Har step se seekhte ho!

## Freelancing Basics

### Platforms

| Platform | Best For | Commission |
|----------|----------|-----------|
| Upwork | Long-term projects | 5-20% |
| Fiverr | Small, defined tasks | 20% |
| Toptal | Premium clients (tough screening) | 0% (hourly) |
| Freelancer | Various projects | 10% |
| Direct Clients | Networking, referrals | 0% |

### Freelancing Tips

```
1. Start small — first 3-4 projects kam rate pe lo (reviews ke liye)
2. Portfolio banao — live projects dikhao
3. Communication — client ko regular updates do
4. Contract — scope clearly define karo BEFORE starting
5. Payment — 50% advance, 50% on completion
6. Time management — deadline se pehle deliver karo
```

### Freelance Rate Guide (India)

```
Beginner (0-6 months):    Rs. 300-600/hour
Intermediate (6-18 months): Rs. 600-1500/hour
Advanced (18+ months):     Rs. 1500-3000+/hour

International clients:
Beginner:     $10-20/hour
Intermediate: $20-40/hour
Advanced:     $40-80+/hour
```

> **Warning:** Freelancing mein pehle 3-6 months tough hote hain — kam projects, kam rate. Patience rakho, quality deliver karo, reviews build karo. Baad mein rate automatically badh jayega!

### Tum Kya The Aur Kya Ban Gaye

```
Day 0:  "JavaScript kya hai?"
Day 30: "Main functions, arrays, async/await likh sakta hoon!"
Day 60: "Main REST APIs bana sakta hoon, database connect kar sakta hoon!"

### Yaad Rakho Ye Baatein

```
1. CONSISTENCY > Intensity
   - Roz 2 ghante coding > Weekend pe 12 ghante
   - Chhote steps daily > Bade jumps occasionally

2. BUILD > Read
   - 10 tutorials dekhne se developer nahi bante
   - 1 project banana > 10 tutorials dekhna

3. FAIL > Fear
   - Bugs aayenge, errors aayenge — ye learning hai
   - Senior developers bhi Google karte hain!

4. NETWORK > Solo
   - Community join karo (Discord, Twitter, meetups)
   - Doosron ko help karo — teaching = deepest learning

5. PATIENCE > Perfection
   - First job mushkil hogi — sabke saath hota hai
   - 6 months job search normal hai — himmat mat haaro
```
