## Resume Tips for Backend Developers

### Resume Structure

```
HEADER:
- Name, Email, Phone, LinkedIn, GitHub, Portfolio URL

SUMMARY (2 lines max):
"Backend developer with expertise in Node.js, Express.js, MongoDB.
Built production-grade APIs with authentication, real-time features, and Docker deployment."

SKILLS:
Backend:     Node.js, Express.js, REST API, WebSocket, Socket.io
Database:    MongoDB, Mongoose, Redis, PostgreSQL (learning)
Auth:        JWT, bcrypt, OAuth, RBAC
DevOps:      Docker, AWS EC2, Nginx, CI/CD, GitHub Actions
Frontend:    React.js, HTML/CSS, JavaScript
Tools:       Git, Postman, VS Code, Linux

PROJECTS (2-3 best ones):
- KisanMart — Full Stack E-Commerce
  "Built REST APIs, JWT auth, real-time notifications, Dockerized, deployed on AWS"
  Tech: Node.js, Express, MongoDB, React, Socket.io, Docker, AWS
  [Live Link] [GitHub Link]

EDUCATION:
- Your degree/course

CERTIFICATIONS (optional):
- Any relevant certificates
```

### Resume Do's and Don'ts

```
DO:
 ✅ Quantify achievements — "Built API handling 1000+ requests/min"
 ✅ Include live project links
 ✅ List specific technologies, not just "web development"
 ✅ Keep it 1 page (fresher) or 2 pages (experienced)
 ✅ ATS-friendly format (no fancy designs for online submission)

DON'T:
 ❌ "I am a hardworking and passionate developer" — generic mat likho
 ❌ List every technology you've heard of — sirf jo aata hai wo likho
 ❌ Typos aur grammatical errors — proofread karo!
 ❌ Include personal info (photo, age, marital status — India specific hoga toh theek)
 ❌ 5 page resume — recruiter ko 30 seconds milte hain
```

## Interview Preparation Roadmap

### Technical Interview Topics

```
Round 1: DSA (Data Structures & Algorithms)
├── Arrays, Strings, HashMap — most common
├── Linked Lists, Stacks, Queues
├── Trees, Graphs (basics)
├── Sorting, Searching algorithms
└── Practice: LeetCode Easy → Medium (150+ problems)

Round 2: Backend Knowledge
├── Node.js Event Loop — kaise kaam karta hai?
├── Express middleware chain — order matters
├── MongoDB vs PostgreSQL — kab kya use karein?
├── REST API design principles
├── Authentication flow — JWT kaise kaam karta hai?
├── Database indexing — kyu zaroori hai?
├── Caching strategies — Redis kab use karein?
└── Error handling best practices

Round 3: System Design (Mid-Level+)
├── URL Shortener — design karo
├── Chat Application — architecture batao
├── E-Commerce — how to handle 10K orders/min?
├── Rate Limiter — implement karo
├── Load Balancing — concepts
└── Database Sharding — kab zaroori?

Round 4: Behavioral
├── "Tell me about yourself" — 2 minute pitch ready rakho
├── "Describe a challenging project" — KisanMart ki story
├── "How do you handle deadlines?" — real examples do
└── "Why should we hire you?" — specific skills batao
```

> **Yaad Rakho:** DSA practice zaroori hai — but backend knowledge equally important hai. Most companies backend role ke liye system design + backend concepts pe zyada focus karti hain. Dono balance karo!

### 30-Day Interview Prep Plan

```
Week 1: DSA — Arrays, Strings, HashMap (5 problems/day)
Week 2: DSA — Linked Lists, Trees + Backend concepts revision
Week 3: System Design basics + Mock interviews
Week 4: Company-specific preparation + more mocks
```
