# 🌅 HOUR 1 — CONCEPT

## Navigation Kya Hai?

Multi-screen apps me ek screen se doosri pe jane ka mechanism. Flutter me **stack-based navigation** hai — purani screen niche, nayi upar.

> **Socho Aise:** Stack of plates jaisa. Naya plate (screen) upar rakhte ho — `push()`. Plate uthate ho — `pop()`. Sabse upar wala plate hi visible hota hai.

---

## Navigator.push — Naya Screen

```dart
Navigator.push(
  context,
  MaterialPageRoute(builder: (context) => const DetailScreen()),
);
```

### Full Example

```dart
class HomeScreen extends StatelessWidget {
  const HomeScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Home')),
      body: Center(
        child: ElevatedButton(
          onPressed: () {
            Navigator.push(
              context,
              MaterialPageRoute(builder: (_) => const DetailScreen()),
            );
          },
          child: const Text('Go to Detail'),
        ),
      ),
    );
  }
}

class DetailScreen extends StatelessWidget {
  const DetailScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Detail')),
      body: const Center(child: Text('Detail Page')),
    );
  }
}
```

> **Yaad Rakho:** AppBar pe **back button automatic** aata hai (jab push se aaye ho). Manually nahi banana padta.

## Receive Data Back (await pop)

```dart
// Source screen — async function
Future<void> _openDetail() async {
  final result = await Navigator.push<String>(
    context,
    MaterialPageRoute(builder: (_) => const RatingScreen()),
  );

  if (result != null) {
    print('Rating returned: $result');
    setState(() => _rating = result);
```

## Named Routes

Bade apps me named routes use karte hain — strings se identify, MaterialApp me register.

```dart
MaterialApp(
  initialRoute: '/',
  routes: {
    '/': (context) => const HomeScreen(),
    '/detail': (context) => const DetailScreen(),
    '/profile': (context) => const ProfileScreen(),
    '/settings': (context) => const SettingsScreen(),
  },
)

// Use
Navigator.pushNamed(context, '/detail');
Navigator.pushNamed(context, '/profile');
```

### onGenerateRoute (Dynamic Routes with Args)

```dart
MaterialApp(
  initialRoute: '/',
  routes: {'/': (_) => const HomeScreen()},
  onGenerateRoute: (settings) {
    if (settings.name == '/detail') {
      final args = settings.arguments as Map<String, dynamic>;
      return MaterialPageRoute(
        builder: (_) => DetailScreen(
          title: args['title'],
          id: args['id'],
        ),
      );
    }
    return null;
  },
)

// Use
Navigator.pushNamed(
  context,
  '/detail',
  arguments: {'title': 'Hello', 'id': 42},
);
```

## Push Variants

```dart
// pushReplacement — current screen replace karo
Navigator.pushReplacement(
  context,
  MaterialPageRoute(builder: (_) => const HomeScreen()),
);
// Login → Home (login wapas nahi aa sakte)

// pushAndRemoveUntil — sab purani screens hata do
Navigator.pushAndRemoveUntil(
  context,
  MaterialPageRoute(builder: (_) => const HomeScreen()),
  (route) => false,  // sab remove
);
// Logout flow ke liye perfect

// popUntil — multiple pops
Navigator.popUntil(context, (route) => route.isFirst);
// Go back to first screen
```

## Hero Animations

Same image/widget ko 2 screens me **smoothly animate** karne ke liye `Hero` use karte hain.

```dart
// Screen A
Hero(
  tag: 'profile-pic',
  child: CircleAvatar(
    radius: 30,
    backgroundImage: NetworkImage(url),
  ),
)

// Screen B (same tag!)
Hero(
  tag: 'profile-pic',
  child: CircleAvatar(
    radius: 100,
    backgroundImage: NetworkImage(url),
  ),
)
```

> **Magic:** Avatar small to large smoothly animate hoga jab navigate karoge.

> **Yaad Rakho:** Tag **unique** hona chahiye dono screens me. Same tag ka match hota hai animation ke liye.

### Step 2: List screen

```dart
// lib/screens/recipe_list_screen.dart
import 'package:flutter/material.dart';
import '../models/recipe.dart';
import 'recipe_detail_screen.dart';

class RecipeListScreen extends StatefulWidget {
  const RecipeListScreen({super.key});

  @override
  State<RecipeListScreen> createState() => _RecipeListScreenState();
}

class _RecipeListScreenState extends State<RecipeListScreen> {
  final Map<String, int> _ratings = {};

  Future<void> _openDetail(Recipe recipe) async {
    final rating = await Navigator.push<int>(
      context,
      MaterialPageRoute(builder: (_) => RecipeDetailScreen(recipe: recipe)),
    );

    if (rating != null) {
      setState(() {
        _ratings[recipe.id] = rating;
      });
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('${recipe.name} rated $rating/5 ⭐')),
      );
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('🍴 Recipes'), backgroundColor: Colors.deepOrange, foregroundColor: Colors.white),
      body: ListView.builder(
        itemCount: recipes.length,
        itemBuilder: (context, index) {
          final r = recipes[index];
          final rating = _ratings[r.id];
          return Card(
            margin: const EdgeInsets.symmetric(horizontal: 12, vertical: 6),
            child: ListTile(
              leading: Hero(
                tag: 'recipe-${r.id}',
                child: ClipRRect(
                  borderRadius: BorderRadius.circular(8),
                  child: Image.network(r.image, width: 60, height: 60, fit: BoxFit.cover),
                ),
              ),
              title: Text(r.name, style: const TextStyle(fontWeight: FontWeight.bold)),
              subtitle: Text('${r.prepTime} min • ${r.ingredients.length} ingredients'),
              trailing: rating != null
                  ? Row(mainAxisSize: MainAxisSize.min, children: [
                      const Icon(Icons.star, color: Colors.amber, size: 18),
                      Text('$rating/5'),
                    ])
                  : const Icon(Icons.arrow_forward_ios, size: 16),
              onTap: () => _openDetail(r),
            ),
          );
        },
      ),
    );
  }
}
```

## 📋 Quick Revision

| Action | Code |
|--------|------|
| Push | `Navigator.push(context, MaterialPageRoute(builder: (_) => Screen()))` |
| Pop | `Navigator.pop(context)` |
| Pop with value | `Navigator.pop(context, value)` |
| Receive value | `final v = await Navigator.push(...)` |
| Replace | `pushReplacement(...)` |
| Remove all | `pushAndRemoveUntil(..., (r) => false)` |
| Named | `Navigator.pushNamed(context, '/route')` |
| Named + args | `pushNamed(context, '/route', arguments: data)` |
| Hero | `Hero(tag: 'unique-tag', child: ...)` |

## ❌ Common Mistakes

```dart
// MISTAKE 1: Hero tag duplicate
Hero(tag: 'a')...
Hero(tag: 'a')...  // ❌ same screen me 2 hero with same tag
// FIX: unique tags

// MISTAKE 2: pop() called when nothing to pop
// MaterialApp ke home screen pe pop() — error

// MISTAKE 3: push without async/await for value
Navigator.push(...)  // value miss
// FIX: final v = await Navigator.push(...)

// MISTAKE 4: arguments cast galat

// FIX: as Map<String, dynamic>
```

## 🎯 Interview Tips

1. **Q: push vs pushReplacement?**
   *A: push naya screen add karta hai stack me. pushReplacement current ko replace karta hai (stack me bhi).*

2. **Q: Named routes vs MaterialPageRoute?**
   *A: Named routes scalable hain bade apps me. MaterialPageRoute small apps + dynamic builders ke liye.*

3. **Q: Hero animation kab nahi chalti?**
   *A: Tags match nahi karte, ya direct push nahi (e.g. modal). Tab Hero affect nahi hota.*

4. **Q: Argument pass karne ka best way?**
   *A: Constructor (compile-time safe). Named routes me arguments map (runtime).*
