# 🌅 HOUR 1 — CONCEPT

## Layouts — UI Ka Skeleton

Flutter me UI **nested widgets** se banta hai. Layout widgets bata te hain ki child widgets kaise arrange honge.

> **Socho Aise:** Tum ek **shop owner** ho. Shelves vertical (Column) ya horizontal (Row) lagayoge. Items ko shelf me kaise rakho — center me, side me, evenly spread (mainAxis/crossAxis). Container = ek box jisme item rakhte ho with style (color, border).

---

## Column — Vertical Stack

```dart
Column(
  mainAxisAlignment: MainAxisAlignment.center,
  crossAxisAlignment: CrossAxisAlignment.start,
  children: [
    Text('First'),
    Text('Second'),
    Text('Third'),
  ],
)
```

**Layout direction:**
- **mainAxis** = vertical (Column ka primary direction)
- **crossAxis** = horizontal (perpendicular)

---

## Row — Horizontal Stack

```dart
Row(
  mainAxisAlignment: MainAxisAlignment.spaceBetween,
  crossAxisAlignment: CrossAxisAlignment.center,
  children: [
    Icon(Icons.home),
    Text('Home'),
    Icon(Icons.search),
  ],
)
```

**Layout direction:**
- **mainAxis** = horizontal (Row ka primary direction)
- **crossAxis** = vertical (perpendicular)

---

## MainAxisAlignment Options

| Value | Effect (Column) | Visual |
|-------|-----------------|--------|
| `start` | Top se | `■■■        ` |
| `end` | Bottom se | `        ■■■` |
| `center` | Beech me | `   ■■■    ` |
| `spaceBetween` | First/last edges, baki gap | `■  ■  ■` |
| `spaceAround` | Equal gap including edges | ` ■ ■ ■ ` |
| `spaceEvenly` | Sab equally spaced | ` ■ ■ ■ ` |

> **Yaad Rakho:** `mainAxisAlignment` Column me **vertical** position handle karta hai, Row me **horizontal**.

---

## CrossAxisAlignment Options

| Value | Effect (Column) |
|-------|-----------------|
| `start` | Left edge se align |
| `end` | Right edge se align |
| `center` | Center align |
| `stretch` | Full width fill (Column me) / full height (Row me) |
| `baseline` | Text baseline align |

```dart
Column(
  crossAxisAlignment: CrossAxisAlignment.stretch,
  children: [
    Container(height: 50, color: Colors.red),
    Container(height: 50, color: Colors.blue),  // full width fill
  ],
)
```

---

## Container — All-in-One Box

```dart
Container(
  width: 200,
  height: 100,
  margin: EdgeInsets.all(10),         // bahar ka spacing
  padding: EdgeInsets.all(16),        // andar ka spacing
  alignment: Alignment.center,        // child position

  decoration: BoxDecoration(
    color: Colors.indigo,
    borderRadius: BorderRadius.circular(12),
    border: Border.all(color: Colors.white, width: 2),
    boxShadow: [
      BoxShadow(
        color: Colors.black26,
        blurRadius: 8,
        offset: Offset(0, 4),
      ),
    ],
    gradient: LinearGradient(
      colors: [Colors.indigo, Colors.purple],
      begin: Alignment.topLeft,
      end: Alignment.bottomRight,
    ),
  ),

  child: Text('Hello', style: TextStyle(color: Colors.white)),
)
```

> **Yaad Rakho:** `Container` me `color` aur `decoration` saath nahi use kar sakte. Decoration use karo to color uske andar daalo (`BoxDecoration(color: ...)`).

---

## Padding vs SizedBox vs Margin

```dart
// Padding — andar space
Padding(
  padding: EdgeInsets.all(20),
  child: Text('Hello'),
)

// SizedBox — fixed size
SizedBox(
  width: 200,
  height: 100,
  child: Text('Hello'),
)

// SizedBox as spacer
Column(
  children: [
    Text('A'),
    SizedBox(height: 20),  // 20px gap
    Text('B'),
  ],
)

// Margin via Container
Container(
  margin: EdgeInsets.all(10),
  child: Text('Spaced'),
)
```

> **Tip:** **Spacer ke liye SizedBox use karo** — sabse simple, performant, intent clear hota hai.

---

## EdgeInsets Variants

```dart
EdgeInsets.all(16)                          // sab side 16
EdgeInsets.symmetric(horizontal: 20)        // left + right 20
EdgeInsets.symmetric(vertical: 10)          // top + bottom 10
EdgeInsets.only(left: 16, top: 8)           // specific sides
EdgeInsets.fromLTRB(10, 20, 10, 20)         // left/top/right/bottom
```

## Expanded — Available Space Fill

```dart
Row(
  children: [
    Container(width: 100, color: Colors.red),
    Expanded(
      child: Container(color: Colors.blue),  // baki saari space le lega
    ),
    Container(width: 80, color: Colors.green),
  ],
)
```

### Multiple Expanded with `flex`

```dart
Row(
  children: [
    Expanded(flex: 1, child: Container(color: Colors.red)),     // 1 part
    Expanded(flex: 2, child: Container(color: Colors.blue)),    // 2 parts
    Expanded(flex: 1, child: Container(color: Colors.green)),   // 1 part
  ],
)
// Total 4 parts: red 25%, blue 50%, green 25%
```

> **Yaad Rakho:** `Expanded` sirf `Row`, `Column`, `Flex` ke andar kaam karta hai. Akela use karoge to error.

---

## Flexible vs Expanded

| Widget | Behaviour |
|--------|-----------|
| `Expanded` | **Always** available space le leta hai |
| `Flexible` | Available space tak ja sakta hai, par child ke size pe depend |

```dart
Row(
  children: [
    Flexible(
      flex: 1,
      child: Text('Long text but flexible'),  // text size se zyada nahi
    ),
    Expanded(
      flex: 1,
      child: Container(color: Colors.blue),   // full available
    ),
  ],
)
```

## Stack — Overlay Widgets

```dart
Stack(
  children: [
    // Background image
    Container(
      width: double.infinity,
      height: 200,
      color: Colors.indigo,
    ),

    // Overlay text — bottom-left
    Positioned(
      bottom: 16,
      left: 16,
      child: Text('Overlay', style: TextStyle(color: Colors.white)),
    ),

    // Top-right badge
    Positioned(
      top: 8,
      right: 8,
      child: CircleAvatar(child: Text('5')),
    ),
  ],
)
```

> **Tip:** Stack image ke upar text overlay, badges, watermarks ke liye perfect.

## Task 1: Login Screen Layout (25 min)

```dart
import 'package:flutter/material.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: const LoginScreen(),
      debugShowCheckedModeBanner: false,
    );
  }
}

class LoginScreen extends StatelessWidget {
  const LoginScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: Colors.grey[100],
      body: SafeArea(
        child: Padding(
          padding: const EdgeInsets.all(24),
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              // Logo
              const Icon(Icons.flutter_dash, size: 80, color: Colors.indigo),
              const SizedBox(height: 16),

              // Title
              const Text(
                'Welcome Back',
                style: TextStyle(fontSize: 32, fontWeight: FontWeight.bold),
                textAlign: TextAlign.center,
              ),
              const SizedBox(height: 8),
              Text(
                'Login to continue',
                style: TextStyle(fontSize: 16, color: Colors.grey[600]),
                textAlign: TextAlign.center,
              ),
              const SizedBox(height: 40),

              // Email field
              Container(
                padding: const EdgeInsets.symmetric(horizontal: 16),
                decoration: BoxDecoration(
                  color: Colors.white,
                  borderRadius: BorderRadius.circular(12),
                  border: Border.all(color: Colors.grey.shade300),
                ),
                child: const TextField(
                  decoration: InputDecoration(
                    icon: Icon(Icons.email),
                    hintText: 'Email',
                    border: InputBorder.none,
                  ),
                ),
              ),
              const SizedBox(height: 16),

              // Password field
              Container(
                padding: const EdgeInsets.symmetric(horizontal: 16),
                decoration: BoxDecoration(
                  color: Colors.white,
                  borderRadius: BorderRadius.circular(12),
                  border: Border.all(color: Colors.grey.shade300),
                ),
                child: const TextField(
                  obscureText: true,
                  decoration: InputDecoration(
                    icon: Icon(Icons.lock),
                    hintText: 'Password',
                    border: InputBorder.none,
                  ),
                ),
              ),
              const SizedBox(height: 24),

              // Login button
              ElevatedButton(
                onPressed: () {},
                style: ElevatedButton.styleFrom(
                  backgroundColor: Colors.indigo,
                  foregroundColor: Colors.white,
                  padding: const EdgeInsets.symmetric(vertical: 16),
                  shape: RoundedRectangleBorder(
                    borderRadius: BorderRadius.circular(12),
                  ),
                ),
                child: const Text('LOGIN', style: TextStyle(fontSize: 16, fontWeight: FontWeight.bold)),
              ),
              const SizedBox(height: 16),

              // Forgot password
              TextButton(
                onPressed: () {},
                child: const Text('Forgot Password?'),
              ),
            ],
          ),
        ),
      ),
    );
  }
}
```

class StatsDashboard extends StatelessWidget {
  const StatsDashboard({super.key});

  Widget _statCard(String label, String value, Color color, IconData icon) {
    return Expanded(
      child: Container(
        margin: const EdgeInsets.symmetric(horizontal: 4),
        padding: const EdgeInsets.symmetric(vertical: 16),
        decoration: BoxDecoration(
          color: color.withOpacity(0.1),
          borderRadius: BorderRadius.circular(12),
          border: Border.all(color: color.withOpacity(0.3)),
        ),
        child: Column(
          children: [
            Icon(icon, color: color, size: 28),
            const SizedBox(height: 8),
            Text(
              value,
              style: TextStyle(fontSize: 22, fontWeight: FontWeight.bold, color: color),
            ),
            const SizedBox(height: 4),
            Text(
              label,
              style: TextStyle(fontSize: 12, color: Colors.grey[600]),
            ),
          ],
        ),
      ),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Padding(
      padding: const EdgeInsets.all(12),
      child: Row(
        children: [
          _statCard('Days', '7', Colors.indigo, Icons.calendar_today),
          _statCard('Topics', '12', Colors.green, Icons.book),
          _statCard('Hours', '14', Colors.orange, Icons.timer),

      ),
    );
  }
}

## 📋 Quick Revision

| Widget | Use |
|--------|-----|
| `Column` | Vertical stack |
| `Row` | Horizontal stack |
| `mainAxisAlignment` | Primary axis position |
| `crossAxisAlignment` | Perpendicular axis |
| `Container` | Box with size + decoration |
| `Padding` | Inner spacing |
| `SizedBox(h:20)` | Spacer or fixed size |
| `Expanded(flex:2)` | Fill available space |
| `Flexible` | Take up to available |
| `Stack + Positioned` | Overlay widgets |
| `BoxDecoration` | Border, shadow, gradient |
| `EdgeInsets` | Spacing values |

## ❌ Common Mistakes

```dart
// MISTAKE 1: Container me color + decoration dono
Container(color: Colors.red, decoration: BoxDecoration(...))  // ❌
// FIX: BoxDecoration(color: ...) andar daalo

// MISTAKE 2: Expanded Stack ke andar
Stack(children: [Expanded(child: ...)])  // ❌
// FIX: Stack me Positioned use karo

// MISTAKE 3: Row me unbounded width
Row(children: [Text('Long' * 100)])  // overflow
// FIX: Expanded ya Flexible se wrap karo

// MISTAKE 4: SizedBox without dimensions
SizedBox(child: Text('Hi'))  // bekaar
// FIX: SizedBox(width: 100, child: Text('Hi'))
```

## 🎯 Interview Tips

1. **Q: Row aur Column ka mainAxis kya hai?**
   *A: Row ka mainAxis horizontal, Column ka vertical. crossAxis perpendicular hota hai.*

2. **Q: Expanded aur Flexible me kya farq?**
   *A: Expanded **always** full available space leta hai. Flexible child ke needs tak.*

3. **Q: Container me color + decoration dono kyu nahi?**
   *A: Conflict hota hai — decoration apna color set kar sakti hai. Compiler ek baar me ek hi accept karta hai.*

4. **Q: Stack me child overlay kaise position karte hain?**
   *A: `Positioned` widget se — top/left/right/bottom values dekar.*
