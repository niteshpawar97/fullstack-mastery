# 🌅 HOUR 1 — CONCEPT

## CI/CD Kya Hai?

- **CI (Continuous Integration):** Code push pe automatically tests + builds run hote hain
- **CD (Continuous Deployment):** Tests pass to automatically Play Store/TestFlight pe deploy

> **Socho Aise:** Tum code likho — push karo. Robot khud test karega + APK banayega + Play Store upload karega. **Tum sirf code likhne pe focus.**

## GitHub Actions — Flutter Workflow

`.github/workflows/flutter.yml`:

```yaml
name: Flutter CI

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]

jobs:
  test:
    name: Test
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - name: Setup Flutter
        uses: subosito/flutter-action@v2
        with:
          flutter-version: '3.24.0'
          channel: 'stable'
          cache: true

      - name: Install dependencies
        run: flutter pub get

      - name: Analyze
        run: flutter analyze

      - name: Test
        run: flutter test --coverage

      - name: Upload coverage
        uses: codecov/codecov-action@v3
        with:
          file: coverage/lcov.info

  build-android:
    name: Build Android APK
    needs: test
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v3
        with:
          distribution: 'zulu'
          java-version: '17'
      - uses: subosito/flutter-action@v2
        with:
          flutter-version: '3.24.0'
          cache: true

      - run: flutter pub get
      - run: flutter build apk --release

      - name: Upload APK
        uses: actions/upload-artifact@v3
        with:
          name: release-apk
          path: build/app/outputs/flutter-apk/app-release.apk
```

> **Auto-trigger:** Push pe ye workflow run ho jayega. **Status badge** README me lag jayegi.

## Signed Build with Secrets

GitHub repo → Settings → Secrets:

- `KEYSTORE_BASE64` — keystore.jks ka base64 encoded content
- `KEYSTORE_PASSWORD`
- `KEY_ALIAS`
- `KEY_PASSWORD`

```bash
# Local pe encode
base64 upload-keystore.jks > keystore.txt
# Copy content to GitHub secret
```

Workflow update:

```yaml
      - name: Decode keystore
        run: |
          echo "${{ secrets.KEYSTORE_BASE64 }}" | base64 -d > android/app/upload-keystore.jks

      - name: Create key.properties
        run: |
          cat > android/key.properties <<EOF
          storePassword=${{ secrets.KEYSTORE_PASSWORD }}
          keyPassword=${{ secrets.KEY_PASSWORD }}
          keyAlias=${{ secrets.KEY_ALIAS }}
          storeFile=upload-keystore.jks
          EOF

      - run: flutter build appbundle --release
```

## Auto-Deploy to Play Store Internal Track

```yaml
      - name: Upload to Play Store
        uses: r0adkll/upload-google-play@v1
        with:
          serviceAccountJsonPlainText: ${{ secrets.SERVICE_ACCOUNT_JSON }}
          packageName: com.example.app
          releaseFiles: build/app/outputs/bundle/release/app-release.aab
          track: internal
          status: completed
```

> **Setup:** Google Cloud Console me service account banao with Play Console permission, JSON key download, GitHub secret me daalo.

## Codemagic Setup

1. [codemagic.io](https://codemagic.io) signup (Google Cloud auth)
2. **Add application** → GitHub repo connect
3. **Workflow Editor** → preset "Flutter App"
4. Configure:
   - Trigger: Push to main
   - Build: Android + iOS
   - Test: `flutter test`
   - Sign: Upload keystore
   - Publish: Play Store / TestFlight

> **Codemagic.yaml** option for code-based config (similar to GitHub Actions YAML).

### Sample codemagic.yaml

```yaml
workflows:
  android-workflow:
    name: Android Release
    instance_type: linux_x2
    environment:
      flutter: stable
      android_signing:
        - keystore_reference
    scripts:
      - name: Get packages
        script: flutter packages pub get
      - name: Test
        script: flutter test
      - name: Build AAB
        script: flutter build appbundle --release
    artifacts:
      - build/**/outputs/bundle/release/*.aab
    publishing:
      google_play:
        credentials: $GOOGLE_PLAY_SERVICE_ACCOUNT
        track: internal
```

# 🌆 HOUR 2 — PRACTICE

## Task 1: Setup GitHub Actions (30 min)

### Step 1: Create Workflow

`.github/workflows/flutter.yml`:

```yaml
name: Flutter CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: subosito/flutter-action@v2
        with:
          flutter-version: '3.24.0'
          cache: true
      - run: flutter pub get
      - run: flutter analyze
      - run: flutter test

  build-debug-apk:
    needs: test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v3
        with:
          distribution: 'zulu'
          java-version: '17'
      - uses: subosito/flutter-action@v2
        with:
          flutter-version: '3.24.0'
          cache: true
      - run: flutter pub get
      - run: flutter build apk --debug
      - uses: actions/upload-artifact@v3
        with:
          name: debug-apk
          path: build/app/outputs/flutter-apk/app-debug.apk
```

### Step 2: Push + Watch

## Task 2: PR Workflow (15 min)

`.github/workflows/pr.yml`:

```yaml
name: PR Checks

on:
  pull_request:
    branches: [main, develop]

jobs:
  validate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: subosito/flutter-action@v2
        with:
          flutter-version: '3.24.0'
          cache: true
      - run: flutter pub get

      - name: Format check
        run: dart format --set-exit-if-changed .

      - name: Analyze
        run: flutter analyze

      - name: Test
        run: flutter test --coverage

      - name: PR Comment
        if: failure()
        uses: actions/github-script@v7
        with:
          script: |
            github.rest.issues.createComment({
              issue_number: context.issue.number,
              owner: context.repo.owner,
              repo: context.repo.repo,
              body: '❌ Tests failed. Please fix before merging.'
            });
```

> **Result:** PR open hoga to format + analyze + tests check honge. Fail to **merge block**.

## ❌ Common Mistakes

```yaml
# MISTAKE 1: No cache
flutter-version: '3.24.0'  # without cache: true → slow build

# MISTAKE 2: Secrets in code
- run: KEY=hardcoded   # ❌ leaked
# FIX: ${{ secrets.X }}

# MISTAKE 3: Flutter version mismatch
# Local 3.16 vs CI 3.24 → behavior diff
# FIX: pin exact version

# MISTAKE 4: No quality gates
# CI green but no tests run
# FIX: flutter analyze + test required
```

## 🎯 Interview Tips

1. **Q: CI/CD ka real-world benefit?**
   *A: Faster feedback (push se 5 min me know if works), no manual deploy, fewer human errors.*

2. **Q: GitHub Actions vs Codemagic?**
   *A: Actions — free for OSS, flexible, complex YAML. Codemagic — Flutter-tailored, easier UI, paid above limits.*

3. **Q: Production deploy automate karna safe hai?**
   *A: Internal track haan. Production manual approval gate rakho — bug avoid karne ke liye.*
