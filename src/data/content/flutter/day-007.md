# 🌅 HOUR 1 — CONCEPT

## Widget — Flutter Ka DNA

Flutter me **sab kuch widget hai** — text, button, layout, padding, color, animation. Sab widget hain.

> **Socho Aise:** Widget = LEGO block. Tum chote chote blocks (widgets) ko combine karke bada banate ho — house, car, robot. Flutter app bhi exactly waise — small widgets ko nest karke complete UI banti hai.

---

## Widget Tree Concept

```
MaterialApp
  └── Scaffold
        ├── AppBar
        │     └── Text('Title')
        ├── body
        │     └── Center
        │           └── Text('Hello')
        └── FloatingActionButton
              └── Icon(Icons.add)
```

Har widget ka ek **parent** hota hai (except root) aur **children** ho sakte hain.

> **Yaad Rakho:** Widget **immutable** hote hain — ek baar create hone ke baad change nahi hote. UI update karne ke liye **rebuild** hota hai (purana tree replace, naya bana).

---

## Stateless vs Stateful Widget

### StatelessWidget
- **Static UI** — koi state nahi badalti
- Examples: Text label, Logo, Static card

### StatefulWidget (Day 11 me detail)
- **Dynamic UI** — counter, toggle, form
- State badal sakta hai

```dart
// Stateless example
class GreetingWidget extends StatelessWidget {
  final String name;

  const GreetingWidget({super.key, required this.name});

  @override
  Widget build(BuildContext context) {
    return Text('Hello, $name!');
  }
}
```

> **Tip:** Default me **StatelessWidget** use karo. Sirf jab UI dynamic ho (user input, animations), tabhi Stateful banao.

---

## `build()` Method

Har widget me `build(BuildContext context)` method hota hai — wahi UI return karta hai.

```dart
class MyWidget extends StatelessWidget {
  const MyWidget({super.key});

  @override
  Widget build(BuildContext context) {
    return Container(
      color: Colors.blue,
      child: Text('Hello'),
    );
  }
}
```

> **Yaad Rakho:** `build()` Flutter automatically call karta hai — tum nahi karte. Jab UI rebuild hota hai (parent change, hot reload), Flutter `build()` dobara call karta hai.

## MaterialApp — Root Widget

```dart
MaterialApp(
  title: 'My App',                  // OS-level app title
  debugShowCheckedModeBanner: false, // top-right "DEBUG" banner hide
  theme: ThemeData(
    primarySwatch: Colors.indigo,
    scaffoldBackgroundColor: Colors.grey[100],
    fontFamily: 'Roboto',
  ),
  darkTheme: ThemeData.dark(),       // dark mode theme
  themeMode: ThemeMode.system,       // system/light/dark
  home: HomePage(),                  // first screen
)
```

### ThemeData Deep Dive

```dart
theme: ThemeData(
  // Color scheme (Material 3)
  colorScheme: ColorScheme.fromSeed(seedColor: Colors.indigo),
  useMaterial3: true,

  // Text styles
  textTheme: const TextTheme(
    headlineLarge: TextStyle(fontSize: 32, fontWeight: FontWeight.bold),
    bodyLarge: TextStyle(fontSize: 16),
  ),

  // App bar style
  appBarTheme: const AppBarTheme(
    backgroundColor: Colors.indigo,
    foregroundColor: Colors.white,
    elevation: 4,
  ),
)
```

> **Tip:** Theme define karne se **app-wide consistency** aati hai. Color/font ek jagah change karo, sab screens pe apply.

## Scaffold — Page Skeleton

Scaffold ek **standard page layout** provide karta hai:

```dart
Scaffold(
  appBar: AppBar(title: Text('My App')),
  body: Center(child: Text('Content here')),
  floatingActionButton: FloatingActionButton(
    onPressed: () { /* action */ },
    child: Icon(Icons.add),
  ),
  bottomNavigationBar: BottomNavigationBar(...),
  drawer: Drawer(...),
  backgroundColor: Colors.white,
)
```

| Slot | Kya |
|------|-----|
| `appBar` | Top bar (title, actions) |
| `body` | Main content |
| `floatingActionButton` | Bottom-right circular button |
| `bottomNavigationBar` | Bottom tabs |
| `drawer` | Side menu (left swipe) |
| `endDrawer` | Right side menu |

## Task 1: "About Me" Page Setup (15 min)

`lib/main.dart` ko replace karo:

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'About Me',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.indigo),
        useMaterial3: true,
      ),
      home: const AboutMePage(),
    );
  }
}

class AboutMePage extends StatelessWidget {
  const AboutMePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('About Me'),
        centerTitle: true,
        backgroundColor: Colors.indigo,
        foregroundColor: Colors.white,
      ),
      body: const Center(
        child: Text(
          'Coming soon...',
          style: TextStyle(fontSize: 20),
        ),
      ),
    );
  }
}
```

`flutter run` karo aur AppBar dekho.

## ❌ Common Mistakes

```dart
// MISTAKE 1: const bhulna jab possible ho
Text('Hello')             // Better: const Text('Hello')

// MISTAKE 2: Scaffold ke bahar SnackBar
showSnackBar(...)         // Need ScaffoldMessenger.of(context)

// MISTAKE 3: setState in StatelessWidget
class MyWidget extends StatelessWidget {
  void increment() {
    setState(() {});      // ❌ Stateless me setState nahi
  }
}

// MISTAKE 4: build() me heavy work
@override
Widget build(BuildContext context) {
  fetchDataFromAPI();     // ❌ build me API call mat karo
  return ...;
}
```

## 🎯 Interview Tips

1. **Q: StatelessWidget aur StatefulWidget me kya farq?**
   *A: Stateless ki UI fixed (input change pe rebuild). Stateful me internal state badal sakta hai (`setState`).*

2. **Q: `const` constructor kab use karte hain?**
   *A: Jab widget compile-time pe known ho. Performance better — widget rebuild se bachta hai.*

3. **Q: BuildContext kya hai?**
   *A: Widget tree me current widget ki position. Theme, MediaQuery, Navigator access ke liye chahiye.*

4. **Q: Scaffold ke bina app chal sakti hai?**
   *A: Haan, par default styles (background, padding, snackbar support) miss honge. Material apps me hamesha use karte hain.*
