## ListView.builder — Performance Mode

Jab list me **bohot saare items** ho (100s, 1000s), `ListView` slow ho jayega. **`ListView.builder`** sirf visible items ko render karta hai (lazy loading).

```dart
List<String> contacts = List.generate(1000, (i) => 'Contact $i');

ListView.builder(
  itemCount: contacts.length,
  itemBuilder: (context, index) {
    return ListTile(
      leading: CircleAvatar(child: Text('${index + 1}')),
      title: Text(contacts[index]),
    );
  },
)
```

> **Tip:** **Hamesha `ListView.builder` use karo** dynamic data ke liye. Performance significantly better.

---

ListView.separated(

## GridView — Grid Layout

### GridView.count (Fixed Columns)

```dart
GridView.count(
  crossAxisCount: 2,           // 2 columns
  crossAxisSpacing: 8,
  mainAxisSpacing: 8,
  padding: EdgeInsets.all(8),
  children: List.generate(20, (i) =>
    Container(
      color: Colors.indigo.withOpacity(0.5),
      child: Center(child: Text('Item $i')),
    ),
  ),
)
```

### GridView.builder (Performance)

```dart
GridView.builder(
  gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: 3,
    crossAxisSpacing: 8,
    mainAxisSpacing: 8,
    childAspectRatio: 1,  // square (width/height)
  ),
  itemCount: 100,
  itemBuilder: (context, index) {
    return Container(color: Colors.primaries[index % 17]);
  },
)
```

### GridView.extent (Max Cell Width)

```dart
GridView.extent(
  maxCrossAxisExtent: 150,  // har cell max 150 wide
  children: [...],
)
```

> **Use Cases:**
> - **GridView.count**: Fixed grid (2-col, 3-col)
> - **GridView.builder**: Bohot saare items
> - **GridView.extent**: Responsive — screen size pe columns auto-adjust

## Images

### 1. Asset Image (App ke andar bundled)

`pubspec.yaml` me declare karna padta hai:

```yaml
flutter:
  uses-material-design: true
  assets:
    - assets/images/
    - assets/icons/profile.png
```

Folder structure:
```
my_app/
├── assets/
│   └── images/
│       ├── logo.png
│       └── profile.jpg
├── lib/
└── pubspec.yaml
```

Use:
```dart
Image.asset(
  'assets/images/logo.png',
  width: 100,
  height: 100,
  fit: BoxFit.cover,
)
```

> **Yaad Rakho:** `pubspec.yaml` me asset add ke baad **`flutter pub get`** run karo, warna asset load nahi hoga.

### 2. Network Image (Internet se)

```dart
Image.network(
  'https://picsum.photos/200',
  width: 200,
  height: 200,
  fit: BoxFit.cover,
  loadingBuilder: (context, child, progress) {
    if (progress == null) return child;
    return CircularProgressIndicator();
  },
  errorBuilder: (context, error, stackTrace) {
    return Icon(Icons.error);
  },
)
```

### 3. CircleAvatar — Round Image

```dart
CircleAvatar(
  radius: 40,
  backgroundImage: NetworkImage('https://i.pravatar.cc/150'),
  // OR
  // backgroundImage: AssetImage('assets/images/profile.jpg'),
)

// Letter avatar (no image)
CircleAvatar(
  backgroundColor: Colors.indigo,
  child: Text('A', style: TextStyle(color: Colors.white)),
)
```

### BoxFit Options

```dart
BoxFit.cover    // poori container fill karo, crop OK
BoxFit.contain  // image full dikhe, gaps OK
BoxFit.fill     // stretch karo (distortion ho sakta)
BoxFit.fitWidth // width fit, height adjust
BoxFit.fitHeight // height fit
BoxFit.none     // original size
BoxFit.scaleDown // contain par chota ho jaye to original size
```

> **Tip:** Photos ke liye `BoxFit.cover` (sabse common). Logos ke liye `BoxFit.contain`.

## Task 1: Photo Gallery with GridView (20 min)

```dart
import 'package:flutter/material.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: const GalleryScreen(),
      debugShowCheckedModeBanner: false,
    );
  }
}

class GalleryScreen extends StatelessWidget {
  const GalleryScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Photo Gallery'),
        backgroundColor: Colors.indigo,
        foregroundColor: Colors.white,
      ),
      body: GridView.builder(
        padding: const EdgeInsets.all(8),
        gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
          crossAxisCount: 3,
          crossAxisSpacing: 8,
          mainAxisSpacing: 8,
          childAspectRatio: 1,
        ),
        itemCount: 30,
        itemBuilder: (context, index) {
          return ClipRRect(
            borderRadius: BorderRadius.circular(8),
            child: Image.network(
              'https://picsum.photos/200?random=$index',
              fit: BoxFit.cover,
              loadingBuilder: (context, child, progress) {
                if (progress == null) return child;
                return Container(
                  color: Colors.grey[200],
                  child: const Center(child: CircularProgressIndicator()),
                );
              },
              errorBuilder: (_, __, ___) => Container(
                color: Colors.grey[300],
                child: const Icon(Icons.broken_image),
              ),
            ),
          );
        },
      ),
    );
  }
}
```

> **Practice:** `crossAxisCount` ko 2 ya 4 karke dekho. Aspect ratio change karo (`16/9`).

## Task 2: Contact List with ListView.builder (20 min)

```dart
class Contact {
  final String name;
  final String phone;
  final String avatar;

  Contact(this.name, this.phone, this.avatar);
}

class ContactsScreen extends StatelessWidget {
  ContactsScreen({super.key});

  final List<Contact> contacts = List.generate(
    20,
    (i) => Contact(
      'Person ${i + 1}',
      '+91 9876${(54000 + i).toString().padLeft(5, '0')}',
      'https://i.pravatar.cc/150?img=${i + 1}',
    ),
  );

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Contacts'),
        backgroundColor: Colors.indigo,
        foregroundColor: Colors.white,
        actions: [
          IconButton(icon: const Icon(Icons.search), onPressed: () {}),
          IconButton(icon: const Icon(Icons.more_vert), onPressed: () {}),
        ],
      ),
      body: ListView.separated(
        itemCount: contacts.length,
        separatorBuilder: (_, __) => const Divider(height: 1),
        itemBuilder: (context, index) {
          final contact = contacts[index];
          return ListTile(
            leading: CircleAvatar(
              backgroundImage: NetworkImage(contact.avatar),
            ),
            title: Text(contact.name, style: const TextStyle(fontWeight: FontWeight.w600)),
            subtitle: Text(contact.phone),
            trailing: Row(
              mainAxisSize: MainAxisSize.min,
              children: [
                IconButton(
                  icon: const Icon(Icons.call, color: Colors.green),
                  onPressed: () => print('Call ${contact.name}'),
                ),
                IconButton(
                  icon: const Icon(Icons.message, color: Colors.indigo),
                  onPressed: () => print('Msg ${contact.name}'),
                ),
              ],
            ),
            onTap: () {
              ScaffoldMessenger.of(context).showSnackBar(
                SnackBar(content: Text('Tapped ${contact.name}')),
              );
            },
          );
        },
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: () {},
        backgroundColor: Colors.indigo,
        child: const Icon(Icons.person_add, color: Colors.white),
      ),
    );
  }
}
```

> **Run karo** — list scrollable hogi, har contact pe call/message buttons.

## Task 3: Network Image with Loading State (10 min)

```dart
class FancyImage extends StatelessWidget {
  final String url;
  final double size;

  const FancyImage({super.key, required this.url, this.size = 200});

  @override
  Widget build(BuildContext context) {
    return ClipRRect(
      borderRadius: BorderRadius.circular(16),
      child: Image.network(
        url,
        width: size,
        height: size,
        fit: BoxFit.cover,
        loadingBuilder: (context, child, progress) {
          if (progress == null) return child;
          return SizedBox(
            width: size,
            height: size,
            child: Center(
              child: CircularProgressIndicator(
                value: progress.expectedTotalBytes != null
                    ? progress.cumulativeBytesLoaded / progress.expectedTotalBytes!
                    : null,
              ),
            ),
          );
        },
        errorBuilder: (_, __, ___) => Container(
          width: size,
          height: size,
          color: Colors.red[100],
          child: const Center(
            child: Icon(Icons.error, color: Colors.red, size: 48),
          ),
        ),
      ),
    );
  }
}
```

## Task 4: Icon-Based Bottom Navigation (UI only) (15 min)

```dart
class HomeWithBottomNav extends StatefulWidget {
  const HomeWithBottomNav({super.key});

  @override
  State<HomeWithBottomNav> createState() => _HomeWithBottomNavState();
}

class _HomeWithBottomNavState extends State<HomeWithBottomNav> {
  int _selectedIndex = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Home')),
      body: Center(
        child: Text('Tab $_selectedIndex selected', style: const TextStyle(fontSize: 24)),
      ),
      bottomNavigationBar: BottomNavigationBar(
        currentIndex: _selectedIndex,
        onTap: (i) => setState(() => _selectedIndex = i),
        type: BottomNavigationBarType.fixed,
        selectedItemColor: Colors.indigo,
        items: const [
          BottomNavigationBarItem(icon: Icon(Icons.home), label: 'Home'),
          BottomNavigationBarItem(icon: Icon(Icons.search), label: 'Search'),
          BottomNavigationBarItem(icon: Icon(Icons.favorite), label: 'Likes'),
          BottomNavigationBarItem(icon: Icon(Icons.person), label: 'Profile'),
        ],
      ),
    );
  }
}
```

## ❌ Common Mistakes

```dart
// MISTAKE 1: ListView.builder me itemCount bhulna
ListView.builder(itemBuilder: (c, i) => ...)  // ❌ infinite list crash

// MISTAKE 2: Asset add karke pub get nahi karna
// pubspec.yaml me likha but flutter pub get nahi kiya → asset load nahi

// MISTAKE 3: Image.network without errorBuilder
Image.network(url)  // network fail → red X
// FIX: errorBuilder add karo

// MISTAKE 4: Column me ListView (unbounded height)
Column(children: [ListView.builder(...)])  // ❌
// FIX: Expanded(child: ListView.builder(...))

Icon(Icons.facebookk)  // ❌ — typo
```

## 🎯 Interview Tips

1. **Q: ListView aur ListView.builder me kya farq?**
   *A: ListView saare children eagerly create karta hai. Builder lazy — sirf visible items.*

2. **Q: GridView me responsive grid kaise banayein?**
   *A: `GridView.extent(maxCrossAxisExtent: 200)` — screen size se columns auto-adjust.*

3. **Q: Image.network slow lagti hai, kaise improve karein?**
   *A: `cached_network_image` package use karo — disk cache + memory cache automatic.*

4. **Q: Asset images kahan declare karte hain?**
   *A: `pubspec.yaml` me `flutter:` ke andar `assets:` section me. Path `assets/...` se start.*
