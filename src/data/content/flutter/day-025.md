# 🌅 HOUR 1 — CONCEPT

## Push Notifications Kya Hain?

Server se app pe **message bhejna** even when app **band ho** ya background me ho.

> **Socho Aise:** WhatsApp message — phone band hai, par notification aata hai. **Wo push notification hai.**

### FCM (Firebase Cloud Messaging)

Google ka free push notification service. **Unlimited messages**, kisi ko bhi bhej sakte ho.

### Notification States

| State | Description |
|-------|-------------|
| **Foreground** | App khula hai, screen pe hai |
| **Background** | App khula par minimize / different screen |
| **Terminated** | App pura close (swipe se) |

Har state ka handling different hota hai.

## Initialize FCM

```dart
import 'package:firebase_messaging/firebase_messaging.dart';

Future<void> initializeFCM() async {
  // Permission (iOS + Android 13+)
  final settings = await FirebaseMessaging.instance.requestPermission(
    alert: true,
    badge: true,
    sound: true,
  );

  print('Permission: ${settings.authorizationStatus}');

  // Get FCM token
  final token = await FirebaseMessaging.instance.getToken();
  print('FCM Token: $token');
  // Save token to Firestore for sending notifications later
}
```

> **FCM Token** har device ka unique ID hai. Token Firestore me save karke server side se specific user ko message bhej sakte ho.

## Receive Notifications

### Foreground

```dart
FirebaseMessaging.onMessage.listen((RemoteMessage message) {
  print('Foreground: ${message.notification?.title}');
  print('Body: ${message.notification?.body}');
  print('Data: ${message.data}');

  // App khula hai — manually local notification dikhao
  // (default me foreground notification show nahi hoti)
});
```

### Background (User Tapped)

```dart
FirebaseMessaging.onMessageOpenedApp.listen((RemoteMessage message) {
  print('User tapped notification (app was background)');
  // Navigate to specific screen
  Navigator.pushNamed(context, '/details', arguments: message.data['id']);
});
```

### Terminated → Open Notification

```dart
final initialMessage = await FirebaseMessaging.instance.getInitialMessage();
if (initialMessage != null) {
  // App was opened FROM notification (terminated state)
  print('Initial: ${initialMessage.notification?.title}');
}
```

### Background Handler (App killed, message received)

```dart
@pragma('vm:entry-point')
Future<void> backgroundHandler(RemoteMessage message) async {
  await Firebase.initializeApp();
  print('Background message: ${message.notification?.title}');
}

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp();
  FirebaseMessaging.onBackgroundMessage(backgroundHandler);
  runApp(const MyApp());
}
```

> **Important:** Background handler **top-level function** hona chahiye (class method nahi). `@pragma('vm:entry-point')` mandatory.

## Local Notifications (Without Server)

`flutter_local_notifications` se app khud ke andar se notifications dikha sakta hai.

```dart
import 'package:flutter_local_notifications/flutter_local_notifications.dart';

final _notifications = FlutterLocalNotificationsPlugin();

Future<void> initLocalNotifications() async {
  const androidSettings = AndroidInitializationSettings('@mipmap/ic_launcher');
  const iosSettings = DarwinInitializationSettings();

  await _notifications.initialize(
    const InitializationSettings(android: androidSettings, iOS: iosSettings),
    onDidReceiveNotificationResponse: (response) {
      print('Tapped: ${response.payload}');
    },
  );
}

Future<void> showSimpleNotification(String title, String body) async {
  const details = NotificationDetails(
    android: AndroidNotificationDetails(
      'default_channel',
      'Default Channel',
      importance: Importance.max,
      priority: Priority.high,
    ),
    iOS: DarwinNotificationDetails(),
  );

  await _notifications.show(0, title, body, details);
}
```


```dart
import 'package:timezone/data/latest.dart' as tz;
import 'package:timezone/timezone.dart' as tz;

Future<void> scheduleNotification(DateTime when, String title, String body) async {
  tz.initializeTimeZones();

  await _notifications.zonedSchedule(
    1,
    title,
    body,
    tz.TZDateTime.from(when, tz.local),
    const NotificationDetails(
      android: AndroidNotificationDetails(
        'default_channel',
        'Default Channel',
        importance: Importance.max,
      ),
      iOS: DarwinNotificationDetails(),
    ),
    androidScheduleMode: AndroidScheduleMode.exactAllowWhileIdle,
    uiLocalNotificationDateInterpretation: UILocalNotificationDateInterpretation.absoluteTime,
  );
}

// Use
scheduleNotification(
  DateTime.now().add(const Duration(seconds: 30)),
  'Reminder',
  'Aapka 30 second wait khatam!',
);
```

## Task 1: FCM Setup + Token Display (25 min)

```dart
import 'package:flutter/material.dart';
import 'package:firebase_core/firebase_core.dart';
import 'package:firebase_messaging/firebase_messaging.dart';
import 'package:flutter_local_notifications/flutter_local_notifications.dart';

@pragma('vm:entry-point')
Future<void> backgroundHandler(RemoteMessage message) async {
  await Firebase.initializeApp();
  print('BG: ${message.notification?.title}');
}

final localNotifications = FlutterLocalNotificationsPlugin();

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp();

  // Background handler
  FirebaseMessaging.onBackgroundMessage(backgroundHandler);

  // Local notifications
  await localNotifications.initialize(
    const InitializationSettings(
      android: AndroidInitializationSettings('@mipmap/ic_launcher'),
      iOS: DarwinInitializationSettings(),
    ),
  );

  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});
  @override
  Widget build(BuildContext context) =>
      const MaterialApp(home: NotificationScreen(), debugShowCheckedModeBanner: false);
}

class NotificationScreen extends StatefulWidget {
  const NotificationScreen({super.key});
  @override
  State<NotificationScreen> createState() => _NotificationScreenState();
}

class _NotificationScreenState extends State<NotificationScreen> {
  String? _token;
  final List<String> _messages = [];

  @override
  void initState() {
    super.initState();
    _setupFCM();
  }

  Future<void> _setupFCM() async {
    // Permission
    final settings = await FirebaseMessaging.instance.requestPermission(alert: true, badge: true, sound: true);
    print('Permission: ${settings.authorizationStatus}');

    // Token
    final token = await FirebaseMessaging.instance.getToken();
    setState(() => _token = token);

    // Foreground listener
    FirebaseMessaging.onMessage.listen((message) {
      final title = message.notification?.title ?? '';
      final body = message.notification?.body ?? '';

      setState(() => _messages.insert(0, '$title: $body'));

      // Show as local notification
      localNotifications.show(
        0,
        title,
        body,
        const NotificationDetails(
          android: AndroidNotificationDetails('default_channel', 'Default', importance: Importance.max),
          iOS: DarwinNotificationDetails(),
        ),
      );
    });

    // Background tap
    FirebaseMessaging.onMessageOpenedApp.listen((message) {
      print('Tapped: ${message.notification?.title}');
    });
  }

  Future<void> _copyToken() async {
    if (_token == null) return;
    // Use clipboard package or just print
    print('Token: $_token');
    ScaffoldMessenger.of(context).showSnackBar(
      const SnackBar(content: Text('Token printed in console')),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('FCM Demo')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            const Text('FCM Token (use to test):', style: TextStyle(fontWeight: FontWeight.bold)),
            const SizedBox(height: 8),
            SelectableText(_token ?? 'Loading...', style: const TextStyle(fontSize: 10, fontFamily: 'monospace')),
            const SizedBox(height: 16),
            ElevatedButton(onPressed: _copyToken, child: const Text('Print Token')),
            const Divider(height: 32),
            const Text('Received messages:', style: TextStyle(fontWeight: FontWeight.bold)),
            Expanded(
              child: _messages.isEmpty
                  ? const Center(child: Text('Koi message nahi — Console se test karo'))
                  : ListView.builder(
                      itemCount: _messages.length,
                      itemBuilder: (_, i) => Card(child: ListTile(title: Text(_messages[i]))),
                    ),
            ),
          ],
        ),
      ),
    );
  }
}
```

> **Test:**
> 1. App run karo, token copy karo (console se)
> 2. Firebase Console → Cloud Messaging → Send notification → paste token
> 3. App foreground me → notification dikhega + list me add hoga
> 4. App background → system notification, tap pe app khulega

## Task 2: Topic Subscription UI (15 min)

```dart
class TopicsScreen extends StatefulWidget {
  const TopicsScreen({super.key});
  @override
  State<TopicsScreen> createState() => _TopicsScreenState();
}

class _TopicsScreenState extends State<TopicsScreen> {
  final Map<String, bool> _subscriptions = {
    'news': false,
    'sports': false,
    'tech': false,
    'offers': false,
  };

  Future<void> _toggle(String topic) async {
    final current = _subscriptions[topic] ?? false;
    if (current) {
      await FirebaseMessaging.instance.unsubscribeFromTopic(topic);
    } else {
      await FirebaseMessaging.instance.subscribeToTopic(topic);
    }
    setState(() => _subscriptions[topic] = !current);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Subscriptions')),
      body: ListView(
        children: _subscriptions.keys.map((topic) {
          return SwitchListTile(
            title: Text(topic.toUpperCase()),
            subtitle: Text('Subscribe to $topic notifications'),
            value: _subscriptions[topic]!,
            onChanged: (_) => _toggle(topic),
          );
        }).toList(),
      ),
    );
  }
}
```

## Task 3: Scheduled Reminder (15 min)

```dart
import 'package:timezone/data/latest.dart' as tz;
import 'package:timezone/timezone.dart' as tz;

class ReminderScreen extends StatefulWidget {
  const ReminderScreen({super.key});
  @override
  State<ReminderScreen> createState() => _ReminderScreenState();
}

class _ReminderScreenState extends State<ReminderScreen> {
  final _titleController = TextEditingController();
  int _seconds = 10;

  @override
  void initState() {
    super.initState();
    tz.initializeTimeZones();
  }

  Future<void> _schedule() async {
    if (_titleController.text.trim().isEmpty) return;
    final scheduledTime = DateTime.now().add(Duration(seconds: _seconds));

    await localNotifications.zonedSchedule(
      DateTime.now().millisecondsSinceEpoch ~/ 1000,
      'Reminder',
      _titleController.text,
      tz.TZDateTime.from(scheduledTime, tz.local),
      const NotificationDetails(
        android: AndroidNotificationDetails('default_channel', 'Default', importance: Importance.max),
        iOS: DarwinNotificationDetails(),
      ),
      androidScheduleMode: AndroidScheduleMode.exactAllowWhileIdle,
      uiLocalNotificationDateInterpretation: UILocalNotificationDateInterpretation.absoluteTime,
    );

    if (!mounted) return;
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('Reminder set for $_seconds seconds')),
    );
    _titleController.clear();
  }

  @override
  void dispose() {
    _titleController.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Schedule Reminder')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          children: [
            TextField(
              controller: _titleController,
              decoration: const InputDecoration(labelText: 'Reminder text', border: OutlineInputBorder()),
            ),
            const SizedBox(height: 12),
            Row(
              children: [
                const Text('Trigger after: '),
                Expanded(
                  child: Slider(
                    value: _seconds.toDouble(),
                    min: 5,
                    max: 60,
                    divisions: 11,
                    label: '${_seconds}s',
                    onChanged: (v) => setState(() => _seconds = v.toInt()),
                  ),
                ),
                Text('${_seconds}s'),
              ],
            ),
            const SizedBox(height: 12),
            ElevatedButton(onPressed: _schedule, child: const Text('Schedule Notification')),
          ],
        ),
      ),
    );
  }
}
```

## 🎯 Interview Tips

1. **Q: FCM ka token kya hai aur kaha save karte ho?**
   *A: Per-device unique ID. Firestore me user document me save karke specific user ko message bhej sakte hain server se.*

2. **Q: Topic vs token notifications?**
   *A: Token — specific user. Topic — sab subscribers (broadcast). Topic scalable, token personal.*

3. **Q: Background handler kyu top-level function?**
   *A: Background isolate me chalta hai — class state available nahi. Static/top-level only.*

4. **Q: Local vs push notifications?**
   *A: Local — app ke andar se trigger (alarm, reminder). Push — server se aaya (FCM).*
