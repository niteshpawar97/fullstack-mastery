# 🌅 HOUR 1 — CONCEPT

## Function Kya Hota Hai?

Function matlab ek **reusable code block** jo kuch input leta hai (parameters), kuch kaam karta hai, aur output deta hai (return value).

> **Socho Aise:** Tumhare ghar me ek **mixer machine** hai. Tum usme aam dalte ho (input), button dabate ho (function call), aur juice nikalta hai (output). Har baar mixer banane ki zaroorat nahi — ek baar bana, baar baar use karo. Bilkul waise hi function hota hai.

---

## Function Syntax

```dart
returnType functionName(parameter1, parameter2) {
  // kaam karo
  return result;
}
```

### Simple Example

```dart
int add(int a, int b) {
  return a + b;
}

void main() {
  int sum = add(5, 3);
  print(sum);  // 8
}
```

### Return Type `void`

Agar function kuch return nahi karta, to `void` use karo:

```dart
void greet(String name) {
  print('Hello, $name!');
  // koi return nahi
}

void main() {
  greet('Ashutosh');  // Hello, Ashutosh!
}
```

> **Yaad Rakho:** Dart strongly typed hai — return type aur parameter types pehle se declare karne hote hain. JavaScript jaisa "kuch bhi return karo" nahi chalega.

---

## Optional Parameters

Dart me 2 type ke optional parameters hote hain:

### 1. Positional Optional `[...]`

```dart
String greet(String name, [String greeting = 'Hello']) {
  return '$greeting, $name!';
}

void main() {
  print(greet('Ashutosh'));            // Hello, Ashutosh!
  print(greet('Rohit', 'Namaste'));    // Namaste, Rohit!
}
```

### 2. Named Optional `{...}`

```dart
String createUser({required String name, int age = 18, String city = 'Lucknow'}) {
  return '$name ($age) from $city';
}

void main() {
  print(createUser(name: 'Ashutosh'));                          // Ashutosh (18) from Lucknow
  print(createUser(name: 'Rohit', age: 25, city: 'Delhi'));     // Rohit (25) from Delhi
  print(createUser(age: 30, name: 'Priya'));                    // order matter nahi karta
}
```

> **Tip:** Jab parameters 3+ ho ya optional ho, **named parameters** use karo — readable hota hai. Flutter widgets me named parameters hi everywhere chalte hain (`Container(color: Colors.red, width: 100)`).

## Arrow `=>` Shorthand

Single expression wale function ke liye `=>` use kar sakte ho:

```dart
// Long form
int square(int x) {
  return x * x;
}

// Arrow form (same thing)
int squareShort(int x) => x * x;

// More examples
String greet(String name) => 'Hello, $name';
bool isEven(int n) => n % 2 == 0;
double area(double r) => 3.14 * r * r;
```

> **Yaad Rakho:** Arrow sirf **single expression** ke liye kaam karta hai. Multiple lines ke liye `{ ... }` block hi use karna padega.

---

## Closures — Functions That Remember

**Closure** ek aisa function hai jo **apne bahar ke variables** ko remember karta hai, even after function call khatam ho jaye.

```dart
Function makeCounter() {
  int count = 0;

  return () {
    count++;
    return count;
  };
}

void main() {
  var counter1 = makeCounter();
  print(counter1());  // 1
  print(counter1());  // 2
  print(counter1());  // 3

  var counter2 = makeCounter();
  print(counter2());  // 1 (alag counter)
}
```

> **Socho Aise:** Closure ek **dabba** hai jisme function aur uske around ka data dono closed hote hain. Jaise tumhara wallet — wallet (function) khol ne pe paisa (variables) miljata hai. Ek wallet ka paisa doosre wallet me nahi jata.

## Higher-Order Functions

Higher-order function = ek function jo **doosre function ko parameter le** ya **function return kare**.

### Example: Function as Parameter

```dart
int operate(int a, int b, Function operation) {
  return operation(a, b);
}

int add(int a, int b) => a + b;
int multiply(int a, int b) => a * b;

void main() {
  print(operate(5, 3, add));       // 8
  print(operate(5, 3, multiply));  // 15

  // Anonymous function bhi pass kar sakte ho
  print(operate(10, 2, (a, b) => a - b));  // 8
}
```

### List ke Higher-Order Functions

Dart ki List me built-in helpful methods hain:

```dart
void main() {
  List<int> numbers = [1, 2, 3, 4, 5];

  // forEach — har item pe action
  numbers.forEach((n) => print('Item: $n'));

  // map — har item ko transform
  List<int> doubled = numbers.map((n) => n * 2).toList();
  print(doubled);  // [2, 4, 6, 8, 10]

  // where — filter
  List<int> evens = numbers.where((n) => n % 2 == 0).toList();
  print(evens);  // [2, 4]

  // reduce — single value mein collapse
  int sum = numbers.reduce((a, b) => a + b);
  print(sum);  // 15
}
```

> **Tip:** `map`, `where`, `reduce` JavaScript me bhi same names se hote hain. Functional programming ka core hai ye. Code cleaner banata hai vs manual loops.

## Task 1: Calculator Function (15 min)

Ek calculator banao jo 4 operations support kare:

```dart
double calculate(double a, double b, String op) {
  switch (op) {
    case '+': return a + b;
    case '-': return a - b;
    case '*': return a * b;
    case '/':
      if (b == 0) {
        print('Error: Zero se divide nahi');
        return 0;
      }
      return a / b;
    default:
      print('Unknown operation');
      return 0;
  }
}

void main() {
  print(calculate(15, 5, '+'));  // 20.0
  print(calculate(15, 5, '*'));  // 75.0
  print(calculate(15, 0, '/'));  // Error
}
```

> **Challenge:** Modulo (`%`) aur power (`^`) bhi add karo.

## Task 2: Apply Discount with Named Params (15 min)

```dart
double applyDiscount({
  required double price,
  double discountPercent = 10,
  bool isMember = false,
}) {
  double discount = price * discountPercent / 100;
  if (isMember) discount += price * 0.05;  // member ko extra 5%
  return price - discount;
}

void main() {
  print(applyDiscount(price: 1000));                                  // 900
  print(applyDiscount(price: 1000, discountPercent: 20));             // 800
  print(applyDiscount(price: 1000, isMember: true));                  // 850
  print(applyDiscount(price: 1000, discountPercent: 25, isMember: true));  // 700
}
```

> **Challenge:** Tax bhi add karo as named param. Final = (price - discount) + tax.

## Task 3: Counter Using Closure (15 min)

```dart
Function makeCounter({int start = 0, int step = 1}) {
  int count = start;
  return () {
    int current = count;
    count += step;
    return current;
  };
}

void main() {
  var c1 = makeCounter();
  print(c1());  // 0
  print(c1());  // 1
  print(c1());  // 2

  var c2 = makeCounter(start: 10, step: 5);
  print(c2());  // 10
  print(c2());  // 15
  print(c2());  // 20
}
```

## Task 4: Map/Filter/Reduce on a List (20 min)

```dart
void main() {
  List<Map<String, dynamic>> students = [
    {'name': 'Ashutosh', 'marks': 85},
    {'name': 'Rohit', 'marks': 62},
    {'name': 'Priya', 'marks': 91},
    {'name': 'Amit', 'marks': 45},
    {'name': 'Sneha', 'marks': 78},
  ];

  // 1. Sirf naam list nikalo
  List<String> names = students.map((s) => s['name'] as String).toList();
  print('Names: $names');

  // 2. Pass students (>= 60)
  List<String> passed = students
      .where((s) => s['marks'] >= 60)
      .map((s) => s['name'] as String)
      .toList();
  print('Passed: $passed');

  // 3. Total marks
  int total = students
      .map((s) => s['marks'] as int)
      .reduce((a, b) => a + b);
  print('Total: $total');

  // 4. Average
  double avg = total / students.length;
  print('Average: $avg');

  // 5. Topper
  var topper = students.reduce((a, b) =>
      (a['marks'] as int) > (b['marks'] as int) ? a : b);
  print('Topper: ${topper['name']} with ${topper['marks']}');
}
```

## Task 5: Function as Parameter (10 min)

```dart
List<int> processList(List<int> items, int Function(int) transformer) {
  List<int> result = [];
  for (int item in items) {
    result.add(transformer(item));
  }
  return result;
}

void main() {
  List<int> nums = [1, 2, 3, 4, 5];

  print(processList(nums, (n) => n * 2));      // [2, 4, 6, 8, 10]
  print(processList(nums, (n) => n * n));      // [1, 4, 9, 16, 25]
  print(processList(nums, (n) => n + 100));    // [101, 102, 103, 104, 105]
}
```

## 📋 Quick Revision

| Concept | Syntax |
|---------|--------|
| Function | `int add(int a, int b) { return a+b; }` |
| Arrow | `int add(int a, int b) => a + b;` |
| Optional positional | `[String x = 'default']` |
| Optional named | `{required String x, int y = 5}` |
| Anonymous | `(x) => x * 2` |
| Map | `list.map((x) => x*2).toList()` |
| Filter | `list.where((x) => x > 5).toList()` |
| Reduce | `list.reduce((a,b) => a+b)` |

## ❌ Common Mistakes

```dart
// MISTAKE 1: required bhul jana
void greet({String name}) { ... }
// FIX: void greet({required String name}) { ... }

// MISTAKE 2: Arrow me multiple statements
int square(int x) => { return x * x; }   // ❌
// FIX: int square(int x) => x * x;

// MISTAKE 3: map ke baad toList() bhul jana
List<int> doubled = numbers.map((n) => n * 2);  // ❌ Iterable hai
// FIX: numbers.map((n) => n * 2).toList();

// MISTAKE 4: void function se return karna
void greet(String name) {
  return 'Hello $name';  // ❌ void return nahi kar sakta
}
```

## 🎯 Interview Tips

1. **Q: Optional positional aur named parameters me kya farq?**
   *A: Positional `[]` order matter karta hai. Named `{}` order doesn't matter, par `paramName:` bolna padta hai.*

2. **Q: Arrow function kab use karna chahiye?**
   *A: Single expression ke liye. Multi-line ya complex logic me normal function better.*

3. **Q: Closure kya hai?**
   *A: Function jo apne enclosing scope ke variables ko capture karta hai. Counter, debouncer, throttle me use hota hai.*

4. **Q: `map` aur `where` me kya farq?**
   *A: `map` har item transform karta hai (length same). `where` filter karta hai (length kam ho sakti hai).*
