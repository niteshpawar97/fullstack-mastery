# 🌅 HOUR 1 — CONCEPT

## BlocProvider Scoping

```dart
// Global — pura app
runApp(BlocProvider(create: (_) => AuthBloc(), child: MyApp()));

// Screen-scoped — sirf ek screen
Navigator.push(context, MaterialPageRoute(
  builder: (_) => BlocProvider(create: (_) => TodoBloc(), child: TodoScreen()),
));

// Sub-tree scoped
BlocProvider.value(
  value: existingBloc,
  child: ChildWidget(),
)
```

> **Use `BlocProvider.value`** when bloc already exists (e.g., navigating with same instance).

## MultiBlocProvider

Multiple blocs ek saath inject karne ke liye:

```dart
runApp(
  MultiBlocProvider(
    providers: [
      BlocProvider(create: (_) => AuthBloc()),
      BlocProvider(create: (_) => ThemeCubit()),
      BlocProvider(create: (_) => CartBloc()),
    ],
    child: const MyApp(),
  ),
);
```

> **Cleaner** than nesting providers manually.

---

## BlocSelector — Fine-Grained Performance

`BlocBuilder` pure state pe rebuild hoti. `BlocSelector` se sirf specific field pe:

```dart
// Old: Builder rebuilds on ANY state change
BlocBuilder<TodoBloc, TodoState>(
  builder: (_, state) => Text('${state.todos.length}'),
)

// Better: Selector rebuilds only when length changes
BlocSelector<TodoBloc, TodoState, int>(
  selector: (state) => state.todos.length,
  builder: (_, length) => Text('$length'),
)
```

## RepositoryProvider — Dependency Injection

Bloc me dependencies (services, repositories) inject karne ke liye:

```dart
class AuthRepository {
  Future<User?> login(String email, String password) async {
    await Future.delayed(const Duration(seconds: 1));
    return User(name: email.split('@').first);
  }

  Future<void> logout() async {}
}

class User {
  final String name;
  User({required this.name});
}

// Inject globally
runApp(
  RepositoryProvider(
    create: (_) => AuthRepository(),
    child: BlocProvider(
      create: (context) => AuthBloc(repository: context.read<AuthRepository>()),
      child: MyApp(),
    ),
  ),
);

// Bloc consumes
class AuthBloc extends Bloc<AuthEvent, AuthState> {
  final AuthRepository repository;
  AuthBloc({required this.repository}) : super(AuthInitial()) {
    on<LoginRequested>((event, emit) async {
      emit(AuthLoading());
      final user = await repository.login(event.email, event.password);
      emit(user != null ? AuthSuccess(user) : const AuthFailure('Failed'));
    });
  }
}
```

> **Why?** Bloc testable hota hai — fake repository inject karke test kar sakte ho.

# 🌆 HOUR 2 — PRACTICE

## Task 1: Multi-Bloc App (Auth + Theme + Cart) (40 min)

```dart
// blocs/auth/auth_bloc.dart
sealed class AuthEvent {}
class AuthLoginRequested extends AuthEvent {
  final String email;
  AuthLoginRequested(this.email);
}
class AuthLogoutRequested extends AuthEvent {}

sealed class AuthState extends Equatable {
  const AuthState();
  @override
  List<Object?> get props => [];
}
class AuthUnauthenticated extends AuthState {}
class AuthAuthenticated extends AuthState {
  final String userName;
  const AuthAuthenticated(this.userName);
  @override
  List<Object> get props => [userName];
}

class AuthBloc extends Bloc<AuthEvent, AuthState> {
  AuthBloc() : super(AuthUnauthenticated()) {
    on<AuthLoginRequested>((e, emit) => emit(AuthAuthenticated(e.email.split('@').first)));
    on<AuthLogoutRequested>((_, emit) => emit(AuthUnauthenticated()));
  }
}

// blocs/theme/theme_cubit.dart
class ThemeCubit extends Cubit<bool> {
  ThemeCubit() : super(false);
  void toggle() => emit(!state);
}

// blocs/cart/cart_cubit.dart
class CartCubit extends Cubit<List<String>> {
  CartCubit() : super([]);
  void add(String item) => emit([...state, item]);
  void remove(int i) => emit([...state]..removeAt(i));
  void clear() => emit([]);
}

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MultiBlocProvider(
      providers: [
        BlocProvider(create: (_) => AuthBloc()),
        BlocProvider(create: (_) => ThemeCubit()),
        BlocProvider(create: (_) => CartCubit()),
      ],
      child: BlocBuilder<ThemeCubit, bool>(
        builder: (_, isDark) => MaterialApp(
          themeMode: isDark ? ThemeMode.dark : ThemeMode.light,
          theme: ThemeData.light(useMaterial3: true),
          darkTheme: ThemeData.dark(useMaterial3: true),
          home: const HomeScreen(),
        ),
      ),
    );
  }
}

class HomeScreen extends StatelessWidget {
  const HomeScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Multi-Bloc Demo'),
        actions: [
          // Cart count via BlocSelector (only rebuilds on count change)
          BlocSelector<CartCubit, List<String>, int>(
            selector: (state) => state.length,
            builder: (_, count) => Padding(
              padding: const EdgeInsets.symmetric(horizontal: 16),
              child: Row(children: [const Icon(Icons.shopping_cart), Text(' $count')]),
            ),
          ),
          BlocBuilder<ThemeCubit, bool>(
            builder: (context, isDark) => IconButton(
              icon: Icon(isDark ? Icons.light_mode : Icons.dark_mode),
              onPressed: () => context.read<ThemeCubit>().toggle(),
            ),
          ),
        ],
      ),
      body: BlocBuilder<AuthBloc, AuthState>(
        builder: (context, authState) {
          if (authState is AuthUnauthenticated) {
            return Center(
              child: Column(
                mainAxisAlignment: MainAxisAlignment.center,
                children: [
                  const Text('Login required'),
                  const SizedBox(height: 16),
                  ElevatedButton(
                    onPressed: () => context.read<AuthBloc>().add(AuthLoginRequested('user@app.com')),
                    child: const Text('Login as user@app.com'),
                  ),
                ],
              ),
            );
          }

          return Padding(
            padding: const EdgeInsets.all(16),
            child: Column(
              children: [
                Text('Welcome, ${(authState as AuthAuthenticated).userName}', style: const TextStyle(fontSize: 24)),
                const SizedBox(height: 16),
                Wrap(
                  spacing: 8,
                  children: ['Apple', 'Banana', 'Mango', 'Orange'].map((item) {
                    return ElevatedButton(
                      onPressed: () => context.read<CartCubit>().add(item),
                      child: Text('+ $item'),
                    );
                  }).toList(),
                ),
                const SizedBox(height: 16),
                BlocBuilder<CartCubit, List<String>>(
                  builder: (context, cart) {
                    if (cart.isEmpty) return const Text('Cart empty');
                    return Expanded(
                      child: ListView.builder(
                        itemCount: cart.length,
                        itemBuilder: (_, i) => ListTile(
                          title: Text(cart[i]),
                          trailing: IconButton(icon: const Icon(Icons.delete), onPressed: () => context.read<CartCubit>().remove(i)),
                        ),
                      ),
                    );
                  },
                ),
                ElevatedButton(
                  onPressed: () => context.read<AuthBloc>().add(AuthLogoutRequested()),
                  child: const Text('Logout'),
                ),
              ],
            ),
          );
        },
      ),
    );
  }
}
```

> **Notice:**
> - `BlocSelector` cart count ke liye — only rebuilds on length change
> - 3 blocs cleanly nested via `MultiBlocProvider`
> - Each bloc independent — auth, theme, cart

## Task 2: Repository Pattern Setup (15 min)

```dart
// repositories/auth_repository.dart
class AuthRepository {
  Future<String?> login(String email) async {
    await Future.delayed(const Duration(seconds: 1));
    if (email.contains('@')) return email.split('@').first;
    return null;
  }
}

// blocs/auth/auth_bloc.dart
class AuthBloc extends Bloc<AuthEvent, AuthState> {
  final AuthRepository repository;

  AuthBloc({required this.repository}) : super(AuthUnauthenticated()) {
    on<AuthLoginRequested>(_onLogin);
  }

  Future<void> _onLogin(AuthLoginRequested event, Emitter emit) async {
    final user = await repository.login(event.email);
    if (user != null) {
      emit(AuthAuthenticated(user));
    } else {
      // Failure state
    }
  }
}

// main.dart
void main() {
  runApp(
    RepositoryProvider(
      create: (_) => AuthRepository(),
      child: MultiBlocProvider(
        providers: [
          BlocProvider(create: (c) => AuthBloc(repository: c.read<AuthRepository>())),
        ],
        child: const MyApp(),
      ),
    ),
  );
}
```

## 🎯 Interview Tips

1. **Q: BlocBuilder vs BlocSelector?**
   *A: Builder rebuilds on full state change. Selector rebuilds only on selected field change — performance win.*

2. **Q: Repository pattern Bloc me kyu?**
   *A: Decouple — Bloc business logic, Repository data layer. Test me fake repo inject karke test.*

3. **Q: MultiBlocProvider order matter karta hai?**
   *A: Yes — earlier providers later providers ke liye access available. Dependency order me lagao.*
