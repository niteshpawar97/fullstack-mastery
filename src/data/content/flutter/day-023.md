# 🌅 HOUR 1 — CONCEPT

## Firestore Kya Hai?

Cloud Firestore = Google ka **NoSQL document database** with **real-time sync**.

> **Socho Aise:** Firestore ek **shared Excel sheet** jaisa hai jo cloud me hai. Tum row add karte ho — friend ki screen pe **instantly** dikh jata hai. **Real-time magic.**

### Firestore Structure

```
firestore-db/
├── notes/                 ← collection
│   ├── doc1/              ← document
│   │   ├── title: "Hello"
│   │   ├── body: "World"
│   │   └── createdAt: ...
│   └── doc2/
└── users/
    └── userId/
        └── name: "Ash"
```

| Concept | Matlab |
|---------|--------|
| **Collection** | Folder of documents (e.g., `notes`) |
| **Document** | One record (key-value map) |
| **Field** | Single data point |
| **Subcollection** | Document ke andar collection |

## CRUD Operations

### Get Reference

```dart
import 'package:cloud_firestore/cloud_firestore.dart';

final firestore = FirebaseFirestore.instance;
final notesRef = firestore.collection('notes');
```

### CREATE — Add Document

```dart
// Auto-generated ID
await notesRef.add({
  'title': 'My first note',
  'body': 'Hello Firestore',
  'createdAt': FieldValue.serverTimestamp(),
});

// Custom ID
await notesRef.doc('note-1').set({
  'title': 'Custom ID',
  'body': '...',
});
```

### READ — Single Document

```dart
final doc = await notesRef.doc('note-1').get();
if (doc.exists) {
  print(doc.data());          // Map
  print(doc.id);              // 'note-1'
  print(doc['title']);
}
```

### READ — All Documents

```dart
final snapshot = await notesRef.get();
for (final doc in snapshot.docs) {
  print('${doc.id}: ${doc['title']}');
}
```

### UPDATE — Modify Fields

```dart
// Specific fields update
await notesRef.doc('note-1').update({
  'title': 'Updated title',
  'updatedAt': FieldValue.serverTimestamp(),
});

// set with merge — exists to update, nahi to create
await notesRef.doc('note-1').set({
  'title': 'New',
}, SetOptions(merge: true));
```

### DELETE

```dart
await notesRef.doc('note-1').delete();
```

## Real-time Streams (Magic!)

`get()` ek baar fetch karta hai. **`snapshots()`** real-time stream return karta hai.

```dart
StreamBuilder<QuerySnapshot>(
  stream: notesRef.orderBy('createdAt', descending: true).snapshots(),
  builder: (context, snapshot) {
    if (snapshot.connectionState == ConnectionState.waiting) {
      return const CircularProgressIndicator();
    }
    if (!snapshot.hasData) return const Text('Empty');

    final docs = snapshot.data!.docs;
    return ListView.builder(
      itemCount: docs.length,
      itemBuilder: (_, i) {
        final note = docs[i];
        return ListTile(
          title: Text(note['title']),
          subtitle: Text(note['body']),
        );
      },
    );
  },
)
```

> **Magic:** Koi naya note add kare → list **instantly** update. Koi delete kare → list me se hat jata. **Zero refresh needed**.

## Queries

### where (Filter)

```dart
notesRef.where('userId', isEqualTo: 'user123')
notesRef.where('isPublished', isEqualTo: true)
notesRef.where('likes', isGreaterThan: 10)
notesRef.where('category', whereIn: ['tech', 'flutter'])
notesRef.where('tags', arrayContains: 'important')
```

### orderBy + limit

```dart
notesRef.orderBy('createdAt', descending: true).limit(10)
```

### Compound

```dart
notesRef
  .where('userId', isEqualTo: currentUserId)
  .where('isArchived', isEqualTo: false)
  .orderBy('createdAt', descending: true)
  .limit(20)
```

> **Yaad Rakho:** Complex queries pe Firebase **composite index** required hota hai. Console error me direct link milta hai — click karke create karo.

## Type-Safe Models with toFirestore/fromFirestore

```dart
class Note {
  final String id;
  final String title;
  final String body;
  final DateTime? createdAt;

  Note({required this.id, required this.title, required this.body, this.createdAt});

  factory Note.fromFirestore(DocumentSnapshot doc) {
    final data = doc.data() as Map<String, dynamic>;
    return Note(
      id: doc.id,
      title: data['title'] ?? '',
      body: data['body'] ?? '',
      createdAt: (data['createdAt'] as Timestamp?)?.toDate(),
    );
  }

  Map<String, dynamic> toFirestore() => {
    'title': title,
    'body': body,
    'createdAt': createdAt != null ? Timestamp.fromDate(createdAt!) : FieldValue.serverTimestamp(),
  };
}
```

> **Pro:** Use `withConverter` for fully typed:

```dart
final notesRef = FirebaseFirestore.instance.collection('notes').withConverter<Note>(
  fromFirestore: (doc, _) => Note.fromFirestore(doc),
  toFirestore: (note, _) => note.toFirestore(),
);

// Usage
await notesRef.add(Note(id: '', title: 'Hi', body: '...'));
final snapshot = await notesRef.get();
final notes = snapshot.docs.map((d) => d.data()).toList();  // List<Note>
```

## Security Rules

`firestore.rules` me default test mode rules:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Production rule example
    match /notes/{noteId} {
      // Only authenticated users
      allow read: if request.auth != null;

      // User can create only their own notes
      allow create: if request.auth != null &&
                   request.auth.uid == request.resource.data.userId;

      // User can edit/delete only their own notes
      allow update, delete: if request.auth != null &&
                           request.auth.uid == resource.data.userId;
    }
  }
}
```

> **Critical:** Production me **NEVER use test mode**. Rules properly likhe — warna anyone read/write kar sakta hai.

```dart
class Note {
  final String id;
  final String title;
  final String body;
  final String userId;
  final String category;
  final DateTime createdAt;

  Note({
    required this.id,
    required this.title,
    required this.body,
    required this.userId,
    required this.category,
    required this.createdAt,
  });

  factory Note.fromFirestore(DocumentSnapshot doc) {
    final data = doc.data() as Map<String, dynamic>;
    return Note(
      id: doc.id,
      title: data['title'] ?? '',
      body: data['body'] ?? '',
      userId: data['userId'] ?? '',
      category: data['category'] ?? 'general',
      createdAt: (data['createdAt'] as Timestamp?)?.toDate() ?? DateTime.now(),
    );
  }

  Map<String, dynamic> toFirestore() => {
    'title': title,
    'body': body,
    'userId': userId,
    'category': category,
    'createdAt': FieldValue.serverTimestamp(),
  };
}
```

### Step 2: NotesService

```dart
class NotesService {
  final _ref = FirebaseFirestore.instance.collection('notes');
  final _userId = FirebaseAuth.instance.currentUser!.uid;

  // Real-time stream — current user's notes
  Stream<List<Note>> watchNotes({String? category}) {
    Query q = _ref.where('userId', isEqualTo: _userId).orderBy('createdAt', descending: true);
    if (category != null && category != 'all') {
      q = q.where('category', isEqualTo: category);
    }
    return q.snapshots().map((s) => s.docs.map((d) => Note.fromFirestore(d)).toList());
  }

  Future<void> add(String title, String body, String category) async {
    await _ref.add({
      'title': title,
      'body': body,
      'userId': _userId,
      'category': category,
      'createdAt': FieldValue.serverTimestamp(),
    });
  }

  Future<void> update(String id, {String? title, String? body, String? category}) async {
    final data = <String, dynamic>{};
    if (title != null) data['title'] = title;
    if (body != null) data['body'] = body;
    if (category != null) data['category'] = category;
    data['updatedAt'] = FieldValue.serverTimestamp();
    await _ref.doc(id).update(data);
  }

  Future<void> delete(String id) async {
    await _ref.doc(id).delete();
  }
}
```

### Step 4: Edit/Add Note Screen

```dart
class EditNoteScreen extends StatefulWidget {
  final Note? note;
  const EditNoteScreen({super.key, this.note});

  @override
  State<EditNoteScreen> createState() => _EditNoteScreenState();
}

class _EditNoteScreenState extends State<EditNoteScreen> {
  final _titleController = TextEditingController();
  final _bodyController = TextEditingController();
  String _category = 'general';
  final _service = NotesService();

  @override
  void initState() {
    super.initState();
    if (widget.note != null) {
      _titleController.text = widget.note!.title;
      _bodyController.text = widget.note!.body;
      _category = widget.note!.category;
    }
  }

  Future<void> _save() async {
    if (_titleController.text.trim().isEmpty) return;
    if (widget.note != null) {
      await _service.update(widget.note!.id, title: _titleController.text, body: _bodyController.text, category: _category);
    } else {
      await _service.add(_titleController.text, _bodyController.text, _category);
    }
    if (mounted) Navigator.pop(context);
  }

  @override
  void dispose() {
    _titleController.dispose();
    _bodyController.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text(widget.note == null ? 'New Note' : 'Edit Note'),
        actions: [IconButton(icon: const Icon(Icons.save), onPressed: _save)],
      ),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          children: [
            TextField(controller: _titleController, decoration: const InputDecoration(labelText: 'Title', border: OutlineInputBorder())),
            const SizedBox(height: 12),
            DropdownButtonFormField<String>(
              value: _category,
              items: ['general', 'work', 'personal', 'ideas'].map((c) => DropdownMenuItem(value: c, child: Text(c))).toList(),
              onChanged: (v) => setState(() => _category = v!),
              decoration: const InputDecoration(labelText: 'Category', border: OutlineInputBorder()),
            ),
            const SizedBox(height: 12),
            Expanded(
              child: TextField(
                controller: _bodyController,
                maxLines: null,
                expands: true,
                decoration: const InputDecoration(labelText: 'Body', border: OutlineInputBorder(), alignLabelWithHint: true),
              ),
            ),
          ],
        ),
      ),
    );
  }
}
```

## ❌ Common Mistakes

```dart
// MISTAKE 1: Test mode in production
// → anyone can read/write database
// FIX: Proper security rules

// MISTAKE 2: snapshots() vs get() confusion
// One-time → get(), real-time → snapshots()

// MISTAKE 3: No null-safe defaults
title: data['title']  // null → crash
// FIX: data['title'] ?? ''

// MISTAKE 4: Composite query without index
.where('a').where('b').orderBy('c')  // → index required error
// FIX: Click error link, create index

// MISTAKE 5: Timestamp as DateTime directly
data['createdAt'] as DateTime  // ❌ it's Timestamp
// FIX: (data['createdAt'] as Timestamp).toDate()
```

## 🎯 Interview Tips

1. **Q: Firestore vs Realtime Database?**
   *A: Firestore — newer, better querying, structured collections. Realtime DB — simpler tree, faster sync.*

2. **Q: snapshots() kaise real-time work karta hai?**
   *A: WebSocket-like persistent connection. Server change push karta hai client ko.*

3. **Q: Security rules kab evaluate hote hain?**
   *A: Har request pe Firebase server pe — client bypass nahi kar sakta.*

4. **Q: Composite index kab chahiye?**
   *A: Multi-field query (multiple where + orderBy) pe. Console error me link milta hai.*
