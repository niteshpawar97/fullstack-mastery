# 🌅 HOUR 1 — CONCEPT

## Operators Kya Hote Hain?

Operator matlab ek **symbol** jo kuch operation perform karta hai — calculation, comparison, ya logical decision.

> **Socho Aise:** Calculator pe `+`, `-`, `*`, `/` buttons hote hain — ye sab operators hain. Code me bhi same thing — operators data pe action karte hain.

### 1. Arithmetic Operators (Math)

```dart
void main() {
  int a = 10;
  int b = 3;

  print(a + b);   // 13  (jod)
  print(a - b);   // 7   (ghata)
  print(a * b);   // 30  (gunaa)
  print(a / b);   // 3.3333333... (bhaag — double return karta hai)
  print(a ~/ b);  // 3   (integer division)
  print(a % b);   // 1   (remainder/modulo)
}
```

> **Yaad Rakho:** `/` always **double** deta hai (decimal). Integer chahiye to `~/` use karo. `%` modulo — even/odd check, FizzBuzz me kaam aata hai.

### 2. Comparison Operators (Tulna)

| Operator | Matlab | Example |
|----------|--------|---------|
| `==` | Equal | `5 == 5` → `true` |
| `!=` | Not equal | `5 != 3` → `true` |
| `>` | Greater than | `10 > 5` → `true` |
| `<` | Less than | `5 < 10` → `true` |
| `>=` | Greater or equal | `5 >= 5` → `true` |
| `<=` | Less or equal | `5 <= 5` → `true` |

```dart
void main() {
  int marks = 75;
  print(marks >= 60);  // true (pass)
  print(marks == 100); // false
}
```

### 3. Logical Operators (AND/OR/NOT)

| Operator | Matlab | Truth |
|----------|--------|-------|
| `&&` | AND | Dono true honge tabhi true |
| `\|\|` | OR | Koi ek true ho to true |
| `!` | NOT | true ko false aur false ko true |

```dart
void main() {
  bool hasMoney = true;
  bool hasTime = false;

  print(hasMoney && hasTime);  // false (movie nahi)
  print(hasMoney || hasTime);  // true (cinema chal sakte ho)
  print(!hasTime);             // true
}
```

> **Socho Aise:** Tum movie tabhi dekh sakte ho jab paisa **AND** time dono ho. Lekin dost ya tum me se koi free ho to mil sakte ho (**OR**).

### 4. Assignment Operators

```dart
void main() {
  int x = 10;
  x += 5;   // x = x + 5  → 15
  x -= 3;   // x = x - 3  → 12
  x *= 2;   // x = x * 2  → 24
  x ~/= 4;  // x = x ~/ 4 → 6
  print(x);
}
```

## Conditions — if / else / else if

```dart
void main() {
  int marks = 85;

  if (marks >= 90) {
    print('A+ grade');
  } else if (marks >= 75) {
    print('A grade');
  } else if (marks >= 60) {
    print('B grade');
  } else {
    print('Practice and karo');
  }
}
```

### Ternary Operator — Short if/else

```dart
void main() {
  int age = 18;

  // Long form
  String status;
  if (age >= 18) {
    status = 'Adult';
  } else {
    status = 'Minor';
  }

  // Short form (ternary)
  String statusShort = age >= 18 ? 'Adult' : 'Minor';
  print(statusShort);
}
```

> **Tip:** Ternary tabhi use karo jab ek line me decision ho. Multi-line logic ke liye normal if/else better.

### Switch-Case

```dart
void main() {
  String day = 'Monday';

  switch (day) {
    case 'Monday':
    case 'Tuesday':
    case 'Wednesday':
    case 'Thursday':
    case 'Friday':
      print('Working day');
      break;
    case 'Saturday':
    case 'Sunday':
      print('Weekend! 🎉');
      break;
    default:
      print('Galat din');
  }
}
```

> **Yaad Rakho:** `break` lagana zaroori hai, warna agla case bhi chal jayega ("fall-through"). `default` ko optional samjho — par best practice me always rakho.

## Loops — Bar Bar Karo

### 1. For Loop

```dart
void main() {
  // 1 se 5 tak print
  for (int i = 1; i <= 5; i++) {
    print('Number: $i');
  }
}
```

**Output:**
```
Number: 1
Number: 2
Number: 3
Number: 4
Number: 5
```

### 2. For-In Loop (List ke liye)

```dart
void main() {
  List<String> fruits = ['apple', 'banana', 'mango'];

  for (String fruit in fruits) {
    print('Fal: $fruit');
  }
}
```

### 3. While Loop

```dart
void main() {
  int count = 5;

  while (count > 0) {
    print('Countdown: $count');
    count--;
  }
  print('Blast off! 🚀');
}
```

### 4. Do-While Loop

```dart
void main() {
  int n = 10;

  do {
    print('Value: $n');
    n--;
  } while (n > 8);
}
```

> **Socho Aise:**
> - **for** = "5 baar daud lagao" (count pata hai)
> - **while** = "thak na jao tab tak daudo" (condition pe rukna hai)
> - **do-while** = "kam se kam ek baar to daudo" (pehle do, fir check)

### break Aur continue

```dart
void main() {
  for (int i = 1; i <= 10; i++) {
    if (i == 5) continue;  // 5 skip karo
    if (i == 8) break;     // 8 pe ruk jao
    print(i);              // 1 2 3 4 6 7
  }
}
```

## Task 1: FizzBuzz Classic (15 min)

**Rule:**
- 3 ke multiples pe → "Fizz"
- 5 ke multiples pe → "Buzz"
- Dono ke multiples pe → "FizzBuzz"
- Warna number print karo

```dart
void main() {
  for (int i = 1; i <= 30; i++) {
    if (i % 3 == 0 && i % 5 == 0) {
      print('FizzBuzz');
    } else if (i % 3 == 0) {
      print('Fizz');
    } else if (i % 5 == 0) {
      print('Buzz');
    } else {
      print(i);
    }
  }
}
```

> **Challenge:** 100 tak run karo. Phir condition ka order badal ke dekho — output kyu galat ho jata hai?

## Task 2: Pattern Printing — Triangle of Stars (15 min)

**Output goal:**
```
*
**
***
****
*****
```

```dart
void main() {
  int rows = 5;

  for (int i = 1; i <= rows; i++) {
    String line = '';
    for (int j = 1; j <= i; j++) {
      line += '*';
    }
    print(line);
  }
}
```

## Task 3: Find Min/Max in a List (15 min)

```dart
void main() {
  List<int> numbers = [42, 7, 91, 13, 56, 28, 84];

  int min = numbers[0];
  int max = numbers[0];

  for (int num in numbers) {
    if (num < min) min = num;
    if (num > max) max = num;
  }

  print('Min: $min');  // 7
  print('Max: $max');  // 91
  print('Range: ${max - min}');  // 84
}
```

> **Challenge:** Average bhi nikalo. Aur sabse zyada baar aane wala number (mode) bhi find karo.

## Task 4: Prime Number Checker (15 min)

```dart
void main() {
  int n = 17;
  bool isPrime = true;

  if (n < 2) {
    isPrime = false;
  } else {
    for (int i = 2; i <= n ~/ 2; i++) {
      if (n % i == 0) {
        isPrime = false;
        break;
      }
    }
  }

  print('$n is ${isPrime ? "prime" : "not prime"}');
}
```

## Task 5: Mini Calculator (10 min)

```dart
void main() {
  double a = 15;
  double b = 4;
  String operation = '*';

  double result;

  switch (operation) {
    case '+':
      result = a + b;
      break;
    case '-':
      result = a - b;
      break;
    case '*':
      result = a * b;
      break;
    case '/':
      if (b == 0) {
        print('Zero se divide nahi kar sakte!');
        return;
      }
      result = a / b;
      break;
    default:
      print('Unknown operation');
      return;
  }

  print('$a $operation $b = $result');
}
```

## ❌ Common Mistakes

```dart
// MISTAKE 1: == vs =
if (x = 5) { ... }
// FIX: if (x == 5) { ... }

// MISTAKE 2: switch me break bhulna
switch (day) {
  case 'Mon': print('Monday');  // No break!
  case 'Tue': print('Tuesday'); // Ye bhi chalega
}
// FIX: Har case ke baad break;

// MISTAKE 3: Infinite loop
int i = 0;
while (i < 10) {
  print(i);
  // i++ bhul gaye! Infinite loop!
}

// MISTAKE 4: Off-by-one
for (int i = 1; i < 10; i++)  // 1-9 print karega, 10 nahi
// Agar 1-10 chahiye: i <= 10
```

## 🎯 Interview Tips

1. **Q: `~/` aur `/` me kya farq?**
   *A: `/` double return karta hai (3/2 = 1.5), `~/` integer (3 ~/ 2 = 1).*

2. **Q: Ternary operator kab use karna chahiye?**
   *A: Single-line conditions ke liye. Nested ternary avoid karo — readability marti hai.*

3. **Q: `while` aur `do-while` me kya farq?**
   *A: `while` pehle condition check karta hai. `do-while` pehle body chalata hai, fir condition check.*
