# 🌅 HOUR 1 — CONCEPT

## Animations Kyu?

Smooth animations app ko **professional + delightful** banate hain. Static UI vs animated UI — same data, but feel completely different.

> **Socho Aise:** Movie aur slideshow me yahi farq hai. Slideshow me frames jump karte hain. Movie me smoothly transition. App me bhi same — instant change vs smooth animate.

---

## Implicit vs Explicit Animations

### Implicit Animations (Easy 80%)
Property change pe **automatic animate** — code minimal.

- `AnimatedContainer`
- `AnimatedOpacity`
- `AnimatedPadding`
- `AnimatedAlign`
- `AnimatedPositioned`

### Explicit Animations (Full Control 20%)
`AnimationController` + `Tween` — manual control, complex sequences.

> **Tip:** Beginner pehle implicit master karo — 80% cases me kaafi hai.

## AnimatedContainer

```dart
class _DemoState extends State<Demo> {
  bool _expanded = false;

  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onTap: () => setState(() => _expanded = !_expanded),
      child: AnimatedContainer(
        duration: const Duration(milliseconds: 500),
        curve: Curves.easeInOut,
        width: _expanded ? 300 : 100,
        height: _expanded ? 300 : 100,
        decoration: BoxDecoration(
          color: _expanded ? Colors.indigo : Colors.green,
          borderRadius: BorderRadius.circular(_expanded ? 50 : 8),
        ),
        child: const Center(child: Text('Tap me', style: TextStyle(color: Colors.white))),
      ),
    );
  }
}
```

> **Magic:** `setState` se property change → AnimatedContainer smoothly animate. Zero animation code likhna padta nahi.

## Curves — Animation Personality

| Curve | Feel |
|-------|------|
| `Curves.linear` | Constant speed (boring) |
| `Curves.easeIn` | Slow start, fast end |
| `Curves.easeOut` | Fast start, slow end |
| `Curves.easeInOut` | Slow-fast-slow (most natural) |
| `Curves.bounceOut` | Bouncy (fun) |
| `Curves.elasticOut` | Spring-like |
| `Curves.fastOutSlowIn` | Material default |

```dart
AnimatedContainer(
  duration: const Duration(milliseconds: 800),
  curve: Curves.bounceOut,
  ...
)
```

> **Use:** **`easeInOut`** safe default. **`bounceOut`** playful (kid apps). **`fastOutSlowIn`** Material design feel.

## TweenAnimationBuilder

Ek specific value range me animate karne ka shortcut:

```dart
TweenAnimationBuilder<double>(
  tween: Tween<double>(begin: 0, end: 1),
  duration: const Duration(milliseconds: 1000),
  curve: Curves.easeOut,
  builder: (context, value, child) {
    return Opacity(
      opacity: value,
      child: Transform.scale(scale: value, child: child),
    );
  },
  child: const Text('Animate!'),
)
```

> **Use:** Entry animations — page load pe smooth fade + scale.

## AnimationController + Tween (Explicit)

```dart
class _MyAnimState extends State<MyAnim> with SingleTickerProviderStateMixin {
  late AnimationController _controller;
  late Animation<double> _animation;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(
      duration: const Duration(seconds: 2),
      vsync: this,
    );
    _animation = Tween<double>(begin: 0, end: 1).animate(
      CurvedAnimation(parent: _controller, curve: Curves.easeInOut),
    );
    _controller.repeat(reverse: true);  // bounce repeatedly
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: _animation,
      builder: (context, child) => Transform.scale(
        scale: 1 + _animation.value * 0.5,
        child: child,
      ),
      child: const Icon(Icons.favorite, color: Colors.red, size: 60),
    );
  }
}
```

> **`with SingleTickerProviderStateMixin`** required hai — `vsync: this` ke liye. Multi-controller ho to `TickerProviderStateMixin`.

> **Critical:** `dispose()` me controller dispose karo.

## Task 1: Animated Splash Screen (15 min)

```dart
class SplashScreen extends StatefulWidget {
  const SplashScreen({super.key});

  @override
  State<SplashScreen> createState() => _SplashScreenState();
}

class _SplashScreenState extends State<SplashScreen> {
  double _opacity = 0;
  double _scale = 0.5;

  @override
  void initState() {
    super.initState();
    Future.delayed(const Duration(milliseconds: 200), () {
      setState(() {
        _opacity = 1;
        _scale = 1;
      });
    });
    Future.delayed(const Duration(seconds: 3), () {
      if (mounted) Navigator.pushReplacement(context, MaterialPageRoute(builder: (_) => const HomeScreen()));
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: Colors.indigo,
      body: Center(
        child: AnimatedOpacity(
          opacity: _opacity,
          duration: const Duration(milliseconds: 800),
          child: AnimatedScale(
            scale: _scale,
            duration: const Duration(milliseconds: 800),
            curve: Curves.easeOut,
            child: const Column(
              mainAxisAlignment: MainAxisAlignment.center,
              children: [
                Icon(Icons.flutter_dash, size: 100, color: Colors.white),
                SizedBox(height: 20),
                Text('Flutter App', style: TextStyle(color: Colors.white, fontSize: 28, fontWeight: FontWeight.bold)),
              ],
            ),
          ),
        ),
      ),
    );
  }
}

class HomeScreen extends StatelessWidget {
  const HomeScreen({super.key});
  @override
  Widget build(BuildContext context) =>
      Scaffold(appBar: AppBar(title: const Text('Home')), body: const Center(child: Text('Welcome!')));
}
```

class ColorCard extends StatefulWidget {
  const ColorCard({super.key});

  @override
  State<ColorCard> createState() => _ColorCardState();
}

class _ColorCardState extends State<ColorCard> {
  int _index = 0;
  final colors = [Colors.indigo, Colors.green, Colors.orange, Colors.red, Colors.purple];

  void _next() {
    setState(() => _index = (_index + 1) % colors.length);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: GestureDetector(
          onTap: _next,
          child: AnimatedContainer(
            duration: const Duration(milliseconds: 600),
            curve: Curves.easeInOut,
            width: 250,
            height: 250,
            decoration: BoxDecoration(
              color: colors[_index],
              borderRadius: BorderRadius.circular(_index.isEven ? 16 : 100),
              boxShadow: [
                BoxShadow(color: colors[_index].withOpacity(0.4), blurRadius: 20, offset: const Offset(0, 8)),
              ],
            ),
            child: const Center(
              child: Text('Tap me', style: TextStyle(color: Colors.white, fontSize: 24, fontWeight: FontWeight.bold)),
            ),
          ),
        ),
      ),
    );

class HeroListScreen extends StatelessWidget {
  HeroListScreen({super.key});

  final items = List.generate(5, (i) => {
    'id': i,
    'title': 'Item ${i + 1}',

  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Hero Gallery')),
      body: ListView.builder(
        itemCount: items.length,
        itemBuilder: (context, i) {
          final item = items[i];
          return ListTile(
            leading: Hero(
              tag: 'img-${item['id']}',
              child: ClipRRect(
                borderRadius: BorderRadius.circular(8),
                child: Image.network(item['image']! as String, width: 60, height: 60, fit: BoxFit.cover),
              ),

            title: Text(item['title']! as String),
            onTap: () => Navigator.push(
              context,
              MaterialPageRoute(builder: (_) => HeroDetailScreen(item: item)),

          );
        },
      ),
    );
  }
}

## Task 5: Pulsing Heart Icon (Explicit Animation) (15 min)

```dart
class PulsingHeart extends StatefulWidget {
  const PulsingHeart({super.key});

  @override
  State<PulsingHeart> createState() => _PulsingHeartState();
}

class _PulsingHeartState extends State<PulsingHeart> with SingleTickerProviderStateMixin {
  late AnimationController _controller;
  late Animation<double> _scale;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(duration: const Duration(milliseconds: 800), vsync: this);
    _scale = Tween<double>(begin: 1, end: 1.3).animate(
      CurvedAnimation(parent: _controller, curve: Curves.easeInOut),
    );
    _controller.repeat(reverse: true);
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Center(
      child: AnimatedBuilder(
        animation: _scale,
        builder: (context, child) => Transform.scale(scale: _scale.value, child: child),
        child: const Icon(Icons.favorite, color: Colors.red, size: 100),
      ),
    );
  }
}
```

## ❌ Common Mistakes

```dart
// MISTAKE 1: Duration zero ya negative
AnimatedContainer(duration: Duration.zero, ...)  // no animation
// FIX: at least 200ms

// MISTAKE 2: Hero same screen me 2 alag tags
Hero(tag: 'a')... Hero(tag: 'a')...  // ❌ duplicate

// MISTAKE 3: AnimatedSwitcher me key bhulna
child: _showA ? Text('A') : Text('B')  // ❌ same widget type
// FIX: Text('A', key: ValueKey('a')), Text('B', key: ValueKey('b'))

// MISTAKE 4: Controller dispose bhulna
AnimationController(...)  // memory leak
// FIX: dispose() me controller.dispose()

// MISTAKE 5: vsync without mixin
AnimationController(vsync: this)  // ❌ this nahi hai
// FIX: with SingleTickerProviderStateMixin
```

## 🎯 Interview Tips

1. **Q: Implicit aur explicit animations me kya farq?**
   *A: Implicit — property change pe auto animate (AnimatedContainer). Explicit — AnimationController + Tween se manual control.*

2. **Q: Hero animation kab nahi chalti?**
   *A: Tags match nahi karte, modal route, ya CustomTransitionPageRoute use kiya bina hero support.*

3. **Q: vsync kya hota hai?**
   *A: Vertical sync — animation framerate ke saath sync. `SingleTickerProviderStateMixin` provide karta hai.*

4. **Q: AnimationController dispose kyu zaroori?**
   *A: Native ticker resources hold karta hai — leak rokne ke liye dispose mandatory.*
