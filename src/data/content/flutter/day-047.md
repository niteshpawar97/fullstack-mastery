# 🌅 HOUR 1 — CONCEPT

## Apple Developer Account Setup

Required:
- **Mac** (required for iOS dev — no Windows/Linux build option)
- **Apple ID** with $99/year Developer Program ($99/year, vs Google's $25 one-time)
- **Xcode** latest version

Sign up: [developer.apple.com](https://developer.apple.com/programs/enroll/)

> **Approval:** 24-48 hours after payment.

---

## App Store Connect Setup

1. [appstoreconnect.apple.com](https://appstoreconnect.apple.com)
2. **My Apps** → **+** → **New App**
3. Fill:
   - **Platform:** iOS
   - **Name:** Food Ordering
   - **Bundle ID:** `com.yourname.foodordering` (must match Xcode)
   - **SKU:** unique identifier (`food-ord-001`)
4. **Create**

## Xcode Project Configuration

```bash
cd ios
```

### 3. Version + Build Number

```

Build: 1           # increment per upload
```

> **Build number** App Store me unique — har upload pe increment mandatory.

### 4. Display Name + Icon

- **Display Name:** Food Ordering
- **App Icon:** Assets.xcassets/AppIcon — 1024×1024 + various sizes

(Use `flutter_launcher_icons` Day 30 ka pattern)

## Upload to App Store Connect

### Option 1: Transporter App (Recommended)

1. Mac App Store se **Transporter** download (free)
2. Transporter open → drag `Runner.ipa` file
3. **Deliver** click
4. Upload progress → success

### Option 2: Xcode Organizer

```bash
open ios/Runner.xcworkspace
```

In Xcode → **Product → Archive** → wait → Organizer window opens.

Click **Distribute App** → **App Store Connect** → **Upload**.

### Option 3: Command Line (altool)

```bash
xcrun altool --upload-app -f build/ios/ipa/Runner.ipa \
  -u apple_id@email.com -p APP_SPECIFIC_PASSWORD
```

## TestFlight

App Store Connect → **My Apps → Food Ordering → TestFlight**:

### Internal Testing

- **Up to 100 testers** (Apple ID only)
- **Instant** — no review
- **90 days** valid per build

Add testers:
1. **Internal Testing** group create
2. Add user emails (must be Apple Developer team members)
3. Apple sends invite

### External Testing

- **Up to 10,000 testers**
- **First build pe Apple review** (~24h)
- Subsequent updates instant
- Public link share possible (no Apple ID required to receive invite)

Add testers:
1. **External Testing** group create
2. Add **What to Test** notes
3. Submit for **Beta App Review**
4. Approved → testers can install

---

## App Store Review

For **production release**:

App Store Connect → Food Ordering → **App Information**:

- **Category:** Food & Drink
- **Privacy Policy URL** (mandatory)
- **App Privacy** → data collection details
- **Pricing**
- **Localizations**

Add screenshots:
- iPhone 6.7" (1290×2796): minimum 3
- iPhone 5.5" (older devices): minimum 3
- iPad Pro 12.9" (2048×2732): if iPad supported

**Submit for Review**:

- Apple typically reviews in **24-48 hours**
- Common rejections: privacy, crash, mismatched description, payment violations
- Replies via Resolution Center

## Common Issues

### Provisioning Profile Issue

```
error: No matching provisioning profiles found
```

Fix:
- Xcode → Preferences → Accounts → re-sign-in
- "Automatically manage signing" toggle off + on

### Missing Compliance

iOS 16+ apps me **encryption declaration** zaroor:

`ios/Runner/Info.plist`:
```xml
<key>ITSAppUsesNonExemptEncryption</key>
<false/>
```

(Set `true` if you do custom encryption beyond HTTPS).

### Push Notifications Setup

For FCM:

1. Apple Developer → **Certificates, Identifiers** → APNs key generate
2. Download `.p8` file
3. Firebase Console → Project Settings → Cloud Messaging → APNs key upload

# 🌆 HOUR 2 — PRACTICE

## Task 1: Build + Upload IPA (30 min)

### Step 1: Configure Xcode

```bash
cd ios
open Runner.xcworkspace
```

- Bundle ID: `com.yourname.foodordering`
- Team: Select your developer team
- Version: `1.0.0`, Build: `1`

### Step 2: Build IPA

```bash
flutter build ipa --release
```

Wait 5-10 minutes. Output in `build/ios/ipa/`.

### Step 3: Upload via Transporter

1. Mac App Store → search **Transporter** → install
2. Sign in with Apple ID
3. Drag `Runner.ipa` to Transporter
4. **Deliver** → wait for processing (~10 min)

### Step 4: Verify in App Store Connect

- App Store Connect → Food Ordering → **TestFlight**
- Build appear hota hai with "Processing" status (~30-60 min)

---

## Task 2: Internal TestFlight (15 min)

### App Store Connect:

1. **TestFlight → Internal Testing → Create New Group**
2. **Group name:** "Internal Team"
3. **+ Testers:** add team member emails
4. **Builds → Add Build to Group** → select uploaded build

Apple sends invite emails. Tester:
1. Receives email "Test Food Ordering on TestFlight"
2. Click "Start Testing"
3. Opens TestFlight app on iPhone → app installs

> **Live updates:** Push new build → testers auto-notified.

---

## Task 3: External TestFlight (10 min)

For wider testers:

1. **TestFlight → External Testing → Create Group "Beta Testers"**
2. Add **What to Test** notes (Apple shows to testers)
3. Add tester emails OR enable **public link**
4. **Submit for Beta App Review** (24h Apple review)
5. Once approved → testers receive invite

---

## Task 4: Production Submission (10 min)

After TestFlight tests pass:

1. **App Information** → fill all required fields
2. **Pricing and Availability** → Free or Paid + countries
3. **App Privacy** → declare data usage
4. **Add for Review:**
   - Select build from TestFlight
   - Add release notes
   - Screenshots (5+ required)
   - Promotional text
5. **Submit for Review**

Wait 24-48h for Apple decision.

If approved → **Manual release** (you click) or **automatic** (publishes when approved).

## ❌ Common Mistakes

```yaml

# Xcode: com.example.foo
# App Store Connect: com.example.bar
# → upload fail
# FIX: Match exactly

# MISTAKE 2: Build number not incremented

# MISTAKE 5: Encryption declaration
```

## 🎯 Interview Tips

1. **Q: TestFlight Internal vs External difference?**
   *A: Internal — 100 testers, instant. External — 10K testers, first build needs review.*

2. **Q: Build number kyu increment karte ho?**
   *A: Apple unique IDs require karta hai. Same build me upload reject.*

   *A: Privacy policy missing, screenshots wrong size, mismatched description, crashes on launch.*
