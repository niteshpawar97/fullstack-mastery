# 🌅 HOUR 1 — CONCEPT

## Cubit vs Bloc — Recap

```dart
// CUBIT — methods directly emit
class CounterCubit extends Cubit<int> {
  CounterCubit() : super(0);
  void increment() => emit(state + 1);
}

// BLOC — events dispatch, handlers process
class CounterBloc extends Bloc<CounterEvent, int> {
  CounterBloc() : super(0) {
    on<CounterIncremented>((event, emit) => emit(state + 1));
    on<CounterDecremented>((event, emit) => emit(state - 1));
  }
}
```

> **When Bloc?** Bade apps me events ko log/audit karna ho, complex flows trace karne ho, ya team conventions me Bloc ho.

## Bloc Class — on<Event>() Handlers

```dart
sealed class LoginEvent {
  const LoginEvent();
}

class LoginRequested extends LoginEvent {
  final String email;
  final String password;
  const LoginRequested(this.email, this.password);
}

class LogoutRequested extends LoginEvent {}

class LoginBloc extends Bloc<LoginEvent, LoginState> {
  LoginBloc() : super(LoginInitial()) {
    on<LoginRequested>(_onLoginRequested);
    on<LogoutRequested>(_onLogoutRequested);
  }

  Future<void> _onLoginRequested(LoginRequested event, Emitter<LoginState> emit) async {
    emit(LoginLoading());
    try {
      await Future.delayed(const Duration(seconds: 1));
      if (event.email == 'admin@app.com' && event.password == 'admin123') {
        emit(LoginSuccess(event.email.split('@').first));
      } else {
        emit(const LoginFailure('Galat email ya password'));
      }
    } catch (e) {
      emit(LoginFailure(e.toString()));
    }
  }

  void _onLogoutRequested(LogoutRequested event, Emitter<LoginState> emit) {
    emit(LoginInitial());
  }
}
```

## BlocBuilder with Sealed States

```dart
BlocBuilder<LoginBloc, LoginState>(
  builder: (context, state) {
    return switch (state) {
      LoginInitial() => const Text('Please login'),
      LoginLoading() => const CircularProgressIndicator(),
      LoginSuccess(:final userName) => Text('Welcome, $userName!'),
      LoginFailure(:final error) => Text('Error: $error', style: const TextStyle(color: Colors.red)),
    };
  },
)
```

> **Magic:** Sealed classes me Dart compiler **all cases** force karta hai. Naya state add karoge to har `switch` me handle karna padega.

## BlocListener (Side Effects)

UI rebuild nahi chahiye, sirf side effect (snackbar, navigate)? Use `BlocListener`:

```dart
BlocListener<LoginBloc, LoginState>(
  listener: (context, state) {
    if (state is LoginSuccess) {
      Navigator.pushReplacement(context, MaterialPageRoute(builder: (_) => const HomeScreen()));
    } else if (state is LoginFailure) {
      ScaffoldMessenger.of(context).showSnackBar(SnackBar(content: Text(state.error)));
    }
  },
  child: SomeWidget(),
)
```

---

## BlocConsumer (Build + Listen Combined)

```dart
BlocConsumer<LoginBloc, LoginState>(
  listener: (context, state) {
    if (state is LoginSuccess) Navigator.pushReplacement(...);
    if (state is LoginFailure) ScaffoldMessenger.of(context).showSnackBar(...);
  },
  builder: (context, state) {
    return state is LoginLoading ? const Loader() : LoginForm();
  },
)
```

> **Tip:** `BlocConsumer` jab dono chahiye — UI rebuild + side effect. Most common pattern login screens me.

## Task 2: Login Bloc with BlocConsumer (45 min)

```dart
sealed class LoginEvent {
  const LoginEvent();
}

class LoginRequested extends LoginEvent {
  final String email;
  final String password;
  const LoginRequested(this.email, this.password);
}

class LogoutRequested extends LoginEvent {}

sealed class LoginState extends Equatable {
  const LoginState();
  @override
  List<Object?> get props => [];
}

class LoginInitial extends LoginState {}
class LoginLoading extends LoginState {}
class LoginSuccess extends LoginState {
  final String userName;
  const LoginSuccess(this.userName);
  @override
  List<Object> get props => [userName];
}
class LoginFailure extends LoginState {
  final String error;
  const LoginFailure(this.error);
  @override
  List<Object> get props => [error];
}

class LoginBloc extends Bloc<LoginEvent, LoginState> {
  LoginBloc() : super(LoginInitial()) {
    on<LoginRequested>(_onLoginRequested);
    on<LogoutRequested>((_, emit) => emit(LoginInitial()));
  }

  Future<void> _onLoginRequested(LoginRequested event, Emitter<LoginState> emit) async {
    emit(LoginLoading());
    try {
      await Future.delayed(const Duration(seconds: 1));

      if (event.email.isEmpty || event.password.isEmpty) {
        emit(const LoginFailure('Email aur password do'));
        return;
      }

      if (event.email == 'admin@app.com' && event.password == 'admin123') {
        emit(LoginSuccess(event.email.split('@').first));
      } else {
        emit(const LoginFailure('Galat email ya password'));
      }
    } catch (e) {
      emit(LoginFailure(e.toString()));
    }
  }
}

class LoginScreen extends StatelessWidget {
  const LoginScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return BlocProvider(
      create: (_) => LoginBloc(),
      child: const LoginView(),
    );
  }
}

class LoginView extends StatefulWidget {
  const LoginView({super.key});
  @override
  State<LoginView> createState() => _LoginViewState();
}

class _LoginViewState extends State<LoginView> {
  final _email = TextEditingController(text: 'admin@app.com');
  final _password = TextEditingController(text: 'admin123');

  @override
  void dispose() {
    _email.dispose();
    _password.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: BlocConsumer<LoginBloc, LoginState>(
        listener: (context, state) {
          if (state is LoginSuccess) {
            ScaffoldMessenger.of(context).showSnackBar(
              SnackBar(content: Text('Welcome ${state.userName}!'), backgroundColor: Colors.green),
            );
            // Navigator.pushReplacement to home in real app
          } else if (state is LoginFailure) {
            ScaffoldMessenger.of(context).showSnackBar(
              SnackBar(content: Text(state.error), backgroundColor: Colors.red),
            );
          }
        },
        builder: (context, state) {
          return SafeArea(
            child: Padding(
              padding: const EdgeInsets.all(24),
              child: Column(
                mainAxisAlignment: MainAxisAlignment.center,
                children: [
                  const Icon(Icons.lock, size: 80, color: Colors.indigo),
                  const SizedBox(height: 16),
                  const Text('Login Bloc Demo', style: TextStyle(fontSize: 28, fontWeight: FontWeight.bold)),
                  const SizedBox(height: 30),

                  // State branch UI
                  switch (state) {
                    LoginSuccess(:final userName) => _SuccessView(userName: userName),
                    _ => _FormView(emailController: _email, passwordController: _password, isLoading: state is LoginLoading),
                  },
                ],
              ),
            ),
          );
        },
      ),
    );
  }
}

class _SuccessView extends StatelessWidget {
  final String userName;
  const _SuccessView({required this.userName});

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        const Icon(Icons.check_circle, size: 80, color: Colors.green),
        const SizedBox(height: 16),
        Text('Welcome, $userName!', style: const TextStyle(fontSize: 24, fontWeight: FontWeight.bold)),
        const SizedBox(height: 24),
        ElevatedButton.icon(
          onPressed: () => context.read<LoginBloc>().add(LogoutRequested()),
          icon: const Icon(Icons.logout),
          label: const Text('Logout'),
        ),
      ],
    );
  }
}

class _FormView extends StatelessWidget {
  final TextEditingController emailController;
  final TextEditingController passwordController;
  final bool isLoading;

  const _FormView({required this.emailController, required this.passwordController, required this.isLoading});

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        TextField(controller: emailController, decoration: const InputDecoration(labelText: 'Email', border: OutlineInputBorder())),
        const SizedBox(height: 12),
        TextField(controller: passwordController, obscureText: true, decoration: const InputDecoration(labelText: 'Password', border: OutlineInputBorder())),
        const SizedBox(height: 16),
        SizedBox(
          width: double.infinity,
          child: ElevatedButton(
            onPressed: isLoading
                ? null
                : () => context.read<LoginBloc>().add(LoginRequested(emailController.text, passwordController.text)),
            style: ElevatedButton.styleFrom(padding: const EdgeInsets.symmetric(vertical: 14)),
            child: isLoading ? const CircularProgressIndicator(color: Colors.white) : const Text('LOGIN'),
          ),
        ),
      ],
    );
  }
}
```

> **Test:**
> - Default credentials → success state
> - Galat creds → failure state + snackbar
> - Empty fields → validation failure
> - Logout → wapas form

## 📋 Quick Revision

| Concept | Code |
|---------|------|
| Sealed event | `sealed class XEvent { const XEvent(); }` |
| Bloc class | `class XBloc extends Bloc<XEvent, XState>` |
| Handler | `on<EventClass>((event, emit) => emit(...))` |
| Dispatch | `context.read<XBloc>().add(EventName())` |
| Listen | `BlocListener` (no rebuild, side effects) |
| Build + listen | `BlocConsumer` |
| Pattern match | `switch (state) { case XState(): ... }` |

## ❌ Common Mistakes

```dart
// MISTAKE 1: emit outside handler
class Bloc { void method() { emit(...); } }  // ❌
// FIX: only inside on<Event>() handler

// MISTAKE 2: Sealed without props
class State extends Equatable { final int x; }
// → equality fails
// FIX: List<Object> get props => [x];

// MISTAKE 3: BlocListener without listener
BlocListener(listener: (c, s) {}, child: ...)  // empty listener no use
// FIX: actual side effect

// MISTAKE 4: Multiple Blocs without MultiBlocProvider
BlocProvider(create: ...)
  BlocProvider(create: ...)  // hard to manage
// FIX: MultiBlocProvider(providers: [...])
```

## 🎯 Interview Tips

1. **Q: Bloc vs Cubit kab use karna chahiye?**
   *A: Cubit — simple flows. Bloc — auditable events, complex state machines, team standards.*

2. **Q: Sealed classes ka benefit?**
   *A: Compile-time exhaustive checking — naya event/state add karoge to handler add karna padega.*

3. **Q: BlocListener vs BlocBuilder?**
   *A: Listener — side effects (no rebuild). Builder — UI rebuild on state change.*

4. **Q: Event-driven kyu? Method directly kyu nahi?**
   *A: Audit trail (logs), replay capability, decoupled UI from logic, easier testing.*
