# 🌅 HOUR 1 — CONCEPT

## Background Tasks Kya?

App **band hone ke baad bhi** kuch run karna ho — sync data, fetch updates, geofencing.

> **Socho Aise:** Tum so gaye, but ghadi automatically time update karti rehti hai. Background services bhi same — app sleep, kaam continue.

### Android vs iOS

| | Android | iOS |
|---|---------|-----|
| Periodic background | ✅ WorkManager | Limited (background fetch ~15 min minimum) |
| Foreground service | ✅ Persistent notification | Limited |
| Geofencing | ✅ | ✅ |
| Periodic data fetch | ✅ Every 15 min minimum | iOS deprioritize karta hai |

> **Reality:** Android me reliable. iOS pe **always-running** background tasks not allowed (battery savings).

## Setup — Top-level Function

```dart
import 'package:workmanager/workmanager.dart';

@pragma('vm:entry-point')
void callbackDispatcher() {
  Workmanager().executeTask((task, inputData) async {
    print('Task: $task');

    switch (task) {
      case 'syncData':
        await _syncWithServer();
        break;
      case 'sendStats':
        await _sendStats();
        break;
    }

    return Future.value(true);
  });
}

Future<void> _syncWithServer() async {
  // API call, DB sync
  await Future.delayed(const Duration(seconds: 5));
  print('Sync done at ${DateTime.now()}');
}

Future<void> _sendStats() async {
  print('Stats sent');
}
```

> **Critical:** `@pragma('vm:entry-point')` mandatory + **top-level function** (not class method).

```dart

  networkType: NetworkType.connected,       // unmetered (WiFi only)

  requiresCharging: false,                  // plugged in
  requiresDeviceIdle: false,                // user not using device
  requiresStorageNotLow: false,             // > 5% storage
```

# 🌆 HOUR 2 — PRACTICE

## Task 1: Periodic Sync (30 min)

### Setup main.dart

```dart
import 'package:flutter/material.dart';
import 'package:workmanager/workmanager.dart';
import 'package:shared_preferences/shared_preferences.dart';

@pragma('vm:entry-point')
void callbackDispatcher() {
  Workmanager().executeTask((task, inputData) async {
    final prefs = await SharedPreferences.getInstance();
    final count = (prefs.getInt('sync_count') ?? 0) + 1;
    await prefs.setInt('sync_count', count);
    await prefs.setString('last_sync', DateTime.now().toIso8601String());
    print('[BG] Sync #$count at ${DateTime.now()}');
    return true;
  });
}

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Workmanager().initialize(callbackDispatcher, isInDebugMode: true);
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});
  @override
  Widget build(BuildContext context) =>
      const MaterialApp(home: SyncScreen(), debugShowCheckedModeBanner: false);
}

class SyncScreen extends StatefulWidget {
  const SyncScreen({super.key});
  @override
  State<SyncScreen> createState() => _SyncScreenState();
}

class _SyncScreenState extends State<SyncScreen> {
  int _count = 0;
  String? _lastSync;
  bool _scheduled = false;

  @override
  void initState() {
    super.initState();
    _loadStats();
  }

  Future<void> _loadStats() async {
    final prefs = await SharedPreferences.getInstance();
    setState(() {
      _count = prefs.getInt('sync_count') ?? 0;
      _lastSync = prefs.getString('last_sync');
    });
  }

  Future<void> _schedulePeriodic() async {
    await Workmanager().registerPeriodicTask(
      'periodic-sync',
      'syncData',
      frequency: const Duration(minutes: 15),
      constraints: Constraints(networkType: NetworkType.connected),
    );
    setState(() => _scheduled = true);
  }

  Future<void> _scheduleOneOff() async {
    await Workmanager().registerOneOffTask(
      'one-off-${DateTime.now().millisecondsSinceEpoch}',
      'syncData',
      initialDelay: const Duration(seconds: 10),
    );
    ScaffoldMessenger.of(context).showSnackBar(const SnackBar(content: Text('Will run in 10 sec')));
  }

  Future<void> _cancelAll() async {
    await Workmanager().cancelAll();
    setState(() => _scheduled = false);
    ScaffoldMessenger.of(context).showSnackBar(const SnackBar(content: Text('All cancelled')));
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Background Sync'),
        actions: [IconButton(icon: const Icon(Icons.refresh), onPressed: _loadStats)],
      ),
      body: Padding(
        padding: const EdgeInsets.all(20),
        child: Column(
          children: [
            Card(
              child: ListTile(
                title: const Text('Sync Count'),
                trailing: Text('$_count', style: const TextStyle(fontSize: 24, fontWeight: FontWeight.bold)),
              ),
            ),
            Card(
              child: ListTile(
                title: const Text('Last Sync'),
                subtitle: Text(_lastSync ?? 'Never'),
              ),
            ),
            const SizedBox(height: 24),
            ElevatedButton(
              onPressed: _scheduleOneOff,
              child: const Text('Run Once After 10 sec'),
            ),
            const SizedBox(height: 12),
            ElevatedButton(
              onPressed: _schedulePeriodic,
              child: const Text('Schedule Periodic (15 min)'),
            ),
            const SizedBox(height: 12),
            OutlinedButton(
              onPressed: _cancelAll,
              child: const Text('Cancel All Tasks'),
            ),
            const SizedBox(height: 24),
            if (_scheduled) const Text('Periodic task scheduled — close app + wait', style: TextStyle(color: Colors.green)),
          ],
        ),
      ),
    );
  }
}
```

> **Test:**
> - One-off — wait 10 sec, console me log
> - Periodic — close app + 15 min wait, console me log dikhega next time open kar ke refresh karne pe
> - WiFi off karke → constraint nahi mil rahi → task delay

## ❌ Common Mistakes

```dart
// MISTAKE 1: callback class method
class X { void cb() {...} }  // ❌
// FIX: top-level function

// MISTAKE 2: @pragma missing
void cb() {...}  // works in dev, fails release
// FIX: @pragma('vm:entry-point')

// MISTAKE 3: Duration too short
frequency: const Duration(minutes: 5)  // ❌ Android min 15
// FIX: 15+ min

// MISTAKE 4: iOS expectations
// → 1-min periodic on iOS = unreliable
// FIX: BackgroundFetch package, accept iOS limitations
```

## 🎯 Interview Tips

1. **Q: Background task minimum interval?**
   *A: Android me 15 min (WorkManager). iOS me variable, system-decided.*

2. **Q: Foreground service vs background task?**
   *A: Foreground — persistent notification visible (music, GPS). Background — silent (WorkManager).*

3. **Q: iOS me background tasks reliable hain?**
   *A: Nahi — iOS battery-aware. Use BackgroundFetch package + accept system decides.*
