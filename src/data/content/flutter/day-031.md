# 🌅 HOUR 1 — CONCEPT

## Bloc Kya Hai?

Bloc = **B**usiness **Lo**gic **C**omponent — industry-standard state management pattern. Riverpod alternative.

> **Socho Aise:** Riverpod = scooter (fast, easy). Bloc = car (more setup but standardized — bade teams ke liye predictable).

### Bloc vs Cubit

- **Cubit:** Simpler — methods se state change (`increment()`, `decrement()`)
- **Bloc:** Event-driven — events dispatch, handlers process (more explicit but verbose)

> **Tip:** Beginners ke liye **Cubit** start point. Bloc events bad me sikho jab need ho.

## Cubit — State Management Class

```dart
import 'package:flutter_bloc/flutter_bloc.dart';

class CounterCubit extends Cubit<int> {
  CounterCubit() : super(0);   // initial state

  void increment() => emit(state + 1);
  void decrement() => emit(state - 1);
  void reset() => emit(0);
}
```

> **Pattern:** Cubit class generic `<int>` — state ka type. `super(0)` initial. `emit(...)` se state update.

## Immutable State Classes

Simple types (int, String) ke liye basic Cubit kaafi hai. Complex state ke liye **immutable class** banao:

```dart
import 'package:equatable/equatable.dart';

class TodoState extends Equatable {
  final List<String> todos;
  final bool loading;
  final String? error;

  const TodoState({
    this.todos = const [],
    this.loading = false,
    this.error,
  });

  TodoState copyWith({
    List<String>? todos,
    bool? loading,
    String? error,
  }) {
    return TodoState(
      todos: todos ?? this.todos,
      loading: loading ?? this.loading,
      error: error,
    );
  }

  @override
  List<Object?> get props => [todos, loading, error];
}
```

### Why Equatable?

`Equatable` se Bloc samajh sakta hai ki state actually change hua ya nahi. Same state emit karne pe **rebuild skip** hota hai (performance).

## Cubit with Complex State

```dart
class TodoCubit extends Cubit<TodoState> {
  TodoCubit() : super(const TodoState());

  Future<void> fetchTodos() async {
    emit(state.copyWith(loading: true, error: null));
    try {
      await Future.delayed(const Duration(seconds: 1));
      emit(state.copyWith(
        todos: ['Buy groceries', 'Learn Flutter', 'Coffee'],
        loading: false,
      ));
    } catch (e) {
      emit(state.copyWith(loading: false, error: e.toString()));
    }
  }

  void add(String todo) {
    emit(state.copyWith(todos: [...state.todos, todo]));
  }

  void remove(int index) {
    final newList = [...state.todos]..removeAt(index);
    emit(state.copyWith(todos: newList));
  }
}
```

## BlocBuilder Performance — buildWhen

```dart
BlocBuilder<TodoCubit, TodoState>(
  buildWhen: (previous, current) => previous.todos != current.todos,
  builder: (context, state) {
    return ListView.builder(
      itemCount: state.todos.length,
      itemBuilder: (_, i) => Text(state.todos[i]),
    );
  },
)
```

> **Why:** Loading state change pe list rebuild nahi hoga — sirf todos change pe.

## context.read vs context.watch (Bloc)

```dart
// Read once (in callbacks)
context.read<CounterCubit>().increment();

// Watch (rebuild on change) — alternative to BlocBuilder for simple cases
final count = context.watch<CounterCubit>().state;

// Select (rebuild on specific field)
final loading = context.select<TodoCubit, bool>((c) => c.state.loading);
```

## Task 2: Theme Cubit with Equatable State (20 min)

```dart
class ThemeState extends Equatable {
  final bool isDark;
  final Color primaryColor;

  const ThemeState({this.isDark = false, this.primaryColor = const Color(0xFF6366F1)});

  ThemeState copyWith({bool? isDark, Color? primaryColor}) {
    return ThemeState(
      isDark: isDark ?? this.isDark,
      primaryColor: primaryColor ?? this.primaryColor,
    );
  }

  @override
  List<Object> get props => [isDark, primaryColor];
}

class ThemeCubit extends Cubit<ThemeState> {
  ThemeCubit() : super(const ThemeState());

  void toggleDark() => emit(state.copyWith(isDark: !state.isDark));

  void setColor(Color color) => emit(state.copyWith(primaryColor: color));
}

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return BlocProvider(
      create: (_) => ThemeCubit(),
      child: BlocBuilder<ThemeCubit, ThemeState>(
        builder: (context, theme) => MaterialApp(
          themeMode: theme.isDark ? ThemeMode.dark : ThemeMode.light,
          theme: ThemeData(useMaterial3: true, colorScheme: ColorScheme.fromSeed(seedColor: theme.primaryColor)),
          darkTheme: ThemeData(useMaterial3: true, colorScheme: ColorScheme.fromSeed(seedColor: theme.primaryColor, brightness: Brightness.dark)),
          home: const ThemeScreen(),
        ),
      ),
    );
  }
}

class ThemeScreen extends StatelessWidget {
  const ThemeScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Theme Bloc')),
      body: Padding(
        padding: const EdgeInsets.all(20),
        child: Column(
          children: [
            BlocBuilder<ThemeCubit, ThemeState>(
              builder: (_, state) => SwitchListTile(
                title: const Text('Dark Mode'),
                value: state.isDark,
                onChanged: (_) => context.read<ThemeCubit>().toggleDark(),
              ),
            ),
            const SizedBox(height: 16),
            const Text('Primary Color', style: TextStyle(fontWeight: FontWeight.bold)),
            const SizedBox(height: 8),
            Wrap(
              spacing: 8,
              children: [Colors.indigo, Colors.green, Colors.red, Colors.amber, Colors.purple].map((c) {
                return GestureDetector(
                  onTap: () => context.read<ThemeCubit>().setColor(c),
                  child: CircleAvatar(backgroundColor: c, radius: 22),
                );
              }).toList(),
            ),
          ],
        ),
      ),
    );
  }
}
```

## Task 3: Todo Cubit with Loading + Error (25 min)

```dart
class TodoState extends Equatable {
  final List<String> todos;
  final bool loading;
  final String? error;

  const TodoState({this.todos = const [], this.loading = false, this.error});

  TodoState copyWith({List<String>? todos, bool? loading, String? error, bool clearError = false}) {
    return TodoState(
      todos: todos ?? this.todos,
      loading: loading ?? this.loading,
      error: clearError ? null : (error ?? this.error),
    );
  }

  @override
  List<Object?> get props => [todos, loading, error];
}

class TodoCubit extends Cubit<TodoState> {
  TodoCubit() : super(const TodoState()) {
    fetch();
  }

  Future<void> fetch() async {
    emit(state.copyWith(loading: true, clearError: true));
    try {
      await Future.delayed(const Duration(seconds: 1));
      emit(state.copyWith(
        todos: ['Flutter sikhna', 'Coffee peena', 'Code likhna'],
        loading: false,
      ));
    } catch (e) {
      emit(state.copyWith(loading: false, error: e.toString()));
    }
  }

  void add(String todo) {
    if (todo.trim().isEmpty) return;
    emit(state.copyWith(todos: [...state.todos, todo.trim()]));
  }

  void remove(int index) {
    final list = [...state.todos]..removeAt(index);
    emit(state.copyWith(todos: list));
  }

  void clear() => emit(state.copyWith(todos: []));
}

class TodoScreen extends StatelessWidget {
  const TodoScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return BlocProvider(
      create: (_) => TodoCubit(),
      child: const TodoView(),
    );
  }
}

class TodoView extends StatelessWidget {
  const TodoView({super.key});

  @override
  Widget build(BuildContext context) {
    final controller = TextEditingController();

    return Scaffold(
      appBar: AppBar(
        title: BlocBuilder<TodoCubit, TodoState>(
          buildWhen: (p, c) => p.todos.length != c.todos.length,
          builder: (_, state) => Text('Todos (${state.todos.length})'),
        ),
        actions: [
          IconButton(
            icon: const Icon(Icons.refresh),
            onPressed: () => context.read<TodoCubit>().fetch(),
          ),
        ],
      ),
      body: Column(
        children: [
          Padding(
            padding: const EdgeInsets.all(12),
            child: Row(
              children: [
                Expanded(
                  child: TextField(
                    controller: controller,
                    decoration: const InputDecoration(hintText: 'Naya todo', border: OutlineInputBorder()),
                    onSubmitted: (v) {
                      context.read<TodoCubit>().add(v);
                      controller.clear();
                    },
                  ),
                ),
              ],
            ),
          ),
          Expanded(
            child: BlocBuilder<TodoCubit, TodoState>(
              builder: (_, state) {
                if (state.loading) return const Center(child: CircularProgressIndicator());
                if (state.error != null) {
                  return Center(child: Text('Error: ${state.error}', style: const TextStyle(color: Colors.red)));
                }
                if (state.todos.isEmpty) return const Center(child: Text('Koi todo nahi'));

                return ListView.builder(
                  itemCount: state.todos.length,
                  itemBuilder: (_, i) => ListTile(
                    title: Text(state.todos[i]),
                    trailing: IconButton(
                      icon: const Icon(Icons.delete, color: Colors.red),
                      onPressed: () => context.read<TodoCubit>().remove(i),
                    ),
                  ),
                );
              },
            ),
          ),
        ],
      ),
    );
  }
}
```

## 📋 Quick Revision

| Concept | Code |
|---------|------|
| Setup | `flutter_bloc + equatable` |
| Cubit class | `class X extends Cubit<T> { X() : super(initial); }` |
| Update state | `emit(newState)` |
| Equatable state | `class State extends Equatable { props => [...] }` |
| copyWith | immutable updates |
| Inject | `BlocProvider(create: (_) => Cubit())` |
| Listen + rebuild | `BlocBuilder<Cubit, State>(builder: ...)` |
| Read once | `context.read<Cubit>()` |
| Watch | `context.watch<Cubit>().state` |
| Select | `context.select<Cubit, T>((c) => c.state.field)` |
| Optimize | `buildWhen: (p, c) => ...` |

## ❌ Common Mistakes

```dart
// MISTAKE 1: Mutable state
state.todos.add(todo);  // ❌ won't trigger rebuild
emit(state);            // same reference
// FIX: emit(state.copyWith(todos: [...state.todos, todo]));

// MISTAKE 2: Equatable bhulna
class State { final List todos; }  // can't compare
// FIX: extends Equatable + props override

// MISTAKE 3: BlocProvider scope galat
BlocProvider above MaterialApp.home? Sub-route me access?
// FIX: BlocProvider as high as needed in tree

// MISTAKE 4: read in build method
build() { context.read<X>().increment(); }  // ❌ infinite rebuild
// FIX: read sirf event handlers (onPressed) me
```

## 🎯 Interview Tips

1. **Q: Cubit aur Bloc me kya farq?**
   *A: Cubit method-based (simpler). Bloc event-based (more boilerplate, but explicit + auditable).*

2. **Q: Equatable kyu zaroori?**
   *A: State change detect karne ke liye. Same state emit pe rebuild skip — performance.*

3. **Q: Bloc vs Riverpod kab use karte ho?**
   *A: Bade teams + standardized patterns → Bloc. Solo + flexibility → Riverpod. Both production-grade.*

4. **Q: BlocBuilder vs Consumer (Provider)?**
   *A: Same concept — listen + rebuild on state change. Bloc adds buildWhen for fine control.*
