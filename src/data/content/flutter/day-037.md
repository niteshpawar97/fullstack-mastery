## AnimationController Recap (Day 19 Extended)

```dart
late AnimationController _controller;

@override
void initState() {
  super.initState();
  _controller = AnimationController(
    duration: const Duration(seconds: 2),
    vsync: this,
    lowerBound: 0,        // default 0
    upperBound: 1,        // default 1
  );
}

// Methods
_controller.forward();         // start
_controller.reverse();         // backwards
_controller.repeat();          // infinite loop
_controller.repeat(reverse: true);  // bounce
_controller.stop();
_controller.reset();
_controller.value = 0.5;       // jump to specific
```

## Curves — Easing

| Curve | Effect |
|-------|--------|
| `Curves.linear` | Constant speed |
| `Curves.easeIn` | Slow start |
| `Curves.easeOut` | Slow end |
| `Curves.easeInOut` | Smooth both sides |
| `Curves.bounceOut` | Bouncy |
| `Curves.elasticOut` | Spring |
| `Curves.fastOutSlowIn` | Material default |
| `Curves.decelerate` | Decelerating |

```dart
final animation = Tween<double>(begin: 0, end: 1).animate(
  CurvedAnimation(parent: _controller, curve: Curves.elasticOut),
);
```

## Staggered Animations

Multiple animations with **timing offsets**:

```dart
class _State extends State<Demo> with SingleTickerProviderStateMixin {
  late AnimationController _controller;
  late Animation<double> _opacity;
  late Animation<Offset> _slide;
  late Animation<double> _scale;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(duration: const Duration(seconds: 2), vsync: this);

    _opacity = Tween<double>(begin: 0, end: 1).animate(
      CurvedAnimation(parent: _controller, curve: const Interval(0, 0.4, curve: Curves.easeIn)),
    );

    _slide = Tween<Offset>(begin: const Offset(0, 0.3), end: Offset.zero).animate(
      CurvedAnimation(parent: _controller, curve: const Interval(0.2, 0.6, curve: Curves.easeOut)),
    );

    _scale = Tween<double>(begin: 0.5, end: 1).animate(
      CurvedAnimation(parent: _controller, curve: const Interval(0.4, 1.0, curve: Curves.elasticOut)),
    );

    _controller.forward();
  }

  @override
  Widget build(BuildContext context) {
    return AnimatedBuilder(
      animation: _controller,
      builder: (_, __) => Opacity(
        opacity: _opacity.value,
        child: SlideTransition(
          position: _slide,
          child: ScaleTransition(scale: _scale, child: const Icon(Icons.star, size: 100)),
        ),
      ),
    );
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }
}
```

> **Interval(0.2, 0.6)** — 20% se 60% time pe ye animation chalegi. Different intervals = staggered effect.

## Listening to Animation Status

```dart
_controller.addStatusListener((status) {
  if (status == AnimationStatus.completed) {
    _controller.reverse();
  } else if (status == AnimationStatus.dismissed) {
    _controller.forward();
  }
});
```

> **Use:** Auto bounce (forward → reverse → forward).

```dart
  late Animation<double> _scale;

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(duration: const Duration(milliseconds: 800), vsync: this);
    _scale = TweenSequence<double>([

  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Center(
      child: AnimatedBuilder(
        animation: _scale,
        builder: (_, child) => Transform.scale(scale: _scale.value, child: child),
        child: const Icon(Icons.favorite, color: Colors.red, size: 100),

    );
```

## Task 3: Staggered List Entry (20 min)

```dart
class StaggeredList extends StatefulWidget {
  const StaggeredList({super.key});
  @override
  State<StaggeredList> createState() => _StaggeredListState();
}

class _StaggeredListState extends State<StaggeredList> with SingleTickerProviderStateMixin {
  late AnimationController _controller;
  final items = ['Flutter', 'Dart', 'Bloc', 'Riverpod', 'Firebase', 'Get_it', 'Mocktail', 'Bloc'];

  @override
  void initState() {
    super.initState();
    _controller = AnimationController(duration: const Duration(milliseconds: 1500), vsync: this)..forward();
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  Animation<double> _itemAnimation(int index) {
    final start = index * 0.1;
    final end = (start + 0.5).clamp(0, 1.0);
    return CurvedAnimation(
      parent: _controller,
      curve: Interval(start, end as double, curve: Curves.easeOut),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Staggered List')),
      body: ListView.builder(
        padding: const EdgeInsets.all(16),
        itemCount: items.length,
        itemBuilder: (_, i) {
          final anim = _itemAnimation(i);
          return AnimatedBuilder(
            animation: anim,
            builder: (_, child) => Opacity(
              opacity: anim.value,
              child: Transform.translate(
                offset: Offset(50 * (1 - anim.value), 0),
                child: child,
              ),
            ),
            child: Card(
              child: ListTile(leading: const Icon(Icons.code), title: Text(items[i])),
            ),
          );
        },
      ),
    );
  }
}
```

## Task 4: Page Route Fade Transition (10 min)

```dart
class FadePageRoute<T> extends PageRouteBuilder<T> {
  final Widget page;

  FadePageRoute({required this.page})
      : super(
          pageBuilder: (_, __, ___) => page,
          transitionDuration: const Duration(milliseconds: 600),
          transitionsBuilder: (_, animation, __, child) {
            return FadeTransition(
              opacity: animation,
              child: ScaleTransition(
                scale: Tween<double>(begin: 0.95, end: 1).animate(
                  CurvedAnimation(parent: animation, curve: Curves.easeOut),
                ),
                child: child,
              ),
            );
          },
        );
}

// Use
```

## 🎯 Interview Tips

1. **Q: Implicit vs explicit animations?**
   *A: Implicit (AnimatedContainer) — auto on property change. Explicit — AnimationController + Tween for fine control.*

2. **Q: Curves performance impact?**
   *A: Minimal — math evaluation per frame. CPU me chalti hai, GPU pe nahi.*

3. **Q: Staggered animations kaise banate ho?**
   *A: Single AnimationController + multiple animations with `Interval` curves at different start/end.*
