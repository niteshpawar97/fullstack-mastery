# 🌅 HOUR 1 — CONCEPT

## Class Kya Hota Hai?

Class ek **blueprint** hai — ek template jisse **objects** banaye jate hain.

> **Socho Aise:** Mobile factory me ek **design** hota hai — kis size ka phone hoga, kya features honge. Wo design = **class**. Aur usse jo asli phones banate hain — wo = **objects** (instances). Ek class se hazaar phones ban sakte hain, har phone alag (different colors, owners) but structure same.

## Class Define Karna

```dart
class Person {
  // Properties (data)
  String name;
  int age;
  String city;

  // Constructor (object banane wala function)
  Person(this.name, this.age, this.city);

  // Method (kaam)
  void introduce() {
    print('Naam $name, umar $age, sheher $city');
  }
}

void main() {
  // Object banao
  Person p1 = Person('Ashutosh', 25, 'Lucknow');
  Person p2 = Person('Rohit', 30, 'Delhi');

  p1.introduce();  // Naam Ashutosh, umar 25, sheher Lucknow
  p2.introduce();  // Naam Rohit, umar 30, sheher Delhi
}
```

> **Yaad Rakho:** `this.name` shortcut hai — matlab `this.name = name` (constructor parameter ko property me assign karo).

## Named Constructor

Ek class ke multiple constructors ho sakte hain:

```dart
class Point {
  double x;
  double y;

  // Default constructor
  Point(this.x, this.y);

  // Named constructor
  Point.origin() : x = 0, y = 0;
  Point.onXAxis(double x) : this(x, 0);  // redirect to default
}

void main() {
  var p1 = Point(3, 4);
  var p2 = Point.origin();
  var p3 = Point.onXAxis(5);

  print('${p1.x}, ${p1.y}');  // 3.0, 4.0
  print('${p2.x}, ${p2.y}');  // 0.0, 0.0
  print('${p3.x}, ${p3.y}');  // 5.0, 0.0
}
```

> **Tip:** Flutter me `Color.fromARGB(...)`, `DateTime.now()`, `Duration(seconds: 5)` — sab named constructors hain.

## Getters Aur Setters

```dart
class Rectangle {
  double width;
  double height;

  Rectangle(this.width, this.height);

  // Getter — calculated property
  double get area => width * height;
  double get perimeter => 2 * (width + height);

  // Setter — value validation ke saath set
  set widthValue(double w) {
    if (w > 0) width = w;
    else print('Width positive hona chahiye');
  }
}

void main() {
  var r = Rectangle(5, 3);
  print(r.area);       // 15
  print(r.perimeter);  // 16

  r.widthValue = 10;
  print(r.area);       // 30

  r.widthValue = -5;   // Width positive hona chahiye
}
```

## Inheritance — `extends`

Ek class doosri class ke properties + methods inherit kar sakti hai.

```dart
class Animal {
  String name;
  int age;

  Animal(this.name, this.age);

  void eat() {
    print('$name khana kha raha hai');
  }

  void sleep() {
    print('$name so raha hai');
  }
}

class Dog extends Animal {
  String breed;

  Dog(String name, int age, this.breed) : super(name, age);

  void bark() {
    print('$name bhonk raha hai!');
  }
}

void main() {
  var d = Dog('Tommy', 3, 'Labrador');
  d.eat();   // Tommy khana kha raha hai (parent se)
  d.sleep(); // Tommy so raha hai (parent se)
  d.bark();  // Tommy bhonk raha hai! (apna)
  print(d.breed);  // Labrador
}
```

> **Socho Aise:** Inheritance ek family tree jaisa hai. Father (Animal) ke jo property hain (eat, sleep), wo son (Dog) ko automatically miljati hain. Beta apni properties (bark) bhi add kar sakta hai.

## Method Override — `@override`

Child class parent ke method ko **redefine** kar sakti hai:

```dart
class Animal {
  void makeSound() {
    print('Some sound');
  }
}

class Dog extends Animal {
  @override
  void makeSound() {
    print('Bhow bhow!');
  }
}

class Cat extends Animal {
  @override
  void makeSound() {
    print('Meow meow!');
  }
}

void main() {
  Animal a = Dog();  a.makeSound();  // Bhow bhow!
  Animal b = Cat();  b.makeSound();  // Meow meow!
}
```

> **Yaad Rakho:** `@override` annotation lagana best practice hai — compiler check karta hai ki tum sahi method override kar rahe ho. Typo se bachata hai.

## Abstract Class

**Abstract class** = ek aisi class jiska direct object nahi banta. Ye sirf **template** ka kaam karti hai — child classes implementation deti hain.

```dart
abstract class Shape {
  // Abstract method — implementation nahi
  double area();
  double perimeter();

  // Concrete method (with body) bhi ho sakta hai
  void describe() {
    print('Area: ${area()}, Perimeter: ${perimeter()}');
  }
}

class Circle extends Shape {
  double radius;
  Circle(this.radius);

  @override
  double area() => 3.14 * radius * radius;

  @override
  double perimeter() => 2 * 3.14 * radius;
}

class Square extends Shape {
  double side;
  Square(this.side);

  @override
  double area() => side * side;

  @override
  double perimeter() => 4 * side;
}

void main() {
  // var s = Shape();  // ❌ ERROR — abstract class
  Circle c = Circle(5);
  c.describe();  // Area: 78.5, Perimeter: 31.4

  Square sq = Square(4);
  sq.describe();  // Area: 16, Perimeter: 16
}
```

## Mixins — `with` Keyword

Mixin = ek class me **multiple "abilities"** add karne ka tareeka. Inheritance se zyada flexible.

```dart
mixin Swimmer {
  void swim() => print('Tair raha hai 🏊');
}

mixin Flyer {
  void fly() => print('Ud raha hai 🕊️');
}

mixin Runner {
  void run() => print('Daud raha hai 🏃');
}

class Duck with Swimmer, Flyer, Runner {
  String name;
  Duck(this.name);
}

class Fish with Swimmer {
  String name;
  Fish(this.name);
}

void main() {
  var donald = Duck('Donald');
  donald.swim();  // Tair raha hai
  donald.fly();   // Ud raha hai
  donald.run();   // Daud raha hai

  var nemo = Fish('Nemo');
  nemo.swim();    // Tair raha hai (sirf yahi mil sakta)
  // nemo.fly();  // ❌ Fish me Flyer mixin nahi hai
}
```

> **Socho Aise:** Mixin power-ups hain. Class ek "base character" hai (Mario), aur mixins use multiple abilities (jump, fire, fly) dete hain. Bina inheritance chain banaye.

> **Tip:** Inheritance "is-a" relation (Dog **is-a** Animal). Mixins "can-do" relation (Duck **can do** swim, fly).

## Constructor Initializer List

```dart
class Temperature {
  final double celsius;
  final double fahrenheit;

  // Initializer list
  Temperature.fromCelsius(this.celsius)
      : fahrenheit = celsius * 9 / 5 + 32;

  Temperature.fromFahrenheit(this.fahrenheit)
      : celsius = (fahrenheit - 32) * 5 / 9;
}

void main() {
  var t = Temperature.fromCelsius(25);
  print('${t.celsius}°C = ${t.fahrenheit}°F');  // 25°C = 77°F
}
```

## Task 1: Animal → Dog → Puppy Class Chain (20 min)

```dart
class Animal {
  String name;
  int age;

  Animal(this.name, this.age);

  void eat() => print('$name khana kha raha hai');
  void sleep() => print('$name so raha hai');
  void describe() => print('Naam: $name, Umar: $age');
}

class Dog extends Animal {
  String breed;

  Dog(String name, int age, this.breed) : super(name, age);

  void bark() => print('$name: Bhow bhow!');
}

class Puppy extends Dog {
  String favoriteToy;

  Puppy(String name, int age, String breed, this.favoriteToy)
      : super(name, age, breed);

  void play() => print('$name $favoriteToy se khel raha hai');

  @override
  void bark() => print('$name: Yip yip!');  // Puppies softer bark
}

void main() {
  var rex = Puppy('Rex', 1, 'Beagle', 'rubber bone');
  rex.describe();   // Naam: Rex, Umar: 1
  rex.eat();        // Rex khana kha raha hai
  rex.sleep();      // Rex so raha hai
  rex.bark();       // Rex: Yip yip! (overridden)
  rex.play();       // Rex rubber bone se khel raha hai
  print(rex.breed); // Beagle
}
```

## Task 2: Vehicle Abstract Class (20 min)

```dart
abstract class Vehicle {
  String name;
  int wheels;

  Vehicle(this.name, this.wheels);

  // Abstract methods
  void start();
  void stop();

  // Concrete method
  void describe() {
    print('$name has $wheels wheels');
  }
}

class Car extends Vehicle {
  Car(String name) : super(name, 4);

  @override
  void start() => print('$name engine start! Vroom vroom 🚗');

  @override
  void stop() => print('$name ruk gayi');
}

class Bike extends Vehicle {
  Bike(String name) : super(name, 2);

  @override
  void start() => print('$name kick maaro! 🏍️');

  @override
  void stop() => print('$name brake lagao');
}

class Truck extends Vehicle {
  double loadCapacity;

  Truck(String name, this.loadCapacity) : super(name, 6);

  @override
  void start() => print('$name diesel engine on 🚚');

  @override
  void stop() => print('$name parking me');

  @override
  void describe() {
    super.describe();
    print('Load capacity: $loadCapacity tons');
  }
}

void main() {
  Car swift = Car('Maruti Swift');
  swift.describe();
  swift.start();

  Bike royal = Bike('Royal Enfield');
  royal.describe();
  royal.start();

  Truck tata = Truck('Tata 1612', 10);
  tata.describe();
  tata.start();
}
```

## Task 4: Override Methods + Polymorphism (15 min)

```dart
abstract class Shape {
  String name;
  Shape(this.name);

  double area();

  void display() {
    print('$name area: ${area().toStringAsFixed(2)}');
  }
}

class Circle extends Shape {
  double radius;
  Circle(this.radius) : super('Circle');

  @override
  double area() => 3.14159 * radius * radius;
}

class Rectangle extends Shape {
  double width, height;
  Rectangle(this.width, this.height) : super('Rectangle');

  @override
  double area() => width * height;
}

class Triangle extends Shape {
  double base, height;
  Triangle(this.base, this.height) : super('Triangle');

  @override
  double area() => 0.5 * base * height;
}

void main() {
  List<Shape> shapes = [
    Circle(5),
    Rectangle(4, 6),
    Triangle(3, 4),
  ];

  for (Shape s in shapes) {
    s.display();
  }

  // Total area
  double total = shapes
      .map((s) => s.area())
      .reduce((a, b) => a + b);
  print('Total area: ${total.toStringAsFixed(2)}');
}
```

> **Polymorphism magic:** Sab `Shape` type me hain, par har ek apna `area()` calculate karta hai. Code clean + extensible.

## 🎯 Interview Tips

1. **Q: Inheritance aur Composition me kya farq?**
   *A: Inheritance "is-a" (Dog is-a Animal). Composition "has-a" (Car has-a Engine). Modern OOP composition ko prefer karta hai.*

2. **Q: Abstract class kab use karte hain?**
   *A: Jab template define karna ho but full implementation force na karni ho. Common methods inherit, specific methods child class ko define karna hai.*

3. **Q: Mixin aur Interface me kya farq?**
   *A: Mixin code reuse karta hai (with body). Interface sirf contract define karta hai (Dart me `implements`). Mixin = "ability share". Interface = "promise".*

4. **Q: `super` aur `this` me kya farq?**
   *A: `this` current object refer karta hai. `super` parent class refer karta hai (uska method ya constructor).*
