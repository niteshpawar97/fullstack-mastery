# 🌅 HOUR 1 — CONCEPT

## Null Safety — Dart Ki Superpower

### Null Kya Hota Hai?

`null` matlab "kuch nahi". Variable hai par usme value nahi.

```dart
String? name;  // ye null hai
print(name);   // null
```

> **Socho Aise:** `null` ek **khaali dabba** hai. Dabba hai (variable exists), par andar kuch nahi (value nahi). Agar tum khaali dabbe se kuch nikalne ki koshish karoge, to crash ho jayega — yahi hota hai "null pointer exception".

### Pre-Null-Safety Problem

Pehle Dart me koi bhi variable null ho sakta tha — jisse runtime crashes hote the. Ab Dart **null safe** hai.

```dart
// Default — non-nullable
String name = 'Ashutosh';
// name = null;  // ❌ ERROR — non-nullable

// Nullable type — `?` lagao
String? nickname;
nickname = null;  // ✅ Allowed
nickname = 'Ashu'; // ✅ Allowed
```

> **Yaad Rakho:** `String` aur `String?` alag types hain. `String` kabhi null nahi ho sakta. `String?` null ya value dono ho sakti hai.

## Null-Aware Operators

### 1. `??` — Default Value

```dart
void main() {
  String? name;  // null
  String displayName = name ?? 'Guest';
  print(displayName);  // Guest

  name = 'Ashutosh';
  String displayName2 = name ?? 'Guest';
  print(displayName2);  // Ashutosh
}
```

### 2. `?.` — Safe Method Call

```dart
void main() {
  String? name;
  print(name?.length);   // null (crash nahi hua)

  name = 'Ashutosh';
  print(name?.length);   // 8
  print(name.length);    // 8 (non-null hai to direct bhi chalega)
}
```

### 3. `!` — Bang Operator (Trust Me)

```dart
void main() {
  String? name = 'Ashutosh';

  // "Mujhe pakka pata hai ye null nahi hai"
  int len = name!.length;
  print(len);  // 8
}
```

> **Tip — Bang Operator Carefully Use Karo:** `!` use sirf tab karo jab tum 100% sure ho variable null nahi hai. Agar null hua to runtime crash hoga. `?.` aur `??` safer hain.

### 4. `??=` — Assign If Null

```dart
void main() {
  String? name;
  name ??= 'Default';   // null hai, to assign
  print(name);  // Default

  name ??= 'Other';     // already non-null, kuch nahi hoga
  print(name);  // Default
}
```

## Late Variable

```dart
class User {
  late String fullName;  // initialize bad me karenge

  void setName(String name) {
    fullName = name;
  }
}

void main() {
  var u = User();
  u.setName('Ashutosh');
  print(u.fullName);  // Ashutosh
}
```

> **Yaad Rakho:** `late` matlab "initialize ho jayega, par abhi nahi". Use sirf jab pakka ho ki access karne se pehle assign ho jayega.

## Collections

### 1. List

```dart
void main() {
  // Typed list
  List<int> numbers = [1, 2, 3, 4, 5];
  List<String> fruits = ['apple', 'banana', 'mango'];

  // Add/remove
  numbers.add(6);            // [1,2,3,4,5,6]
  numbers.remove(2);         // [1,3,4,5,6]
  numbers.removeAt(0);       // [3,4,5,6]
  numbers.insert(0, 100);    // [100,3,4,5,6]

  // Access
  print(numbers[0]);         // 100
  print(numbers.length);     // 5
  print(numbers.first);      // 100
  print(numbers.last);       // 6

  // Iterate
  for (int n in numbers) {
    print(n);
  }

  // Higher-order
  int total = numbers.reduce((a, b) => a + b);
  List<int> doubled = numbers.map((n) => n * 2).toList();
}
```

### 2. Set (Unique Items)

```dart
void main() {
  Set<String> tags = {'flutter', 'dart', 'mobile', 'flutter'};
  print(tags);  // {flutter, dart, mobile} — duplicate gaya

  tags.add('ios');
  tags.add('flutter');  // ignore — already hai
  print(tags);  // {flutter, dart, mobile, ios}

  print(tags.contains('dart'));  // true
}
```

> **Tip:** Jab unique values chahiye (tags, IDs), Set use karo. Faster lookup vs List.

### 3. Map (Key-Value)

```dart
void main() {
  Map<String, dynamic> user = {
    'name': 'Ashutosh',
    'age': 25,
    'isStudent': true,
    'hobbies': ['coding', 'reading'],
  };

  // Access
  print(user['name']);          // Ashutosh
  print(user['email']);         // null

  // Add/update
  user['email'] = 'ash@dev.in';
  user['age'] = 26;             // update

  // Remove
  user.remove('isStudent');

  // Iterate
  user.forEach((key, value) {
    print('$key: $value');
  });

  // Keys/values
  print(user.keys);
  print(user.values);
}
```

## Generics — `<T>`

Generics matlab **type ko parameter** banana — ek class/function multiple types ke liye reusable.

```dart
// Generic function
T firstItem<T>(List<T> list) {
  return list[0];
}

void main() {
  List<int> nums = [1, 2, 3];
  List<String> names = ['a', 'b'];

  print(firstItem<int>(nums));      // 1
  print(firstItem<String>(names));  // a
  // Type infer ho jata hai usually
  print(firstItem(nums));           // 1
}
```

### Generic Class

```dart
class Box<T> {
  T value;
  Box(this.value);

  void show() => print('Value: $value');
}

void main() {
  var intBox = Box<int>(42);
  var strBox = Box<String>('hello');
  var listBox = Box<List<int>>([1, 2, 3]);

  intBox.show();   // Value: 42
  strBox.show();   // Value: hello
  listBox.show();  // Value: [1, 2, 3]
}
```

> **Socho Aise:** Generics ek **container** hain jo kisi bhi type ke liye kaam kare. Jaise box me jewelry rakho ya khilona — box ka structure same, content alag. List<T> isi liye banta hai — same list code, sab types ke liye.

## Async / Await — Future Intro

Real apps me data API se aata hai, file padhna padta hai, ye sab **time leta hai**. Dart async-await pattern use karta hai.

### Future Kya Hai?

Future = ek **future me milne wali value**. Abhi nahi, kuch der baad.

```dart
Future<String> fetchUserName() async {
  // Pretend ye API call hai (2 sec lagega)
  await Future.delayed(Duration(seconds: 2));
  return 'Ashutosh';
}

void main() async {
  print('Fetching...');
  String name = await fetchUserName();
  print('Got: $name');
}
```

**Output:**
```
Fetching...   (immediately)
Got: Ashutosh (after 2 sec)
```

### Async / Await Rules

1. **`async`** function hamesha `Future` return karta hai
2. **`await`** se Future ke complete hone ka wait karte hain
3. `await` sirf `async` function ke andar use kar sakte ho

```dart
Future<int> add(int a, int b) async {
  await Future.delayed(Duration(milliseconds: 500));
  return a + b;
}

Future<void> main() async {
  print('Starting...');
  int result = await add(5, 3);
  print('Sum: $result');
  print('Done');
}
```

> **Yaad Rakho:** `await` ke bina Future use karoge to actual value nahi milegi — `Instance of Future<int>` aayega. Hamesha `await` lagao.

## Task 1: Nullable User Lookup (15 min)

```dart
class User {
  String name;
  String? email;
  String? phone;

  User(this.name, {this.email, this.phone});
}

String getUserContact(User user) {
  // Pehle email try karo, fir phone, warna fallback
  return user.email ?? user.phone ?? 'No contact';
}

void main() {
  var u1 = User('Ashutosh', email: 'ash@dev.in');
  var u2 = User('Rohit', phone: '9999988888');
  var u3 = User('Priya');

  print(getUserContact(u1));  // ash@dev.in
  print(getUserContact(u2));  // 9999988888
  print(getUserContact(u3));  // No contact

  // Null-aware method call
  print(u1.email?.length);  // 10
  print(u3.email?.length);  // null (no crash)
}
```

> **Challenge:** `User` me address bhi nullable add karo. Function jo agar kuch nahi mile to "Connect via app" return kare.

## Task 2: Generic List Utility (20 min)

```dart
T? firstWhere<T>(List<T> list, bool Function(T) predicate) {
  for (T item in list) {
    if (predicate(item)) return item;
  }
  return null;
}

List<R> myMap<T, R>(List<T> list, R Function(T) transform) {
  List<R> result = [];
  for (T item in list) {
    result.add(transform(item));
  }
  return result;
}

void main() {
  List<int> nums = [1, 2, 3, 4, 5];
  List<String> names = ['Ashu', 'Rohit', 'Priya'];

  // First even number
  int? evenNum = firstWhere(nums, (n) => n % 2 == 0);
  print(evenNum);  // 2

  // First name starting with 'P'
  String? pName = firstWhere(names, (n) => n.startsWith('P'));
  print(pName);  // Priya

  // Map int to String
  List<String> strNums = myMap(nums, (n) => 'Number $n');
  print(strNums);  // [Number 1, Number 2, ...]

  // Map String to length
  List<int> lengths = myMap(names, (n) => n.length);
  print(lengths);  // [4, 5, 5]
}
```

## Task 3: Future.delayed Demo — Loading Simulation (15 min)

```dart
Future<List<String>> fetchPosts() async {
  print('Fetching posts...');
  await Future.delayed(Duration(seconds: 2));
  return ['Post 1', 'Post 2', 'Post 3'];
}

Future<String> fetchUser(int id) async {
  await Future.delayed(Duration(milliseconds: 800));
  return 'User #$id';
}

Future<void> main() async {
  print('Start');

  // Sequential
  List<String> posts = await fetchPosts();
  print('Posts: $posts');

  String user = await fetchUser(42);
  print('User: $user');

  // Parallel — Future.wait
  print('\nParallel fetch:');
  Stopwatch sw = Stopwatch()..start();
  var results = await Future.wait([
    fetchUser(1),
    fetchUser(2),
    fetchUser(3),
  ]);
  print('All users: $results');
  print('Time: ${sw.elapsedMilliseconds}ms');  // ~800ms (parallel!)

  print('Done');
}
```

> **Tip:** `Future.wait()` se multiple futures parallel chalte hain — total time = slowest future ka time, sum nahi.

## Task 4: JSON-like Map Operations (20 min)

```dart
void main() {
  // Sample API response
  Map<String, dynamic> response = {
    'status': 'success',
    'user': {
      'id': 42,
      'name': 'Ashutosh',
      'email': 'ash@dev.in',
      'address': null,
    },
    'posts': [
      {'id': 1, 'title': 'Flutter Day 1', 'likes': 25},
      {'id': 2, 'title': 'Dart Basics', 'likes': 18},
      {'id': 3, 'title': 'OOP Concepts', 'likes': 32},
    ],
  };

  // Safe nested access
  String? userName = response['user']?['name'];
  String? address = response['user']?['address'];

  print('User: $userName');                    // Ashutosh
  print('Address: ${address ?? "Not set"}');   // Not set

  // Posts process
  List posts = response['posts'] as List;

  // Total likes
  int totalLikes = posts
      .map((p) => p['likes'] as int)
      .reduce((a, b) => a + b);
  print('Total likes: $totalLikes');  // 75

  // Top post
  var topPost = posts.reduce((a, b) =>
      (a['likes'] as int) > (b['likes'] as int) ? a : b);
  print('Top post: ${topPost['title']} (${topPost['likes']} likes)');

  // Filter posts with likes > 20
  var popular = posts.where((p) => (p['likes'] as int) > 20).toList();
  print('Popular: ${popular.length} posts');
}
```

> **Challenge:** Posts ko `likes` ke descending order me sort karo. Hint: `posts.sort((a, b) => b['likes'] - a['likes']);`

class Box<T> {

}

## ❌ Common Mistakes

```dart
// MISTAKE 1: Bang on null
String? name;
int len = name!.length;  // ❌ Runtime crash

// MISTAKE 2: await bhulna
String name = fetchName();  // ❌ Future hai, value nahi
// FIX: String name = await fetchName();

// MISTAKE 3: async function me return type galat
String fetch() async { ... }  // ❌
// FIX: Future<String> fetch() async { ... }

// MISTAKE 4: List type mismatch
List<int> nums = [1, 2, 'three'];  // ❌ ERROR

// MISTAKE 5: Map me galat type cast
Map<String, dynamic> data = {...};

```

## 🎯 Interview Tips

1. **Q: Null safety kya benefit deta hai?**
   *A: Compile-time pe null pointer exceptions catch hote hain. Runtime crashes drastically kam.*

2. **Q: `late` aur `?` me kya farq?**
   *A: `late` non-null guarantee deta hai (initialize hone tak access ban). `?` nullable banata hai (null bhi allowed).*

3. **Q: List aur Set me kya farq?**
   *A: List ordered + duplicates allowed. Set unordered + unique only.*

4. **Q: Generics kyu use karte hain?**
   *A: Type-safe + reusable code. Same logic multiple types ke liye, bina type cast.*

5. **Q: Future aur async-await kya hai?**
   *A: Future = future value placeholder. async-await us value ko clean syntax me handle karta hai (callbacks ki jagah).*
