# 🌅 HOUR 1 — CONCEPT

## Flutter Aakhirkar Kya Hai?

Flutter ek **UI toolkit** hai jo Google ne banaya — ek codebase se Android, iOS, Web, Desktop sab pe app chal sakti hai.

> **Socho Aise:** Pehle ek developer ko Android ke liye Java/Kotlin sikhna padta tha, iOS ke liye Swift, web ke liye React. Teen alag teams, teen alag codebases. Flutter ne kaha — "**ek code likho, sab platforms pe chalao**". Time + paisa dono bachata hai.

### Flutter Architecture (Simplified)

```
Tumhara Code (Dart)
       ↓
Flutter Framework (Widgets)
       ↓
Flutter Engine (Skia/Impeller — graphics)
       ↓
Platform (Android/iOS/Web/Desktop)
```

> **Yaad Rakho:** Flutter native UI components use nahi karta — apna khud ka rendering engine hai. Isi liye design pixel-perfect rehta hai sab platforms pe.

## `flutter create` — Naya App Banao

```bash
# Naya project banao
flutter create my_first_app

# Project me jao
cd my_first_app

# Run karo
flutter run
```

### Project Folder Structure

```
my_first_app/
├── android/         ← Android-specific code (Kotlin/Gradle)
├── ios/             ← iOS-specific code (Swift/Xcode)
├── lib/             ← Tumhara Dart code yahan
│   └── main.dart    ← Entry point
├── test/            ← Tests yahan
├── pubspec.yaml     ← Dependencies (npm package.json jaisa)
├── .gitignore
└── README.md
```

> **Tip:** **`lib/`** folder me hi tumhara saara Dart code rahega. `android/` aur `ios/` ko sirf platform-specific config ke liye chedo.

## `main.dart` — Entry Point

Default counter app:

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Flutter Demo',
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.deepPurple),
        useMaterial3: true,
      ),
      home: const MyHomePage(title: 'Flutter Demo Home Page'),
    );
  }
}
```

### Step-by-Step Breakdown

1. **`import 'package:flutter/material.dart';`** — Flutter ka Material Design library import
2. **`void main()`** — entry point (Dart program ka start)
3. **`runApp(...)`** — Flutter ko bolta hai "ye widget render karo"
4. **`MyApp extends StatelessWidget`** — root widget
5. **`build(...)`** — har widget me hota hai, UI return karta hai
6. **`MaterialApp`** — Material Design wrapper
7. **`MyHomePage`** — actual screen content

## Hot Reload vs Hot Restart vs Stop+Run

Flutter ka **superpower** — code change karte hi UI me dikhta hai (without losing app state).

| Action | Shortcut | Kya Karta Hai | Speed |
|--------|----------|---------------|-------|
| **Hot Reload** | `r` (terminal) / Save in IDE | Sirf UI rebuild, state same | < 1 sec ⚡ |
| **Hot Restart** | `R` (terminal) | Full app restart, state reset | ~3 sec |
| **Stop + Run** | `q` then `flutter run` | Full reinstall | ~30 sec |

> **Socho Aise:** Hot Reload ek **paint-job** hai (sirf dikhna change). Hot Restart **factory reset** hai (saari memory clear). Stop+Run = pura ghar dobara banao.

### Kab Kya Use Karna

- **Hot Reload (default)**: UI tweaks, color change, text edit
- **Hot Restart**: Initial state, `main()` me change, global variables
- **Stop + Run**: New package add, `pubspec.yaml` change, native config

## Android Emulator Setup

### Option 1: Android Studio Virtual Device

1. Android Studio install karo
2. **More Actions → Virtual Device Manager**
3. **Create Device** → Pixel 7 Pro select → API 34 (or latest)
4. **Finish** → Emulator boot karo
5. `flutter devices` me dikhna chahiye

### Option 2: Real Android Device (USB Debug)

1. Phone me **Settings → About → Build Number 7 baar tap** (Developer options on)
2. **Settings → Developer Options → USB Debugging ON**
3. USB cable se PC connect karo
4. Phone pe "Allow USB debugging" allow karo
5. `flutter devices` me dikhega

```bash
# Devices list
flutter devices

# Run on specific device
flutter run -d emulator-5554
flutter run -d <device-id>
```

> **Tip:** Real device pe testing **always better** — emulator slow hota hai, asli phone fast aur realistic.

## Task 3: Hot Reload Live Demo (15 min)

App running rakho. `lib/main.dart` me find karo:

```dart
appBar: AppBar(
  backgroundColor: Theme.of(context).colorScheme.inversePrimary,
  title: Text(widget.title),
),
```

**Series of changes:**

1. `Text(widget.title)` → `Text('My App!')`. **Save** → instant change
2. AppBar me background color change karo: `backgroundColor: Colors.amber`
3. Body ke text style change karo: `Theme.of(context).textTheme.headlineMedium`
4. Counter ke initial value: `int _counter = 100;` → save → **kuch hua?**

**Observation:** Counter purana value pe stuck rahega kyunki Hot Reload state preserve karta hai!

5. Terminal me **`R`** press karo (capital R — Hot Restart) → counter ab 100 se start hoga

> **Yaad Rakho:** State badalna ho to **Hot Restart**. Sirf UI tweak ho to **Hot Reload** kaafi hai.

## Task 5: Counter App Customize (15 min)

```dart
// _MyHomePageState me ye change karo
int _counter = 0;
String _message = 'Click karo!';

void _incrementCounter() {
  setState(() {
    _counter++;
    if (_counter == 5) {
      _message = 'Wah! 5 baar';
    } else if (_counter == 10) {
      _message = 'Speed up!';
    } else if (_counter > 20) {
      _message = 'Bohot ho gaya 😄';
    }
  });
}

// build me
Center(
  child: Column(
    mainAxisAlignment: MainAxisAlignment.center,
    children: <Widget>[
      Text(
        '$_counter',
        style: TextStyle(fontSize: 64, fontWeight: FontWeight.bold),
      ),
      const SizedBox(height: 20),
      Text(
        _message,
        style: TextStyle(fontSize: 20, color: Colors.indigo),
      ),
    ],
  ),
),
```

> **Save → Hot Reload → Test karo!**

> **Challenge:** Reset button add karo jo counter wapas 0 kare. (Hint: `FloatingActionButton` ek aur add karo, ya AppBar me `actions:` me icon).

## ❌ Common Mistakes

1. **`pubspec.yaml` me indentation tab use karna** — YAML sirf spaces (2) accept karta hai
2. **Real device pe USB debugging on bhulna** — `flutter devices` me empty list aati hai
3. **Hot Reload se state change expect karna** — initial values change ke liye Hot Restart chahiye
4. **`flutter run` ke baad terminal close kar dena** — app stop ho jata hai
5. **Material Design import bhulna** — `import 'package:flutter/material.dart';` zaroori

---

## 🎯 Interview Tips

1. **Q: Hot Reload aur Hot Restart me kya farq?**
   *A: Hot Reload sirf UI tree rebuild karta hai (state same). Hot Restart full app restart (state reset).*

2. **Q: Flutter native UI components use karta hai?**
   *A: Nahi — Skia/Impeller engine se khud render karta hai. Isi liye sab platforms pe pixel-perfect.*

3. **Q: `pubspec.yaml` ka kya kaam?**
   *A: Project metadata + dependencies + assets define karta hai. npm `package.json` jaisa.*

4. **Q: `runApp()` kya karta hai?**
   *A: Given widget ko root attach karta hai aur Flutter ko UI render karne ko bolta hai.*
