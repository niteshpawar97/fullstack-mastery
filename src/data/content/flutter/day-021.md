# 🌅 HOUR 1 — CONCEPT

## Riverpod Kya Hai?

Riverpod = **Provider's evolved version**. Same author (Remi Rousselet), but better:

- ✅ **Compile-time safe** (no `ProviderNotFoundException`)
- ✅ **No BuildContext** required to read providers
- ✅ **Easy to test** (override providers)
- ✅ **Auto-dispose** support
- ✅ **AsyncValue** — built-in loading/data/error states

> **Socho Aise:** Provider = ek **purani car** jo chal rahi hai. Riverpod = **same car ka 2024 model** — better safety, better mileage, modern features.

## Provider Types — 5 Main

### 1. Provider (Read-only)

```dart
final greetingProvider = Provider<String>((ref) {
  return 'Hello, Flutter!';
});

// Use
class MyWidget extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final greeting = ref.watch(greetingProvider);
    return Text(greeting);
  }
}
```

### 2. StateProvider (Simple Mutable)

```dart
final counterProvider = StateProvider<int>((ref) => 0);

// Read
final count = ref.watch(counterProvider);

// Update
ref.read(counterProvider.notifier).state++;
ref.read(counterProvider.notifier).state = 10;
```

> **Use:** Simple values like int, bool, string.

### 3. FutureProvider (Async Data)

```dart
final userProvider = FutureProvider<User>((ref) async {
  final response = await http.get(Uri.parse('https://api.example.com/user/1'));
  return User.fromJson(jsonDecode(response.body));
});

// Use
class UserWidget extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final userAsync = ref.watch(userProvider);

    return userAsync.when(
      data: (user) => Text('Hi, ${user.name}'),
      loading: () => const CircularProgressIndicator(),
      error: (e, stack) => Text('Error: $e'),
    );
  }
}
```

> **Magic:** `AsyncValue.when()` — loading/data/error states automatically handle.

### 4. StreamProvider (Real-time)

```dart
final timerProvider = StreamProvider<int>((ref) {
  return Stream.periodic(const Duration(seconds: 1), (i) => i);
});
```

### 5. StateNotifierProvider (Complex State)

```dart
class TodoNotifier extends StateNotifier<List<String>> {
  TodoNotifier() : super([]);

  void add(String todo) {
    state = [...state, todo];  // immutable
  }

  void remove(int index) {
    state = [...state]..removeAt(index);
  }

  void clear() {
    state = [];
  }
}

final todosProvider = StateNotifierProvider<TodoNotifier, List<String>>((ref) {
  return TodoNotifier();
});

// Use
final todos = ref.watch(todosProvider);
ref.read(todosProvider.notifier).add('Task 1');
```

> **Yaad Rakho:** Riverpod me **immutable state** — `state = [...]` use karo, direct mutate (`state.add(x)`) mat karo.

## ConsumerWidget vs Consumer

### ConsumerWidget (Whole widget rebuilds)

```dart
class MyWidget extends ConsumerWidget {
  const MyWidget({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final count = ref.watch(counterProvider);
    return Text('$count');
  }
}
```

### Consumer (Partial rebuild)

```dart
Column(
  children: [
    const Text('Static text'),
    Consumer(
      builder: (context, ref, child) {
        final count = ref.watch(counterProvider);
        return Text('$count');
      },
    ),
  ],
)
```

> **Use:** Performance ke liye `Consumer` — sirf needed widget rebuild.

## ref.watch / ref.read / ref.listen

| Method | Use |
|--------|-----|
| `ref.watch(p)` | Listen + rebuild on change |
| `ref.read(p)` | Sirf current value (no listen) |
| `ref.listen(p, callback)` | Side effect on change (snackbar, navigate) |

```dart
class _ScreenState extends ConsumerState<Screen> {
  @override
  Widget build(BuildContext context) {
    // Side effect — login success pe navigate
    ref.listen<AuthState>(authProvider, (previous, next) {
      if (next is Authenticated) {
        Navigator.pushReplacement(context, MaterialPageRoute(builder: (_) => const HomeScreen()));
      }
    });

    final auth = ref.watch(authProvider);
    return Scaffold(...);
  }
}
```

## AsyncValue.when() Patterns

```dart
final usersAsync = ref.watch(usersProvider);

// Pattern 1: Standard
return usersAsync.when(
  data: (users) => ListView(children: users.map((u) => Text(u.name)).toList()),
  loading: () => const Center(child: CircularProgressIndicator()),
  error: (e, stack) => Center(child: Text('Error: $e')),
);

// Pattern 2: Custom default
return usersAsync.maybeWhen(
  data: (users) => UserList(users: users),
  orElse: () => const Loader(),
);

// Pattern 3: Direct check
if (usersAsync.isLoading) return Loader();
if (usersAsync.hasError) return ErrorView();
return UserList(users: usersAsync.value!);
```

## family Modifier — Parameterized

```dart
final userProvider = FutureProvider.family<User, int>((ref, userId) async {
  final response = await http.get(Uri.parse('https://api.example.com/user/$userId'));

});

// Use
final user1 = ref.watch(userProvider(1));   // user 1

```

import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';

            onPressed: () => ref.read(counterProvider.notifier).state = 0,

          ),
          const SizedBox(width: 8),
          FloatingActionButton(
            heroTag: 'plus',
            onPressed: () => ref.read(counterProvider.notifier).state++,

    );
  }
}

## Task 2: Async Data with FutureProvider (20 min)

```dart
import 'dart:convert';
import 'package:http/http.dart' as http;

class Post {
  final int id;
  final String title;
  Post({required this.id, required this.title});

  factory Post.fromJson(Map<String, dynamic> j) => Post(id: j['id'], title: j['title']);
}

final postsProvider = FutureProvider<List<Post>>((ref) async {
  final response = await http.get(Uri.parse('https://jsonplaceholder.typicode.com/posts'));
  if (response.statusCode != 200) throw Exception('Failed');
  final List data = jsonDecode(response.body);
  return data.take(20).map((j) => Post.fromJson(j)).toList();
});

class PostsScreen extends ConsumerWidget {
  const PostsScreen({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final postsAsync = ref.watch(postsProvider);

    return Scaffold(
      appBar: AppBar(
        title: const Text('Posts (Riverpod)'),
        actions: [
          IconButton(
            icon: const Icon(Icons.refresh),
            onPressed: () => ref.invalidate(postsProvider),  // re-fetch
          ),
        ],
      ),
      body: postsAsync.when(
        data: (posts) => RefreshIndicator(
          onRefresh: () async => ref.invalidate(postsProvider),
          child: ListView.builder(
            itemCount: posts.length,
            itemBuilder: (_, i) => ListTile(
              leading: CircleAvatar(child: Text('${posts[i].id}')),
              title: Text(posts[i].title),
            ),
          ),
        ),
        loading: () => const Center(child: CircularProgressIndicator()),
        error: (e, stack) => Center(
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            children: [
              const Icon(Icons.error, size: 60, color: Colors.red),
              Text('Error: $e'),
              const SizedBox(height: 16),
              ElevatedButton(
                onPressed: () => ref.invalidate(postsProvider),
                child: const Text('Retry'),
              ),
            ],
          ),
        ),
      ),
    );
  }
}
```

> **`ref.invalidate(provider)`** — provider ko re-evaluate kara ke fresh data fetch.

## Task 3: Todo List with StateNotifier (30 min)

```dart
class Todo {
  final String id;
  final String title;
  final bool done;

  const Todo({required this.id, required this.title, this.done = false});

  Todo copyWith({String? title, bool? done}) {
    return Todo(id: id, title: title ?? this.title, done: done ?? this.done);
  }
}

class TodoNotifier extends StateNotifier<List<Todo>> {
  TodoNotifier() : super([]);

  void add(String title) {
    if (title.trim().isEmpty) return;
    final todo = Todo(id: DateTime.now().toString(), title: title.trim());
    state = [...state, todo];
  }

  void toggle(String id) {
    state = [
      for (final t in state)
        if (t.id == id) t.copyWith(done: !t.done) else t,
    ];
  }

  void remove(String id) {
    state = state.where((t) => t.id != id).toList();
  }

  void clearCompleted() {
    state = state.where((t) => !t.done).toList();
  }
}

final todosProvider = StateNotifierProvider<TodoNotifier, List<Todo>>((ref) {
  return TodoNotifier();
});

// Computed providers (derived state)
final completedCountProvider = Provider<int>((ref) {
  final todos = ref.watch(todosProvider);
  return todos.where((t) => t.done).length;
});

final pendingTodosProvider = Provider<List<Todo>>((ref) {
  final todos = ref.watch(todosProvider);
  return todos.where((t) => !t.done).toList();
});

class TodoScreen extends ConsumerStatefulWidget {
  const TodoScreen({super.key});

  @override
  ConsumerState<TodoScreen> createState() => _TodoScreenState();
}

class _TodoScreenState extends ConsumerState<TodoScreen> {
  final _controller = TextEditingController();

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final todos = ref.watch(todosProvider);
    final completedCount = ref.watch(completedCountProvider);

    return Scaffold(
      appBar: AppBar(
        title: Text('Todos ($completedCount/${todos.length})'),
        actions: [
          if (completedCount > 0)
            IconButton(
              icon: const Icon(Icons.cleaning_services),
              onPressed: () => ref.read(todosProvider.notifier).clearCompleted(),
            ),
        ],
      ),
      body: Column(
        children: [
          Padding(
            padding: const EdgeInsets.all(12),
            child: Row(
              children: [
                Expanded(
                  child: TextField(
                    controller: _controller,
                    decoration: const InputDecoration(hintText: 'Naya todo', border: OutlineInputBorder()),
                    onSubmitted: (v) {
                      ref.read(todosProvider.notifier).add(v);
                      _controller.clear();
                    },
                  ),
                ),
                const SizedBox(width: 8),
                IconButton(
                  icon: const Icon(Icons.add_circle, size: 36, color: Colors.indigo),
                  onPressed: () {
                    ref.read(todosProvider.notifier).add(_controller.text);
                    _controller.clear();
                  },
                ),
              ],
            ),
          ),
          Expanded(
            child: todos.isEmpty
                ? const Center(child: Text('Koi todo nahi'))
                : ListView.builder(
                    itemCount: todos.length,
                    itemBuilder: (_, i) {
                      final t = todos[i];
                      return Dismissible(
                        key: Key(t.id),
                        background: Container(color: Colors.red, alignment: Alignment.centerRight, padding: const EdgeInsets.only(right: 16), child: const Icon(Icons.delete, color: Colors.white)),
                        onDismissed: (_) => ref.read(todosProvider.notifier).remove(t.id),
                        child: CheckboxListTile(
                          value: t.done,
                          onChanged: (_) => ref.read(todosProvider.notifier).toggle(t.id),
                          title: Text(t.title, style: TextStyle(decoration: t.done ? TextDecoration.lineThrough : null, color: t.done ? Colors.grey : null)),
                        ),
                      );
                    },
                  ),
          ),
        ],
      ),
    );
  }
}
```

> **Highlights:**
> - **Immutable state updates** — `[...state, item]` instead of `state.add()`
> - **Computed providers** — `completedCount` derived from todos, auto-updates
> - **Swipe-to-delete** with `Dismissible`

## 📋 Quick Revision

| Pattern | Code |
|---------|------|
| Setup | `ProviderScope(child: MyApp())` + `flutter_riverpod` |
| Read-only | `Provider<T>((ref) => value)` |
| Mutable | `StateProvider<T>((ref) => initial)` |
| Async | `FutureProvider<T>((ref) async => fetch())` |
| Stream | `StreamProvider<T>((ref) => stream)` |
| Complex state | `StateNotifierProvider<NotifierClass, T>` |
| Read in widget | `ref.watch(provider)` |
| One-shot read | `ref.read(provider)` |
| Side effect | `ref.listen(provider, callback)` |
| Refresh | `ref.invalidate(provider)` |
| AsyncValue | `.when(data:, loading:, error:)` |
| Family | `FutureProvider.family<R, P>((ref, p) async => ...)` |
| Auto cleanup | `StateProvider.autoDispose<T>(...)` |
| ConsumerWidget | `class X extends ConsumerWidget` |
| ConsumerStatefulWidget | with `ConsumerState<X>` |

## ❌ Common Mistakes

```dart
// MISTAKE 1: ProviderScope bhulna
runApp(MyApp())  // ❌ providers nahi mil rahe
// FIX: runApp(ProviderScope(child: MyApp()))

// MISTAKE 2: Direct state mutation
state.add(item);  // ❌ Riverpod me state immutable
// FIX: state = [...state, item];

// MISTAKE 3: ref.watch in callbacks
onPressed: () => ref.watch(counterProvider)  // ❌ rebuild causes
// FIX: ref.read(counterProvider)

// MISTAKE 4: AsyncValue without when()
final data = ref.watch(asyncProvider);  // AsyncValue<T>
return Text(data);  // ❌
// FIX: ref.watch(asyncProvider).when(data: ..., loading: ..., error: ...)

// MISTAKE 5: family without providing param
ref.watch(userByIdProvider)  // ❌
// FIX: ref.watch(userByIdProvider(42))
```

## 🎯 Interview Tips

1. **Q: Riverpod kyu Provider se better?**
   *A: Compile-time safe (no runtime exceptions), no BuildContext required, easier testing, AsyncValue built-in.*

2. **Q: ref.watch vs ref.read?**
   *A: watch listens (rebuild on change). read sirf current (no listen). Build me watch, callbacks me read.*

3. **Q: StateProvider vs StateNotifierProvider?**
   *A: StateProvider — simple values (int, bool). StateNotifierProvider — complex state with methods.*

4. **Q: ref.listen kab use karte ho?**
   *A: Side effects — provider change pe navigate, snackbar, dialog. UI rebuild nahi karta.*
