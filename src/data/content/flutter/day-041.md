# 🌅 HOUR 1 — CONCEPT

## Threads Aur Isolates

JavaScript ki tarah **Dart single-threaded** hai. Heavy work UI thread pe karne se app **freeze** ho jata hai (jank).

> **Solution:** **Isolates** — separate memory + execution context. Heavy work isolate pe, UI smooth.

> **Socho Aise:** Restaurant me ek waiter (UI thread). Sab orders waiter se aaye to khada rahega cooking pe. Ek alag chef (isolate) cooking kare — waiter free for orders.

---

## Isolate vs Thread

| | Java/JS Thread | Dart Isolate |
|---|---|---|
| Memory | Shared | Separate |
| Communication | Locks, mutex | Messages (SendPort) |
| Setup overhead | Low | Higher |
| Race conditions | Possible | None |

> **Trade-off:** Setup heavy hai, but **safe + simple** (no shared state, no race conditions).

---

## When to Use Isolates

✅ Big JSON parse (10MB+)
✅ Image processing (compression, filtering)
✅ Encryption / hashing (heavy crypto)
✅ Large file operations
✅ Complex math (ML inference)

❌ **Don't use for:** Simple async (HTTP, DB) — Future/await kafi hai. Isolate overhead waste.

## compute() — Easy Way

```dart
import 'package:flutter/foundation.dart';

// Top-level function (mandatory)
int heavyCalculation(int input) {
  int sum = 0;
  for (int i = 0; i < 100000000; i++) {
    sum += i;
  }
  return sum;
}

// Use anywhere
final result = await compute(heavyCalculation, 10);
print(result);
```

> **`compute()`:** Internally spawns isolate, runs function, returns result, kills isolate. **Simple + clean** for one-shot work.

## Isolate.spawn() — Manual

```dart
import 'dart:isolate';

void heavyTask(SendPort sendPort) {
  // Heavy work
  int sum = 0;
  for (int i = 0; i < 100000000; i++) sum += i;

  sendPort.send(sum);
}

Future<int> runInIsolate() async {
  final receivePort = ReceivePort();
  await Isolate.spawn(heavyTask, receivePort.sendPort);

  final result = await receivePort.first;
  receivePort.close();
  return result as int;
}
```

> **More flexibility** — keep isolate alive for multiple messages, bidirectional communication.

## Bidirectional Communication

```dart
void worker(SendPort mainSendPort) async {
  final receivePort = ReceivePort();
  mainSendPort.send(receivePort.sendPort);   // share my port

  await for (final message in receivePort) {
    if (message == 'shutdown') {
      receivePort.close();
      break;
    }
    // Process message
    final result = message as int;
    mainSendPort.send(result * 2);
  }
}

Future<void> useIsolate() async {
  final mainReceivePort = ReceivePort();
  await Isolate.spawn(worker, mainReceivePort.sendPort);

  final iter = mainReceivePort.cast<dynamic>().iterator;

  // Get worker's port
  await iter.moveNext();
  final workerPort = iter.current as SendPort;

  // Send messages
  workerPort.send(5);
  await iter.moveNext();
  print(iter.current);    // 10

  workerPort.send(20);
  await iter.moveNext();
  print(iter.current);    // 40

  // Shutdown
  workerPort.send('shutdown');
  mainReceivePort.close();
}
```

---

## Limitations

- Isolate **separate memory** — UI state directly modify nahi kar sakta
- Send only **primitives, lists, maps, json-like** — custom classes need fromJson
- **Cost** of spawn — ~10-50ms overhead

```dart
import 'package:flutter/foundation.dart';
import 'package:flutter/material.dart';

int sumUpTo(int n) {
  int sum = 0;
  for (int i = 1; i <= n; i++) sum += i;
  return sum;
}

class HeavyComputeScreen extends StatefulWidget {
  const HeavyComputeScreen({super.key});
  @override
  State<HeavyComputeScreen> createState() => _HeavyComputeScreenState();
}

class _HeavyComputeScreenState extends State<HeavyComputeScreen> {
  String _result = 'No result yet';
  bool _running = false;

  Future<void> _runOnUiThread() async {
    setState(() {
      _running = true;
      _result = 'Computing on UI thread (UI freeze!)';
    });

    final sw = Stopwatch()..start();
    final result = sumUpTo(500000000);    // very heavy
    sw.stop();

    setState(() {
      _result = 'UI thread: $result\nTime: ${sw.elapsedMilliseconds}ms (UI was frozen)';
      _running = false;
    });
  }

  Future<void> _runInCompute() async {
    setState(() {
      _running = true;
      _result = 'Computing in isolate...';
    });

    final sw = Stopwatch()..start();
    final result = await compute(sumUpTo, 500000000);
    sw.stop();

    setState(() {
      _result = 'Isolate: $result\nTime: ${sw.elapsedMilliseconds}ms (UI was responsive)';
      _running = false;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Heavy Compute Demo')),
      body: Padding(
        padding: const EdgeInsets.all(20),
        child: Column(
          children: [
            // Animation to test UI responsiveness
            _SpinningIcon(running: _running),

            const SizedBox(height: 20),
            Text(_result, textAlign: TextAlign.center),
            const SizedBox(height: 24),
            ElevatedButton(
              onPressed: _running ? null : _runOnUiThread,
              child: const Text('Run on UI Thread (FREEZE)'),
            ),
            const SizedBox(height: 8),
            ElevatedButton(
              onPressed: _running ? null : _runInCompute,
              style: ElevatedButton.styleFrom(backgroundColor: Colors.green, foregroundColor: Colors.white),
              child: const Text('Run with compute() (SMOOTH)'),
            ),
          ],
        ),
      ),
    );
  }
}

  const _SpinningIcon({required this.running});

  @override
  State<_SpinningIcon> createState() => _SpinningIconState();
}

      child: const Icon(Icons.refresh, size: 80, color: Colors.indigo),
    );
  }
}
```

## Task 2: Parse Big JSON in Isolate (15 min)

```dart
import 'dart:convert';
import 'package:flutter/foundation.dart';

// Simulate big JSON
String generateBigJson() {
  final list = List.generate(50000, (i) => {
    'id': i,
    'name': 'Item $i',
    'value': i * 3.14,
    'tags': List.generate(10, (j) => 'tag-$j'),
  });
  return jsonEncode(list);
}

// Top-level — runs in isolate
List<dynamic> parseJson(String jsonStr) {
  return jsonDecode(jsonStr) as List;
}

// Use
Future<void> handleBigData() async {
  final json = generateBigJson();

  print('Direct parse...');
  final sw1 = Stopwatch()..start();
  final result1 = jsonDecode(json) as List;
  sw1.stop();
  print('Direct: ${sw1.elapsedMilliseconds}ms (${result1.length} items)');

  print('Compute parse...');
  final sw2 = Stopwatch()..start();
  final result2 = await compute(parseJson, json);
  sw2.stop();
  print('Isolate: ${sw2.elapsedMilliseconds}ms (${result2.length} items)');
  // Slightly slower (overhead) but UI smooth
}
```

## Task 3: Isolate.spawn for Long-Running Worker (20 min)

```dart
import 'dart:isolate';

class CalculatorIsolate {
  Isolate? _isolate;
  SendPort? _sendPort;
  final _ready = Completer<void>();

  Future<void> start() async {
    final receivePort = ReceivePort();
    _isolate = await Isolate.spawn(_workerLoop, receivePort.sendPort);

    receivePort.listen((message) {
      if (message is SendPort) {
        _sendPort = message;
        _ready.complete();
      }
    });

    await _ready.future;
  }

  static void _workerLoop(SendPort mainPort) async {
    final myPort = ReceivePort();
    mainPort.send(myPort.sendPort);

    await for (final message in myPort) {
      if (message == 'shutdown') {
        myPort.close();
        break;
      }
      // message is Map: {'op': '+', 'a': 5, 'b': 3}
      final op = message['op'];
      final a = message['a'];
      final b = message['b'];
      final result = switch (op) {
        '+' => a + b,
        '-' => a - b,
        '*' => a * b,
        '/' => a / b,
        _ => 0,
      };
      mainPort.send(result);
    }
  }

  Future<num> calculate(String op, num a, num b) async {
    final completer = Completer<num>();
    final tempPort = ReceivePort();

    tempPort.listen((result) {
      if (!completer.isCompleted) completer.complete(result as num);
      tempPort.close();
    });

    _sendPort!.send({'op': op, 'a': a, 'b': b});
    return completer.future;
  }

  void dispose() {
    _sendPort?.send('shutdown');
    _isolate?.kill();
  }
}
```

## 📋 Quick Revision

| API | Use |
|-----|-----|
| `compute(fn, input)` | One-shot heavy work |
| `Isolate.spawn(fn, port)` | Long-running isolate |
| `ReceivePort()` | Receive messages |
| `SendPort` | Send messages |
| Pass | primitives, list, map (no widgets/refs) |
| Top-level fn | mandatory (`@pragma` for release) |

## ❌ Common Mistakes

```dart
// MISTAKE 1: compute me class method
compute(myObject.method, input)  // ❌
// FIX: top-level function

// MISTAKE 2: passing UI references
compute(fn, context)  // ❌ context isolate me invalid
// FIX: serialize data → primitives only

// MISTAKE 3: isolate not shutdown
// memory leak
// FIX: isolate.kill() on done

// MISTAKE 4: small work me isolate
final x = await compute((y) => y + 1, 5);
// overhead > benefit. Just await/Future
```

## 🎯 Interview Tips

1. **Q: Dart isolates kya hain aur Java threads se kaise alag?**
   *A: Separate memory, no shared state, message passing only. Threads share memory + need locks.*

2. **Q: compute() kab use karte ho?**
   *A: One-shot heavy work — JSON parse big files, image processing.*

3. **Q: Isolate spawn ka overhead?**
   *A: ~10-50ms initial. So 1ms work me waste. 100ms+ work me beneficial.*
