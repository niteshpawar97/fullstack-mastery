# 🌅 HOUR 1 — CONCEPT

## Dart Kya Hai?

### Flutter Ki Backbone Language

Dart ek **modern programming language** hai jo Google ne 2011 me banayi. 2017 ke baad jab **Flutter** launch hua, Dart ki popularity rocket ki tarah upar gayi.

> **Socho Aise:** Socho ek kumhar hai jo bartan banata hai mitti se. Mitti ke bina kuch nahi ban sakta. Bilkul waise hi Flutter ek "kumhar" hai jo apps banata hai — aur uski "mitti" hai **Dart**. Dart sikhe bina Flutter master nahi ho sakte.

### Dart Ki Khaas Baatein

| Feature | Matlab Kya |
|---------|-----------|
| **Strongly Typed** | Har variable ka type fix hota hai (int, String) |
| **Null Safe** | Bina permission ke null nahi ho sakta — runtime crashes kam |
| **AOT + JIT** | Dev me fast (JIT), production me super fast (AOT) |
| **Async Support** | Future/async-await JavaScript jaisa |
| **Object-Oriented** | Sab kuch object hai — even numbers, strings |

> **Yaad Rakho:** Dart aur JavaScript syntax me thoda similar dikhte hain, par Dart **strongly typed** hai. Ye runtime crashes se bachata hai.

## Variables Aur Types

### Variable = Data Ka Dabba

```dart
void main() {
  String naam = 'Ashutosh';      // Text dabba
  int umar = 25;                 // Whole number
  double height = 5.8;           // Decimal
  bool isStudent = true;         // True/False

  print(naam);     // Ashutosh
  print(umar);     // 25
  print(height);   // 5.8
  print(isStudent);// true
}
```

### Built-in Types

| Type | Example | Use Kab |
|------|---------|---------|
| `int` | `42` | Whole numbers (umar, count) |
| `double` | `3.14` | Decimal (price, height) |
| `String` | `'hello'` | Text |
| `bool` | `true` | True/False |
| `List` | `[1, 2, 3]` | Multiple values |
| `Map` | `{'name': 'Ash'}` | Key-value |

> **Yaad Rakho:** Hamesha **specific type** use karo (`int`, `String`). `dynamic` se bacho.

### `var`, `final`, `const` — Teeno Ka Difference

```dart
void main() {
  // 1. var — type auto-detect, value badal sakti hai
  var naam = 'Ashutosh';
  naam = 'Rohit';          // ✅ Allowed

  // 2. final — value sirf ek baar set, runtime constant
  final int umar = 25;
  // umar = 26;            // ❌ ERROR

  // 3. const — compile-time constant
  const double pi = 3.14159;
  // const aaj = DateTime.now();  // ❌ DateTime.now() runtime hai
}
```

> **Socho Aise:**
> - `var` = normal dabba — kuch bhi rakho, badlo
> - `final` = **lock waala dabba** — ek baar samaan rakha to lock
> - `const` = **factory-sealed dabba** — banta hi sealed hua hai

> **Tip:** Default `final` use karo. Sirf jab badalna ho tab `var`. `const` for `pi`, `appName`.

## String Interpolation — `$` Magic

```dart
void main() {
  String naam = 'Ashutosh';
  int umar = 25;

  // Simple interpolation
  print('Mera naam $naam hai');

  // Expression — curly braces
  print('Next year ${umar + 1} ka');     // 26
  print('Total: ₹${99.99 * 2}');         // 199.98

  // Multi-line
  String bio = '''
  Naam: $naam
  Umar: $umar
  ''';
  print(bio);
}
```

> **Yaad Rakho:** Single variable → `$variable`. Expression → `${expression}`.

## Task 3: Common Mistakes Fix (15 min)

In errors ko spot karo aur fix karo:

```dart
// MISTAKE 1
String age = 25;
// FIX: int age = 25;

// MISTAKE 2
final name = 'Ash';
name = 'Rohit';
// FIX: var name = 'Ash'; name = 'Rohit';

// MISTAKE 3
print('Hi name, age age');
// FIX: print('Hi $name, age $age');

// MISTAKE 4
print('Total ${a+b');
// FIX: print('Total ${a+b}');
```

## Task 4: Mini Program — User Profile (30 min)

`profile.dart` likho. Goal: ek user profile generator.

```dart
void main() {
  // Apni info
  final String fullName = 'Ashutosh Kumar';
  final int birthYear = 1999;
  final String city = 'Lucknow';
  final List<String> hobbies = ['Coding', 'Reading', 'Cricket'];

  // Calculate
  final int currentYear = 2026;
  final int age = currentYear - birthYear;

  // Display
  print('═══════════════════════');
  print('  USER PROFILE');
  print('═══════════════════════');
  print('Naam: $fullName');
  print('Umar: $age saal');
  print('Sheher: $city');
  print('Hobbies: ${hobbies.join(", ")}');
  print('═══════════════════════');
}
```

**Output:**
```
═══════════════════════
  USER PROFILE
═══════════════════════
Naam: Ashutosh Kumar
Umar: 27 saal
Sheher: Lucknow
Hobbies: Coding, Reading, Cricket
═══════════════════════
```

## 🎯 Interview Tips

1. **Q: Dart kyu, JavaScript kyu nahi?**
   *A: Strongly typed, null-safe, AOT compilation se fast, Flutter ke liye optimized.*

2. **Q: `final` aur `const` me kya farq?**
   *A: `final` runtime pe set, `const` compile time pe — value compile time pe pata honi chahiye.*

3. **Q: `var` aur `dynamic` me kya farq?**
   *A: `var` ka type ek baar set hone ke baad fix. `dynamic` kabhi bhi badal sakta hai.*
