# 🌅 HOUR 1 — CONCEPT

## Firebase Storage

Firebase Storage = files store karne ke liye (images, videos, PDFs). Firestore me text store karte hain, **Storage me binary files**.

### Setup

```bash
flutter pub add firebase_storage image_picker permission_handler geolocator
```

Firebase Console → **Storage** → Get Started → Test mode → Region.

### Upload File

```dart
import 'dart:io';
import 'package:firebase_storage/firebase_storage.dart';

Future<String> uploadImage(File file, String path) async {
  final ref = FirebaseStorage.instance.ref().child(path);
  final task = await ref.putFile(file);
  return await task.ref.getDownloadURL();   // public URL
}

// Use
final file = File('/path/to/image.jpg');
final url = await uploadImage(file, 'profiles/user123.jpg');
print(url);  // https://firebasestorage.googleapis.com/...
```

### Upload Progress

```dart
final task = ref.putFile(file);

task.snapshotEvents.listen((TaskSnapshot snapshot) {
  final progress = snapshot.bytesTransferred / snapshot.totalBytes;
  print('Progress: ${(progress * 100).toStringAsFixed(1)}%');
});

await task;
```

### Delete File

```dart
await FirebaseStorage.instance.ref('profiles/user123.jpg').delete();
```

### Storage Rules (Production)

```
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /profiles/{userId} {
      allow read: if true;
      allow write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

## Image Picker — Camera + Gallery

```dart
import 'package:image_picker/image_picker.dart';

Future<File?> pickFromGallery() async {
```

### Request Permission

```dart
import 'package:permission_handler/permission_handler.dart';

Future<bool> requestCameraPermission() async {
  final status = await Permission.camera.request();
  return status.isGranted;
}

Future<bool> requestLocationPermission() async {
  final status = await Permission.location.request();

```

### Check + Open Settings

```dart
final status = await Permission.camera.status;

if (status.isDenied) {

    // user denied — show explanation
  }

  // user ne "Don't ask again" select kiya
```

## Geolocator — GPS Location

```dart
import 'package:geolocator/geolocator.dart';

Future<Position?> getCurrentLocation() async {
  // Service enabled?
  bool serviceEnabled = await Geolocator.isLocationServiceEnabled();
  if (!serviceEnabled) {
    print('GPS off hai');
    return null;
  }

  // Permission
  LocationPermission permission = await Geolocator.checkPermission();
  if (permission == LocationPermission.denied) {
    permission = await Geolocator.requestPermission();
    if (permission == LocationPermission.denied) return null;
  }
  if (permission == LocationPermission.deniedForever) {
    print('Permanently denied — settings me jao');
    return null;
  }

  // Get position
  return await Geolocator.getCurrentPosition(
    desiredAccuracy: LocationAccuracy.high,
  );
}

// Use
final pos = await getCurrentLocation();
if (pos != null) {
  print('Lat: ${pos.latitude}, Long: ${pos.longitude}');
}
```

```dart
import 'package:flutter_image_compress/flutter_image_compress.dart';

Future<File> compressImage(File file) async {
  final result = await FlutterImageCompress.compressAndGetFile(
    file.absolute.path,
    file.absolute.path.replaceAll('.jpg', '_compressed.jpg'),
    quality: 70,
    minWidth: 1024,
    minHeight: 1024,
  );
  return File(result!.path);
}
```

## Task 1: Profile Picture Upload (45 min)

```dart
import 'dart:io';
import 'package:flutter/material.dart';
import 'package:firebase_auth/firebase_auth.dart';
import 'package:firebase_storage/firebase_storage.dart';
import 'package:cloud_firestore/cloud_firestore.dart';
import 'package:image_picker/image_picker.dart';
import 'package:flutter_image_compress/flutter_image_compress.dart';

class ProfileScreen extends StatefulWidget {
  const ProfileScreen({super.key});

  @override
  State<ProfileScreen> createState() => _ProfileScreenState();
}

class _ProfileScreenState extends State<ProfileScreen> {
  String? _photoUrl;
  bool _uploading = false;
  double _progress = 0;

  @override
  void initState() {
    super.initState();
    _loadProfile();
  }

  Future<void> _loadProfile() async {
    final uid = FirebaseAuth.instance.currentUser!.uid;
    final doc = await FirebaseFirestore.instance.collection('users').doc(uid).get();
    if (doc.exists) {
      setState(() => _photoUrl = doc.data()?['photoUrl']);
    }
  }

  Future<void> _pickAndUpload(ImageSource source) async {
    try {
      final picked = await ImagePicker().pickImage(
        source: source,
        maxWidth: 1024,
        imageQuality: 80,
      );
      if (picked == null) return;

      File file = File(picked.path);

      // Compress
      final compressed = await FlutterImageCompress.compressAndGetFile(
        file.path,
        '${file.path}_compressed.jpg',
        quality: 70,
      );
      if (compressed != null) file = File(compressed.path);

      setState(() {
        _uploading = true;
        _progress = 0;
      });

      // Upload to Storage
      final uid = FirebaseAuth.instance.currentUser!.uid;
      final ref = FirebaseStorage.instance.ref('profiles/$uid.jpg');
      final task = ref.putFile(file);

      task.snapshotEvents.listen((snap) {
        setState(() {
          _progress = snap.bytesTransferred / snap.totalBytes;
        });
      });

      await task;
      final url = await ref.getDownloadURL();

      // Save to Firestore
      await FirebaseFirestore.instance.collection('users').doc(uid).set({
        'photoUrl': url,
        'updatedAt': FieldValue.serverTimestamp(),
      }, SetOptions(merge: true));

      // Update Firebase Auth profile
      await FirebaseAuth.instance.currentUser!.updatePhotoURL(url);

      setState(() {
        _photoUrl = url;
        _uploading = false;
      });

      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(content: Text('Upload success! 🎉')),
      );
    } catch (e) {
      setState(() => _uploading = false);
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Error: $e')),
      );
    }
  }

  void _showImageSourceDialog() {
    showModalBottomSheet(
      context: context,
      builder: (_) => Column(
        mainAxisSize: MainAxisSize.min,
        children: [
          ListTile(
            leading: const Icon(Icons.camera),
            title: const Text('Camera'),
            onTap: () {
              Navigator.pop(context);
              _pickAndUpload(ImageSource.camera);
            },
          ),
          ListTile(
            leading: const Icon(Icons.photo_library),
            title: const Text('Gallery'),
            onTap: () {
              Navigator.pop(context);
              _pickAndUpload(ImageSource.gallery);
            },
          ),
        ],
      ),
    );
  }

  @override
  Widget build(BuildContext context) {
    final user = FirebaseAuth.instance.currentUser;
    return Scaffold(
      appBar: AppBar(title: const Text('Profile')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Stack(
              children: [
                CircleAvatar(
                  radius: 80,
                  backgroundImage: _photoUrl != null ? NetworkImage(_photoUrl!) : null,
                  child: _photoUrl == null ? const Icon(Icons.person, size: 80) : null,
                ),
                if (_uploading)
                  Positioned.fill(
                    child: CircleAvatar(
                      radius: 80,
                      backgroundColor: Colors.black54,
                      child: Column(
                        mainAxisAlignment: MainAxisAlignment.center,
                        children: [
                          CircularProgressIndicator(value: _progress, color: Colors.white),
                          const SizedBox(height: 8),
                          Text('${(_progress * 100).toStringAsFixed(0)}%', style: const TextStyle(color: Colors.white)),
                        ],
                      ),
                    ),
                  ),
                Positioned(
                  bottom: 0,
                  right: 0,
                  child: FloatingActionButton.small(
                    onPressed: _uploading ? null : _showImageSourceDialog,
                    child: const Icon(Icons.camera_alt),
                  ),
                ),
              ],
            ),
            const SizedBox(height: 16),
            Text(user?.email ?? '', style: const TextStyle(fontSize: 16)),
          ],
        ),
      ),
    );
  }
}
```

## Task 2: GPS Location with Address (15 min)

```dart
import 'package:geolocator/geolocator.dart';
import 'package:geocoding/geocoding.dart';

class LocationScreen extends StatefulWidget {
  const LocationScreen({super.key});
  @override
  State<LocationScreen> createState() => _LocationScreenState();
}

class _LocationScreenState extends State<LocationScreen> {
  Position? _position;
  String? _address;
  bool _loading = false;
  String? _error;

  Future<void> _getLocation() async {
    setState(() {
      _loading = true;
      _error = null;
    });

    try {
      bool serviceEnabled = await Geolocator.isLocationServiceEnabled();
      if (!serviceEnabled) throw Exception('GPS service off — on karo');

      LocationPermission permission = await Geolocator.checkPermission();
      if (permission == LocationPermission.denied) {
        permission = await Geolocator.requestPermission();
        if (permission == LocationPermission.denied) throw Exception('Permission denied');
      }
      if (permission == LocationPermission.deniedForever) {
        throw Exception('Permanently denied — settings me jao');
      }

      final pos = await Geolocator.getCurrentPosition(desiredAccuracy: LocationAccuracy.high);

      // Reverse geocode
      final placemarks = await placemarkFromCoordinates(pos.latitude, pos.longitude);
      final p = placemarks.first;

      setState(() {
        _position = pos;
        _address = '${p.locality}, ${p.administrativeArea}, ${p.country}';
        _loading = false;
      });
    } catch (e) {
      setState(() {
        _error = e.toString().replaceAll('Exception: ', '');
        _loading = false;
      });
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('My Location')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          children: [
            ElevatedButton.icon(
              onPressed: _loading ? null : _getLocation,
              icon: const Icon(Icons.location_searching),
              label: const Text('Get My Location'),
            ),
            const SizedBox(height: 24),
            if (_loading) const CircularProgressIndicator(),
            if (_error != null) Text(_error!, style: const TextStyle(color: Colors.red)),
            if (_position != null) ...[
              const Icon(Icons.location_on, size: 60, color: Colors.indigo),
              const SizedBox(height: 8),
              Text(_address ?? 'Unknown', style: const TextStyle(fontSize: 18, fontWeight: FontWeight.bold)),
              Text('Lat: ${_position!.latitude.toStringAsFixed(4)}', style: const TextStyle(color: Colors.grey)),
              Text('Long: ${_position!.longitude.toStringAsFixed(4)}', style: const TextStyle(color: Colors.grey)),
            ],
          ],
        ),
      ),
    );
  }
}
```

## Task 3: Permission Denied Graceful UI (10 min)

```dart
Future<void> _checkAndRequest(Permission permission, BuildContext context) async {
  final status = await permission.status;

  if (status.isPermanentlyDenied) {
    showDialog(
      context: context,
      builder: (_) => AlertDialog(
        title: const Text('Permission needed'),
        content: const Text('Permanently denied. Settings me jaake enable karo.'),
        actions: [
          TextButton(onPressed: () => Navigator.pop(context), child: const Text('Cancel')),
          ElevatedButton(
            onPressed: () {
              openAppSettings();
              Navigator.pop(context);
            },
            child: const Text('Open Settings'),
          ),
        ],
      ),
    );
    return;
  }

  if (status.isDenied) {
    final result = await permission.request();
    if (!result.isGranted) {
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(content: Text('Permission denied')),
      );
    }
  }
}
```

## 🎯 Interview Tips

1. **Q: Firebase Storage ke security rules kaise likhte ho?**
   *A: `storage.rules` me path-based, `request.auth` aur `resource` use karke. User-specific paths protect karte hain.*

2. **Q: Image compression kyu zaroori?**
   *A: User experience (fast upload) + cost (less storage + bandwidth) + battery + memory.*

3. **Q: Camera permission ke 3 states?**
   *A: granted, denied (ask again possible), permanentlyDenied (settings only).*

4. **Q: Geolocator high vs low accuracy?**
   *A: high — GPS, accurate but slow + battery. low — cell tower, fast but imprecise.*
