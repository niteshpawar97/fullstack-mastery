# 🌅 HOUR 1 — CONCEPT

## Test Pyramid

```
       /\
      /  \  Integration (slow, expensive)
     /----\
    /      \  Widget (medium)
   /--------\
  /  Unit    \  Many, fast, cheap
 /____________\
```

- **Unit tests:** Business logic, pure Dart functions
- **Widget tests:** Single widget UI behaviour
- **Integration tests:** Full user flows on device

> **Rule:** Write **many unit + widget**, **few integration**. Pyramid balance.

---

## Widget Test Recap

```dart
// test/widget_test.dart
import 'package:flutter_test/flutter_test.dart';
import 'package:flutter/material.dart';

void main() {
  testWidgets('counter increments', (tester) async {
    await tester.pumpWidget(const MaterialApp(home: CounterScreen()));

    expect(find.text('0'), findsOneWidget);

    await tester.tap(find.byIcon(Icons.add));
    await tester.pump();

    expect(find.text('1'), findsOneWidget);
  });
}
```

**Key APIs:**
- `tester.pumpWidget(...)` — render
- `tester.pump()` — single frame
- `tester.pumpAndSettle()` — wait for animations
- `find.text/byIcon/byKey/byType` — locate widgets
- `expect(finder, matcher)` — assert
- `tester.tap/enterText/drag` — interact

## Mocking with Mocktail

```bash
flutter pub add --dev mocktail
```

```dart
import 'package:mocktail/mocktail.dart';

class MockAuthRepository extends Mock implements AuthRepository {}

void main() {
  late MockAuthRepository mockRepo;

  setUp(() {
    mockRepo = MockAuthRepository();
  });

  test('LoginUseCase returns user on success', () async {
    when(() => mockRepo.login('admin@app.com', 'admin123'))
        .thenAnswer((_) async => const User(id: '1', name: 'Admin', email: 'admin@app.com'));

    final useCase = LoginUseCase(mockRepo);
    final result = await useCase('admin@app.com', 'admin123');

    expect(result, isNotNull);
    expect(result!.email, 'admin@app.com');

    verify(() => mockRepo.login('admin@app.com', 'admin123')).called(1);
  });
}
```

### Mocktail Methods

```dart
when(() => mock.method()).thenReturn(value);
when(() => mock.asyncMethod()).thenAnswer((_) async => value);
when(() => mock.method()).thenThrow(Exception('Failed'));

verify(() => mock.method()).called(1);
verifyNever(() => mock.method());
verifyInOrder([...]);
verifyNoMoreInteractions(mock);

// Argument matchers
when(() => mock.method(any())).thenReturn(value);
when(() => mock.method(captureAny())).thenReturn(value);
```

## Bloc Testing

```bash
flutter pub add --dev bloc_test
```

```dart
import 'package:bloc_test/bloc_test.dart';

void main() {
  late MockAuthRepository mockRepo;

  setUp(() {
    mockRepo = MockAuthRepository();
  });

  blocTest<AuthBloc, AuthState>(
    'emits [Loading, Success] on successful login',
    build: () {
      when(() => mockRepo.login(any(), any()))
          .thenAnswer((_) async => const User(id: '1', name: 'A', email: 'a@b.com'));
      return AuthBloc(repository: mockRepo);
    },
    act: (bloc) => bloc.add(const AuthLoginRequested('a@b.com', 'pass123')),
    expect: () => [
      AuthLoading(),
      isA<AuthSuccess>(),
    ],
  );

  blocTest<AuthBloc, AuthState>(
    'emits [Loading, Failure] on invalid credentials',
    build: () {
      when(() => mockRepo.login(any(), any())).thenAnswer((_) async => null);
      return AuthBloc(repository: mockRepo);
    },
    act: (bloc) => bloc.add(const AuthLoginRequested('wrong@app.com', 'wrong')),
    expect: () => [
      AuthLoading(),
      const AuthFailure('Invalid credentials'),
    ],
  );
}
```

## Integration Tests

```bash
flutter pub add --dev integration_test
```

`integration_test/app_test.dart`:

```dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:integration_test/integration_test.dart';
import 'package:my_app/main.dart' as app;

void main() {
  IntegrationTestWidgetsFlutterBinding.ensureInitialized();

  group('Login flow', () {
    testWidgets('user can log in with valid credentials', (tester) async {
      app.main();
      await tester.pumpAndSettle();

      // Find email field
      final emailField = find.byKey(const Key('email-field'));
      await tester.enterText(emailField, 'admin@app.com');
      await tester.pumpAndSettle();

      // Password
      await tester.enterText(find.byKey(const Key('password-field')), 'admin123');
      await tester.pumpAndSettle();

      // Tap login
      await tester.tap(find.byKey(const Key('login-button')));
      await tester.pumpAndSettle();

      // Verify home screen
      expect(find.text('Welcome'), findsOneWidget);
    });
  });
}
```

## Task 2: Bloc Test with Mocktail (25 min)

```dart
// test/blocs/auth_bloc_test.dart
import 'package:bloc_test/bloc_test.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:mocktail/mocktail.dart';
import 'package:my_app/features/auth/domain/entities/user.dart';
import 'package:my_app/features/auth/domain/repositories/auth_repository.dart';
import 'package:my_app/features/auth/domain/usecases/login_usecase.dart';
import 'package:my_app/features/auth/presentation/bloc/auth_bloc.dart';

class MockAuthRepository extends Mock implements AuthRepository {}

void main() {
  late MockAuthRepository mockRepo;
  late LoginUseCase loginUseCase;

  setUp(() {
    mockRepo = MockAuthRepository();
    loginUseCase = LoginUseCase(mockRepo);
  });

  group('AuthBloc', () {
    blocTest<AuthBloc, AuthState>(
      'emits [Loading, Success] on valid credentials',
      build: () {
        when(() => mockRepo.login('user@app.com', 'pass123'))
            .thenAnswer((_) async => const User(id: '1', name: 'User', email: 'user@app.com'));
        return AuthBloc(loginUseCase: loginUseCase);
      },
      act: (bloc) => bloc.add(const AuthLoginRequested('user@app.com', 'pass123')),
      expect: () => [
        AuthLoading(),
        isA<AuthSuccess>().having((s) => s.user.email, 'email', 'user@app.com'),
      ],
    );

    blocTest<AuthBloc, AuthState>(
      'emits [Loading, Failure] when login returns null',
      build: () {
        when(() => mockRepo.login(any(), any())).thenAnswer((_) async => null);
        return AuthBloc(loginUseCase: loginUseCase);
      },
      act: (bloc) => bloc.add(const AuthLoginRequested('wrong@app.com', 'wrong')),
      expect: () => [
        AuthLoading(),
        const AuthFailure('Invalid credentials'),
      ],
    );

    test('LoginUseCase throws on invalid email', () {
      expect(() => loginUseCase('not-email', 'pass123'), throwsException);
    });
  });
}
```

## Task 3: Integration Test for Login (15 min)

```dart
// integration_test/login_flow_test.dart
import 'package:flutter/material.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:integration_test/integration_test.dart';
import 'package:my_app/main.dart' as app;

void main() {
  IntegrationTestWidgetsFlutterBinding.ensureInitialized();

  testWidgets('login flow end-to-end', (tester) async {
    app.main();
    await tester.pumpAndSettle();

    // Find login screen
    expect(find.text('Login'), findsWidgets);

    // Enter credentials
    await tester.enterText(find.byKey(const Key('email')), 'admin@app.com');
    await tester.enterText(find.byKey(const Key('password')), 'admin123');
    await tester.pumpAndSettle();

    // Tap login
    await tester.tap(find.byKey(const Key('loginBtn')));
    await tester.pumpAndSettle(const Duration(seconds: 2));

    // Verify home
    expect(find.text('Welcome'), findsOneWidget);
  });
}
```

Run on real device:
```bash
flutter test integration_test/login_flow_test.dart -d <device-id>
```

## 📋 Quick Revision

| Test Type | Tool/Command |
|-----------|--------------|
| Unit | `test()`, plain Dart |
| Widget | `testWidgets`, `tester.pumpWidget` |
| Golden | `matchesGoldenFile`, `--update-goldens` |
| Mock | `mocktail` — `Mock`, `when().thenAnswer/Return/Throw` |
| Bloc | `bloc_test` — `blocTest(build, act, expect)` |
| Integration | `integration_test` — real device |
| Coverage | `flutter test --coverage` + `genhtml` |
| Find | `find.text/byIcon/byKey/byType` |

## ❌ Common Mistakes

```dart
// MISTAKE 1: tester.pump() after async
await mockRepo.login(...);
await tester.pump();   // single frame
// FIX: pumpAndSettle() for async ops + animations

// MISTAKE 2: Golden test on dynamic widget
matchesGoldenFile('animated.png')  // animation frame variable
// FIX: Pause animation or use static widget

// MISTAKE 3: Mock without when
mockRepo.login(...);  // returns null (default)
// FIX: when(() => mock.login()).thenReturn/Answer/Throw

// MISTAKE 4: Test running on emulator only
// integration_test pe emulator slow
// FIX: Real device or CI
```

## 🎯 Interview Tips

1. **Q: Test pyramid kya hai?**
   *A: Unit > Widget > Integration. Many cheap tests + few expensive ones.*

2. **Q: Golden tests ka use case?**
   *A: Visual regression — UI accidentally change ho gayi to catch karna.*

3. **Q: Mocktail Mockito se kyu better?**
   *A: Code generation nahi chahiye, simpler API, Dart 3 compatible.*

4. **Q: Coverage 100% achieve karna chahiye?**
   *A: No — diminishing returns. 70-80% realistic. Critical paths test priority.*
