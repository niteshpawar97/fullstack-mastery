# 🌅 HOUR 1 — CONCEPT

## State Management Kyu Chahiye?

Day 11 me `setState()` sikha — but limitation: **state sirf widget ke andar** access ho sakta hai.

> **Problem:** Cart screen pe item add karo → CartIcon (AppBar me) update kaise ho? Dono different widgets hain.
>
> **Solution:** Shared state — sab widgets ek hi data ko sun rahe ho.

## Prop Drilling — The Old Way

```dart
class App {
  int cartCount = 0;

  build() => HomeScreen(
    count: cartCount,
    onIncrement: () => setState(() => cartCount++),
  );
}

class HomeScreen extends StatelessWidget {
  final int count;
  final Function onIncrement;

  build() => ProductScreen(count: count, onIncrement: onIncrement);
}

class ProductScreen extends StatelessWidget {
  final int count;
  final Function onIncrement;

  build() => CartIcon(count: count);  // pass karte raho
}
```

> **Pain:** 5 levels deep widget ko data dena hai? 5 levels me prop pass karo. **Mess**.

> **Solution:** Provider — sab widgets ek central store se data lete hain, koi pass nahi karna.

## Concept 1: ChangeNotifier (Data Store)

ChangeNotifier ek class hai jo data hold karti hai aur listeners ko notify karti hai jab data change ho.

```dart
import 'package:flutter/foundation.dart';

class CartModel extends ChangeNotifier {
  final List<String> _items = [];
  int get count => _items.length;
  List<String> get items => List.unmodifiable(_items);

  void add(String item) {
    _items.add(item);
    notifyListeners();   // sab listeners ko bolo "rebuild"
  }

  void remove(String item) {
    _items.remove(item);
    notifyListeners();
  }

  void clear() {
    _items.clear();
    notifyListeners();
  }
}
```

> **Yaad Rakho:** Internal state private (`_items`) rakho. **Mutations sirf methods se hone do** — direct list edit karne se notifyListeners trigger nahi hoga.

## Concept 2: ChangeNotifierProvider (Inject)

App tree me ChangeNotifierProvider lagao — yahan se nichle widgets data access kar sakenge.

```dart
import 'package:provider/provider.dart';

void main() {
  runApp(
    ChangeNotifierProvider(
      create: (_) => CartModel(),
      child: const MyApp(),
    ),
  );
}
```

> **Tip:** Provider **as upar as possible** rakho — typically `runApp` ke around. Saare children access kar paayenge.

## Concept 3: Consume Data — 3 Tareeke

### Way 1: Consumer (Best for partial UI)

```dart
Consumer<CartModel>(
  builder: (context, cart, child) {
    return Text('Items: ${cart.count}');
  },
)
```

### Way 2: Provider.of (Full widget rebuild)

```dart
class HomeScreen extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    final cart = Provider.of<CartModel>(context);  // listen by default
    return Text('${cart.count}');
  }
}
```

### Way 3: context.watch / context.read

```dart
// Listen for changes (rebuild)
final cart = context.watch<CartModel>();
return Text('${cart.count}');

// Read once (no rebuild)
final cart = context.read<CartModel>();
cart.add('New item');  // call method
```

| Method | Rebuild on Change | Use Case |
|--------|-------------------|----------|
| `Consumer` | ✅ Just builder | Partial UI rebuild |
| `Provider.of(context)` | ✅ Full widget | Need value frequently |
| `context.watch` | ✅ Full widget | Read in build() |
| `context.read` | ❌ No rebuild | Calling methods (button onPressed) |

> **Best Practice:**
> - Build me `watch` use karo (auto rebuild)
> - Callbacks me `read` use karo (sirf method call, rebuild nahi chahiye)

## Pattern: Counter App with Provider

```dart
import 'package:flutter/material.dart';
import 'package:flutter/foundation.dart';
import 'package:provider/provider.dart';

class CounterModel extends ChangeNotifier {
  int _count = 0;
  int get count => _count;

  void increment() {
    _count++;
    notifyListeners();
  }

  void decrement() {
    if (_count > 0) {
      _count--;
      notifyListeners();
    }
  }

  void reset() {
    _count = 0;
    notifyListeners();
  }
}

void main() {
  runApp(
    ChangeNotifierProvider(
      create: (_) => CounterModel(),
      child: const MyApp(),
    ),
  );
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});
  @override
  Widget build(BuildContext context) =>
      const MaterialApp(home: CounterScreen(), debugShowCheckedModeBanner: false);
}

class CounterScreen extends StatelessWidget {
  const CounterScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Consumer<CounterModel>(
          builder: (_, counter, __) => Text('Count: ${counter.count}'),
        ),
      ),
      body: Center(
        child: Consumer<CounterModel>(
          builder: (_, counter, __) => Text(
            '${counter.count}',
            style: const TextStyle(fontSize: 100),
          ),
        ),
      ),
      floatingActionButton: Row(
        mainAxisAlignment: MainAxisAlignment.end,
        children: [
          FloatingActionButton(
            heroTag: 'minus',
            onPressed: () => context.read<CounterModel>().decrement(),
            child: const Icon(Icons.remove),
          ),
          const SizedBox(width: 8),
          FloatingActionButton(
            heroTag: 'plus',
            onPressed: () => context.read<CounterModel>().increment(),
            child: const Icon(Icons.add),
          ),
        ],
      ),
    );
  }
}
```

> **Notice:** AppBar me `Consumer` (count dikha rahe), FAB me `context.read` (method call only).

## Task 1: Shopping Cart with Provider (45 min)

### models/cart_model.dart

```dart
import 'package:flutter/foundation.dart';

class CartItem {
  final String id;
  final String name;
  final double price;
  int quantity;

  CartItem({required this.id, required this.name, required this.price, this.quantity = 1});

  double get total => price * quantity;
}

class CartModel extends ChangeNotifier {
  final List<CartItem> _items = [];

  List<CartItem> get items => List.unmodifiable(_items);
  int get count => _items.fold(0, (sum, i) => sum + i.quantity);
  double get total => _items.fold(0.0, (sum, i) => sum + i.total);

  void add(CartItem item) {
    final existing = _items.indexWhere((i) => i.id == item.id);
    if (existing >= 0) {
      _items[existing].quantity++;
    } else {
      _items.add(item);
    }
    notifyListeners();
  }

  void remove(String id) {
    _items.removeWhere((i) => i.id == id);
    notifyListeners();
  }

  void incrementQty(String id) {
    final item = _items.firstWhere((i) => i.id == id);
    item.quantity++;
    notifyListeners();
  }

  void decrementQty(String id) {
    final item = _items.firstWhere((i) => i.id == id);
    if (item.quantity > 1) {
      item.quantity--;
    } else {
      _items.remove(item);
    }
    notifyListeners();
  }

  void clear() {
    _items.clear();
    notifyListeners();
  }
}
```

## Task 2: Theme Provider (15 min)

```dart
class ThemeNotifier extends ChangeNotifier {
  bool _isDark = false;
  bool get isDark => _isDark;

  void toggle() {
    _isDark = !_isDark;
    notifyListeners();
  }
}

void main() {
  runApp(
    ChangeNotifierProvider(
      create: (_) => ThemeNotifier(),
      child: const MyApp(),
    ),
  );
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return Consumer<ThemeNotifier>(
      builder: (context, theme, _) => MaterialApp(
        debugShowCheckedModeBanner: false,
        themeMode: theme.isDark ? ThemeMode.dark : ThemeMode.light,
        theme: ThemeData.light(useMaterial3: true),
        darkTheme: ThemeData.dark(useMaterial3: true),
        home: const HomeScreen(),
      ),
    );
  }
}

class HomeScreen extends StatelessWidget {
  const HomeScreen({super.key});

  @override
  Widget build(BuildContext context) {
    final theme = context.watch<ThemeNotifier>();
    return Scaffold(
      appBar: AppBar(title: const Text('Theme Provider')),
      body: Center(
        child: Switch(
          value: theme.isDark,
          onChanged: (_) => context.read<ThemeNotifier>().toggle(),
        ),
      ),
    );
  }
}
```

## 📋 Quick Revision

| Concept | Code |
|---------|------|
| Add package | `flutter pub add provider` |
| Data store | `class CartModel extends ChangeNotifier` |
| Notify | `notifyListeners()` |
| Inject | `ChangeNotifierProvider(create: (_) => Model())` |
| Multi-store | `MultiProvider(providers: [...])` |
| Listen + rebuild | `Consumer<X>(builder: (c, model, _) => ...)` |
| Listen full | `context.watch<X>()` |
| Read once | `context.read<X>()` |
| Best for build | `watch` |
| Best for callbacks | `read` |

## ❌ Common Mistakes

```dart
// MISTAKE 1: notifyListeners bhulna
void add(item) {
  _items.add(item);
  // notifyListeners();  ❌ UI update nahi hogi
}

// MISTAKE 2: Provider provider scope ke bahar use
runApp(MyApp());  // Provider nahi hai
// MyApp ke andar context.read<X>()  // ❌ ProviderNotFoundException
// FIX: ChangeNotifierProvider top pe lagao

// MISTAKE 3: build() me context.read use karna
build() {
  final cart = context.read<CartModel>();  // ❌ rebuild nahi hoga
}
// FIX: context.watch ya Consumer

// MISTAKE 4: Direct list mutation
cart.items.add(x);  // notifyListeners trigger nahi
// FIX: cart.add(x) — method call karo
```

## 🎯 Interview Tips

1. **Q: setState vs Provider?**
   *A: setState local widget state. Provider app-wide shared state — multiple widgets ko same data access karna ho.*

2. **Q: Consumer vs Provider.of?**
   *A: Consumer sirf builder rebuild karta hai (efficient). Provider.of pura widget rebuild.*

3. **Q: context.watch vs context.read?**
   *A: watch listen karta hai (rebuild on change). read sirf current value (no listening).*

4. **Q: Provider ke alternatives?**
   *A: Riverpod (modern), Bloc (event-driven), GetX (opinionated). Provider beginner friendly + popular.*
