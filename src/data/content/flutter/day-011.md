# 🌅 HOUR 1 — CONCEPT

## State Kya Hota Hai?

State = **data jo time ke saath badal sakta hai** UI me.

> **Socho Aise:** TV remote ka volume button — har press pe volume value badalti hai (state). Volume hi state hai. UI me bhi same — counter, login form input, dark mode toggle — sab state.

### Stateless vs Stateful Recap

| Stateless | Stateful |
|-----------|----------|
| Static UI | Dynamic UI |
| Props se UI | Internal state se UI |
| `extends StatelessWidget` | `extends StatefulWidget` |
| `build()` ek baar | `build()` state change pe rerun |

## StatefulWidget Anatomy

```dart
class CounterPage extends StatefulWidget {
  const CounterPage({super.key});

  @override
  State<CounterPage> createState() => _CounterPageState();
}

class _CounterPageState extends State<CounterPage> {
  int _count = 0;  // STATE

  void _increment() {
    setState(() {
      _count++;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Counter')),
      body: Center(child: Text('$_count', style: const TextStyle(fontSize: 80))),
      floatingActionButton: FloatingActionButton(
        onPressed: _increment,
        child: const Icon(Icons.add),
      ),
    );
  }
}
```

> **Yaad Rakho:** StatefulWidget me **2 classes** hoti hain:
> 1. `Widget` class (immutable, props store karti hai)
> 2. `State` class (mutable, actual state + UI logic)

## `setState()` Ka Magic

`setState()` Flutter ko bolta hai — **"state change ho gaya, build() dobara chalao"**.

```dart
void _increment() {
  _count++;            // ❌ UI update nahi hoga
}

void _increment() {
  setState(() {
    _count++;          // ✅ UI update hoga
  });
}
```

> **Tip:** State variable change setState ke andar karo. Bahar karoge to UI nahi badlegi (Flutter ko pata nahi chalega).

### setState() Best Practices

```dart
// ✅ Acha
setState(() {
  _count++;
  _message = 'Updated';
});

// ❌ Galat — async work setState ke andar mat karo
setState(() async {
  await fetchData();   // bug source
});

// ✅ Sahi — pehle async, fir setState
Future<void> loadData() async {
  final data = await fetchData();
  setState(() {
    _data = data;
  });
}
```

## Lifecycle Methods

State class ke kuch special methods jo Flutter automatically call karta hai widget ki life me.

### 1. `initState()` — Widget Banne Pe

```dart
@override
void initState() {
  super.initState();
  print('Widget bana');
  // API call, controller init, listener add
  _loadData();
}
```

> **Use:** API calls, animation controllers, stream subscriptions.

### 2. `build()` — UI Render

```dart
@override
Widget build(BuildContext context) {
  print('Build called');
  return Scaffold(...);
}
```

> **Yaad Rakho:** `build()` **multiple baar** call hota hai — setState pe, parent rebuild pe, hot reload pe. Heavy work yahan **mat karo**.

### 3. `didChangeDependencies()` — Dependencies Update Pe

```dart
@override
void didChangeDependencies() {
  super.didChangeDependencies();
  // InheritedWidget (Theme, MediaQuery) change pe call hota hai
}
```

### 4. `setState()` — State Change

```dart
setState(() {
  _value = newValue;
});
// Trigger karta hai build()
```

### 5. `dispose()` — Widget Destroy Pe

```dart
@override
void dispose() {
  _controller.dispose();
  _subscription.cancel();
  print('Widget destroy');
  super.dispose();
}
```

> **Important:** Memory leaks se bachne ke liye `dispose()` me **resources cleanup** zaroor karo — controllers, streams, timers.

### Lifecycle Flow Diagram

```
createState()
    ↓
initState()        ← ek baar (widget creation)
    ↓
didChangeDependencies()  ← initState ke baad first time + theme change pe
    ↓
build()            ← multiple times (setState, parent rebuild)
    ↓
... (running)
    ↓
deactivate()
    ↓
dispose()          ← ek baar (widget destroy)
```

## Common Patterns

### Pattern 1: API on Init

```dart
class UserScreen extends StatefulWidget {
  const UserScreen({super.key});

  @override
  State<UserScreen> createState() => _UserScreenState();
}

class _UserScreenState extends State<UserScreen> {
  String? _userName;
  bool _loading = true;

  @override
  void initState() {
    super.initState();
    _fetchUser();
  }

  Future<void> _fetchUser() async {
    await Future.delayed(const Duration(seconds: 2));  // simulate API
    setState(() {
      _userName = 'Ashutosh';
      _loading = false;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: _loading
            ? const CircularProgressIndicator()
            : Text('Hi, $_userName!'),
      ),
    );
  }
}
```

### Pattern 2: Toggle Boolean

```dart
class _ThemeToggleState extends State<ThemeToggle> {
  bool _isDark = false;

  @override
  Widget build(BuildContext context) {
    return Switch(
      value: _isDark,
      onChanged: (value) {
        setState(() {
          _isDark = value;
        });
      },
    );
  }
}
```

### Pattern 3: List Update

```dart
List<String> _items = [];

void _addItem(String item) {
  setState(() {
    _items.add(item);
  });
}

void _removeItem(int index) {
  setState(() {
    _items.removeAt(index);
  });
}
```

## Task 1: Counter v2 with Reset (15 min)

```dart
import 'package:flutter/material.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});
  @override
  Widget build(BuildContext context) =>
      const MaterialApp(home: CounterScreen(), debugShowCheckedModeBanner: false);
}

class CounterScreen extends StatefulWidget {
  const CounterScreen({super.key});

  @override
  State<CounterScreen> createState() => _CounterScreenState();
}

class _CounterScreenState extends State<CounterScreen> {
  int _count = 0;
  String _status = 'Click karo!';

  void _increment() {
    setState(() {
      _count++;
      _updateStatus();
    });
  }

  void _decrement() {
    setState(() {
      if (_count > 0) _count--;
      _updateStatus();
    });
  }

  void _reset() {
    setState(() {
      _count = 0;
      _status = 'Reset! Phir se shuru.';
    });
  }

  void _updateStatus() {
    if (_count == 0) _status = 'Empty';
    else if (_count < 5) _status = 'Just started';
    else if (_count < 10) _status = 'Going strong 💪';
    else if (_count < 20) _status = 'Awesome 🔥';
    else _status = 'You are a beast! 🚀';
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Counter v2'), backgroundColor: Colors.indigo, foregroundColor: Colors.white),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text('$_count', style: const TextStyle(fontSize: 100, fontWeight: FontWeight.bold, color: Colors.indigo)),
            const SizedBox(height: 20),
            Text(_status, style: const TextStyle(fontSize: 18, color: Colors.grey)),
            const SizedBox(height: 40),
            Row(
              mainAxisAlignment: MainAxisAlignment.center,
              children: [
                FloatingActionButton(onPressed: _decrement, heroTag: 'minus', backgroundColor: Colors.red, child: const Icon(Icons.remove)),
                const SizedBox(width: 16),
                FloatingActionButton(onPressed: _reset, heroTag: 'reset', backgroundColor: Colors.grey, child: const Icon(Icons.refresh)),
                const SizedBox(width: 16),
                FloatingActionButton(onPressed: _increment, heroTag: 'plus', backgroundColor: Colors.green, child: const Icon(Icons.add)),
              ],
            ),
          ],
        ),
      ),
    );
  }
}
```

> **Test:** + - reset try karo. Status message badalna chahiye.

## Task 4: Timer-based UI Update (20 min)

```dart
import 'dart:async';
import 'package:flutter/material.dart';

class TimerScreen extends StatefulWidget {
  const TimerScreen({super.key});

  @override
  State<TimerScreen> createState() => _TimerScreenState();
}

class _TimerScreenState extends State<TimerScreen> {
  Timer? _timer;
  int _seconds = 0;
  bool _running = false;

  void _start() {
    setState(() {
      _running = true;
    });
    _timer = Timer.periodic(const Duration(seconds: 1), (t) {
      setState(() {
        _seconds++;
      });
    });
  }

  void _pause() {
    _timer?.cancel();
    setState(() {
      _running = false;
    });
  }

  void _reset() {
    _timer?.cancel();
    setState(() {
      _seconds = 0;
      _running = false;
    });
  }

  String _formatTime(int s) {
    int min = s ~/ 60;
    int sec = s % 60;
    return '${min.toString().padLeft(2, '0')}:${sec.toString().padLeft(2, '0')}';
  }

  @override
  void dispose() {
    _timer?.cancel();  // CRITICAL — memory leak rokne ke liye
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Stopwatch')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text(
              _formatTime(_seconds),
              style: const TextStyle(
                fontSize: 80,
                fontWeight: FontWeight.bold,
                fontFamily: 'monospace',
              ),
            ),
            const SizedBox(height: 40),
            Row(
              mainAxisAlignment: MainAxisAlignment.center,
              children: [
                ElevatedButton.icon(
                  onPressed: _running ? _pause : _start,
                  icon: Icon(_running ? Icons.pause : Icons.play_arrow),
                  label: Text(_running ? 'Pause' : 'Start'),
                ),
                const SizedBox(width: 12),
                OutlinedButton.icon(
                  onPressed: _reset,
                  icon: const Icon(Icons.refresh),
                  label: const Text('Reset'),
                ),
              ],
            ),
          ],
        ),
      ),
    );
  }
}
```

> **Critical:** `dispose()` me `_timer?.cancel()` zaroor karo — warna widget destroy hone ke baad bhi timer chalta rahega.

## Task 5: Add/Remove List Items (15 min)

```dart
class TaskListScreen extends StatefulWidget {
  const TaskListScreen({super.key});

  @override
  State<TaskListScreen> createState() => _TaskListScreenState();
}

class _TaskListScreenState extends State<TaskListScreen> {
  final List<String> _tasks = ['Flutter sikhna', 'Coffee peena'];
  final TextEditingController _controller = TextEditingController();

  void _addTask() {
    if (_controller.text.trim().isEmpty) return;
    setState(() {
      _tasks.add(_controller.text.trim());
      _controller.clear();
    });
  }

  void _removeTask(int index) {
    setState(() {
      _tasks.removeAt(index);
    });
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Tasks')),
      body: Column(
        children: [
          Padding(
            padding: const EdgeInsets.all(12),
            child: Row(
              children: [
                Expanded(
                  child: TextField(
                    controller: _controller,
                    decoration: const InputDecoration(
                      hintText: 'Naya task likho',
                      border: OutlineInputBorder(),
                    ),
                    onSubmitted: (_) => _addTask(),
                  ),
                ),
                const SizedBox(width: 8),
                ElevatedButton(onPressed: _addTask, child: const Text('Add')),
              ],
            ),
          ),
          Expanded(
            child: ListView.builder(
              itemCount: _tasks.length,
              itemBuilder: (context, index) => ListTile(
                leading: const Icon(Icons.check_box_outline_blank),
                title: Text(_tasks[index]),
                trailing: IconButton(
                  icon: const Icon(Icons.delete, color: Colors.red),
                  onPressed: () => _removeTask(index),
                ),
              ),
            ),
          ),
        ],
      ),
    );
  }
}
```

## 📋 Quick Revision

| Concept | Code |
|---------|------|
| StatefulWidget | `class X extends StatefulWidget` |
| State class | `class _XState extends State<X>` |
| State variable | `int _count = 0;` |
| Update UI | `setState(() { _count++; });` |
| On creation | `void initState() { super.initState(); ... }` |
| On destroy | `void dispose() { ... super.dispose(); }` |
| Cleanup | timers, controllers, streams in dispose |

## ❌ Common Mistakes

```dart
// MISTAKE 1: setState bhulna
void _add() {
  _count++;  // ❌ UI update nahi
}
// FIX: setState(() { _count++; });

// MISTAKE 2: dispose bhulna
Timer.periodic(...);  // memory leak
// FIX: _timer?.cancel() in dispose()

// MISTAKE 3: setState async ke andar
setState(() async {
  await fetch();  // ❌ buggy
});
// FIX: pehle await, fir setState

// MISTAKE 4: super call bhulna
@override
void initState() {
  // missing super.initState()
}
// FIX: super.initState() pehle line

// MISTAKE 5: Stateless me state
class X extends StatelessWidget {
  int count = 0;  // ❌ stateless me state nahi
}
```

## 🎯 Interview Tips

1. **Q: setState() exactly kya karta hai?**
   *A: State change mark karta hai aur build() ko schedule karta hai (next frame me UI update).*

2. **Q: initState me API call kar sakte hain?**
   *A: Haan — pattern hai `_loadData()` ko initState se call karna. Async function setState me data set karega.*

3. **Q: dispose() kab call hota hai?**
   *A: Jab widget tree se permanently remove ho jata hai (Navigator.pop, parent ne hata diya).*

4. **Q: 2 classes kyu — Widget aur State?**
   *A: Widget immutable hai (props store), State mutable hai (state + lifecycle). Flutter optimization ke liye separation chahiye.*
