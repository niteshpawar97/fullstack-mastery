# 🌅 HOUR 1 — CONCEPT

## SharedPreferences Kya Hai?

Local **key-value storage** — App restart ke baad bhi data persist rahta hai.

> **Socho Aise:** Phone me ek **note** save karte ho — "user_logged_in: yes". Phone band karke kholo, note vahi pe hai. SharedPreferences exactly waise — small data, key-value, persistent.

### Use Cases

✅ User preferences (dark mode, language, font size)
✅ Auth tokens (login persistence)
✅ Onboarding flag (pehli baar khol raha hai?)
✅ Last viewed item / recent searches
✅ Simple counters

❌ **Don't use for**: Large data, complex queries, relations → SQLite/Hive use karo

### Platform Storage

| Platform | Where |
|----------|-------|
| Android | SharedPreferences XML file |
| iOS | NSUserDefaults plist |
| Web | LocalStorage |
| Desktop | File on disk |

> **Yaad Rakho:** **Encrypted nahi hota** — sensitive data (passwords, credit card) yahan **mat rakho**. `flutter_secure_storage` use karo wo cases me.

## Basic Operations

### Get Instance (Async)

```dart
final prefs = await SharedPreferences.getInstance();
```

> **Tip:** Instance `getInstance()` se aata hai — async hai pehli baar (fir cache me rehta hai).

### Save Data (set)

```dart
await prefs.setString('username', 'Ashutosh');
await prefs.setInt('age', 25);
await prefs.setBool('isDark', true);
await prefs.setDouble('rating', 4.5);
await prefs.setStringList('hobbies', ['Coding', 'Reading']);
```

### Read Data (get)

```dart
final name = prefs.getString('username');           // String? (null if not set)
final age = prefs.getInt('age') ?? 0;               // int? with default
final isDark = prefs.getBool('isDark') ?? false;
final rating = prefs.getDouble('rating') ?? 0.0;
final hobbies = prefs.getStringList('hobbies') ?? [];
```

### Check Existence

```dart
if (prefs.containsKey('token')) {
  // logged in
}
```

### Remove

```dart
await prefs.remove('token');     // ek key
await prefs.clear();             // sab clear (logout)
```

## Pattern 1: First-time User Detection

```dart
Future<bool> isFirstTime() async {
  final prefs = await SharedPreferences.getInstance();
  final isFirst = prefs.getBool('isFirstTime') ?? true;
  if (isFirst) {
    await prefs.setBool('isFirstTime', false);
  }
  return isFirst;
}

// Use
void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  final firstTime = await isFirstTime();
  runApp(MyApp(showOnboarding: firstTime));
}
```

## Pattern 3: Theme Persistence

```dart
class ThemeService {
  static const _key = 'isDarkMode';

  static Future<bool> getTheme() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getBool(_key) ?? false;
  }

  static Future<void> saveTheme(bool isDark) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setBool(_key, isDark);
  }
}

// In Provider/State
class ThemeNotifier extends ChangeNotifier {
  bool _isDark = false;
  bool get isDark => _isDark;

  Future<void> load() async {
    _isDark = await ThemeService.getTheme();
    notifyListeners();
  }

  Future<void> toggle() async {
    _isDark = !_isDark;
    await ThemeService.saveTheme(_isDark);
    notifyListeners();
  }
}
```

## Storing Complex Objects (JSON)

SharedPreferences sirf primitives store karta hai. Complex objects ke liye **JSON encode/decode** karo:

```dart
class UserPrefs {
  static const _key = 'user_data';

  static Future<void> saveUser(User user) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString(_key, jsonEncode(user.toJson()));
  }

  static Future<User?> loadUser() async {
    final prefs = await SharedPreferences.getInstance();
    final json = prefs.getString(_key);
    if (json == null) return null;
    return User.fromJson(jsonDecode(json));
  }
}
```

## When NOT to Use SharedPreferences

| Use Case | Better Tool |
|----------|-------------|
| Many records (1000+ items) | SQLite (`sqflite`) |
| Relational data (tables, joins) | SQLite |
| Sensitive data (password, card) | `flutter_secure_storage` |
| File data (images, PDFs) | `path_provider` + file system |
| Complex queries (search, filter) | SQLite or Hive |

## Task 1: Login + Auto-Login System (40 min)

```dart
import 'package:flutter/material.dart';
import 'package:shared_preferences/shared_preferences.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  final prefs = await SharedPreferences.getInstance();
  final isLoggedIn = prefs.containsKey('auth_token');
  runApp(MyApp(initialLoggedIn: isLoggedIn));
}

class MyApp extends StatelessWidget {
  final bool initialLoggedIn;
  const MyApp({super.key, required this.initialLoggedIn});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(useMaterial3: true, colorScheme: ColorScheme.fromSeed(seedColor: Colors.indigo)),
      home: initialLoggedIn ? const HomeScreen() : const LoginScreen(),
    );
  }
}

// LOGIN
class LoginScreen extends StatefulWidget {
  const LoginScreen({super.key});

  @override
  State<LoginScreen> createState() => _LoginScreenState();
}

class _LoginScreenState extends State<LoginScreen> {
  final _emailController = TextEditingController();
  bool _loading = false;

  Future<void> _login() async {
    if (_emailController.text.isEmpty) return;
    setState(() => _loading = true);

    // Simulate API
    await Future.delayed(const Duration(seconds: 1));

    final prefs = await SharedPreferences.getInstance();
    await prefs.setString('auth_token', 'fake-token-${DateTime.now().millisecondsSinceEpoch}');
    await prefs.setString('user_email', _emailController.text);
    await prefs.setString('user_name', _emailController.text.split('@').first);
    await prefs.setInt('login_at', DateTime.now().millisecondsSinceEpoch);

    if (!mounted) return;
    Navigator.pushReplacement(context, MaterialPageRoute(builder: (_) => const HomeScreen()));
  }

  @override
  void dispose() {
    _emailController.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Padding(
        padding: const EdgeInsets.all(24),
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            const Icon(Icons.lock, size: 80, color: Colors.indigo),
            const SizedBox(height: 20),
            const Text('Login', style: TextStyle(fontSize: 32, fontWeight: FontWeight.bold)),
            const SizedBox(height: 30),
            TextField(
              controller: _emailController,
              decoration: const InputDecoration(labelText: 'Email', border: OutlineInputBorder()),
              keyboardType: TextInputType.emailAddress,

            const SizedBox(height: 20),
            SizedBox(
              width: double.infinity,
              child: ElevatedButton(
                onPressed: _loading ? null : _login,

                  padding: const EdgeInsets.symmetric(vertical: 14),
                  backgroundColor: Colors.indigo,

                child: _loading

            const SizedBox(height: 12),
            const Text('Email type karke login karo. Token saved hoga, app dobara kholne pe direct home jayega.', textAlign: TextAlign.center, style: TextStyle(fontSize: 12, color: Colors.grey)),
          ],

// HOME
class HomeScreen extends StatefulWidget {
  const HomeScreen({super.key});

  @override
  State<HomeScreen> createState() => _HomeScreenState();
}

class _HomeScreenState extends State<HomeScreen> {
  String _userName = '';
  String _userEmail = '';
  DateTime? _loginAt;

  @override
  void initState() {
    super.initState();
    _loadUser();
  }

  Future<void> _loadUser() async {
    final prefs = await SharedPreferences.getInstance();
    setState(() {
      _userName = prefs.getString('user_name') ?? 'Guest';
      _userEmail = prefs.getString('user_email') ?? '';
      final loginMs = prefs.getInt('login_at');
      if (loginMs != null) _loginAt = DateTime.fromMillisecondsSinceEpoch(loginMs);
    });
  }

  Future<void> _logout() async {
    final confirm = await showDialog<bool>(
      context: context,
      builder: (_) => AlertDialog(
        title: const Text('Logout?'),
        content: const Text('Saved data clear ho jayega.'),
        actions: [
          TextButton(onPressed: () => Navigator.pop(context, false), child: const Text('Cancel')),
          TextButton(onPressed: () => Navigator.pop(context, true), child: const Text('Logout', style: TextStyle(color: Colors.red))),
        ],
      ),
    );

    if (confirm == true) {
      final prefs = await SharedPreferences.getInstance();
      await prefs.clear();
      if (!mounted) return;
      Navigator.pushReplacement(context, MaterialPageRoute(builder: (_) => const LoginScreen()));
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Home'),
        backgroundColor: Colors.indigo,
        foregroundColor: Colors.white,
        actions: [IconButton(icon: const Icon(Icons.logout), onPressed: _logout)],
      ),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            CircleAvatar(radius: 50, backgroundColor: Colors.indigo, child: Text(_userName.isNotEmpty ? _userName[0].toUpperCase() : '?', style: const TextStyle(fontSize: 40, color: Colors.white))),
            const SizedBox(height: 20),
            Text('Welcome, $_userName 👋', style: const TextStyle(fontSize: 24, fontWeight: FontWeight.bold)),
            const SizedBox(height: 8),
            Text(_userEmail, style: const TextStyle(color: Colors.grey)),
            if (_loginAt != null) ...[
              const SizedBox(height: 12),
              Text('Login: ${_loginAt!.toLocal()}', style: const TextStyle(fontSize: 12, color: Colors.grey)),
            ],
          ],
        ),
      ),
    );
  }
}
```

## Task 2: Theme Persistence (15 min)

```dart
class _ThemeAppState extends State<ThemeApp> {
  bool _isDark = false;
  bool _loaded = false;

  @override
  void initState() {
    super.initState();
    _loadTheme();
  }

  Future<void> _loadTheme() async {
    final prefs = await SharedPreferences.getInstance();
    setState(() {
      _isDark = prefs.getBool('isDark') ?? false;
      _loaded = true;
    });
  }

  Future<void> _toggle() async {
    final prefs = await SharedPreferences.getInstance();
    setState(() => _isDark = !_isDark);
    await prefs.setBool('isDark', _isDark);
  }

  @override
  Widget build(BuildContext context) {
    if (!_loaded) {
      return const MaterialApp(home: Scaffold(body: Center(child: CircularProgressIndicator())));
    }
    return MaterialApp(
      themeMode: _isDark ? ThemeMode.dark : ThemeMode.light,
      theme: ThemeData.light(useMaterial3: true),
      darkTheme: ThemeData.dark(useMaterial3: true),
      home: Scaffold(
        appBar: AppBar(
          title: const Text('Theme Persist'),
          actions: [IconButton(icon: Icon(_isDark ? Icons.light_mode : Icons.dark_mode), onPressed: _toggle)],
        ),
        body: const Center(child: Text('Toggle karke app restart karo — preference saved.')),
      ),
    );
  }
}
```

## Task 3: Recent Searches (15 min)

```dart
class SearchService {
  static const _key = 'recent_searches';
  static const _maxItems = 5;

  static Future<List<String>> getRecent() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getStringList(_key) ?? [];
  }

  static Future<void> add(String term) async {
    final prefs = await SharedPreferences.getInstance();
    final list = prefs.getStringList(_key) ?? [];

    list.remove(term);             // duplicate hatao
    list.insert(0, term);          // top pe daalo
    if (list.length > _maxItems) list.removeLast();  // limit

    await prefs.setStringList(_key, list);
  }

  static Future<void> clear() async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.remove(_key);
  }
}

// UI
class SearchScreen extends StatefulWidget {
  const SearchScreen({super.key});

  @override
  State<SearchScreen> createState() => _SearchScreenState();
}

class _SearchScreenState extends State<SearchScreen> {
  final _controller = TextEditingController();
  List<String> _recent = [];

  @override
  void initState() {
    super.initState();
    _load();
  }

  Future<void> _load() async {
    _recent = await SearchService.getRecent();
    setState(() {});
  }

  Future<void> _search(String term) async {
    if (term.trim().isEmpty) return;
    await SearchService.add(term.trim());
    _controller.clear();
    await _load();
    ScaffoldMessenger.of(context).showSnackBar(SnackBar(content: Text('Searched: $term')));
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Search'),
        actions: [
          IconButton(
            icon: const Icon(Icons.clear_all),
            onPressed: () async { await SearchService.clear(); await _load(); },
          ),
        ],
      ),
      body: Column(
        children: [
          Padding(
            padding: const EdgeInsets.all(12),
            child: TextField(
              controller: _controller,
              onSubmitted: _search,
              decoration: InputDecoration(
                hintText: 'Type aur Enter dabao',
                border: const OutlineInputBorder(),
                suffixIcon: IconButton(icon: const Icon(Icons.search), onPressed: () => _search(_controller.text)),
              ),
            ),
          ),
          const Padding(padding: EdgeInsets.all(12), child: Align(alignment: Alignment.centerLeft, child: Text('Recent searches', style: TextStyle(fontWeight: FontWeight.bold)))),
          Expanded(
            child: _recent.isEmpty
                ? const Center(child: Text('Koi recent search nahi'))
                : ListView.builder(
                    itemCount: _recent.length,
                    itemBuilder: (_, i) => ListTile(
                      leading: const Icon(Icons.history),
                      title: Text(_recent[i]),
                      onTap: () => _controller.text = _recent[i],
                    ),
                  ),
          ),
        ],
      ),
    );
  }
}
```

| Action | Code |
|--------|------|
| Get instance | `final prefs = await SharedPreferences.getInstance();` |
| Save string | `prefs.setString(key, value)` |
| Get string | `prefs.getString(key) ?? 'default'` |
| Save bool | `prefs.setBool(key, true)` |

| Clear all | `prefs.clear()` |

## ❌ Common Mistakes

```dart
// MISTAKE 1: WidgetsFlutterBinding.ensureInitialized() bhulna in main

  final prefs = await SharedPreferences.getInstance();  // ❌ error
  runApp(MyApp());

// FIX: WidgetsFlutterBinding.ensureInitialized() pehle line

// MISTAKE 2: await bhulna

// FIX: await prefs.setString(...)

// MISTAKE 3: Sensitive data
prefs.setString('password', 'abc');  // ❌ plain text
// FIX: flutter_secure_storage use karo

// MISTAKE 4: Object directly save
prefs.setString('user', user);  // ❌ User object string nahi
// FIX: jsonEncode(user.toJson())

// MISTAKE 5: Default value bhulna
final age = prefs.getInt('age');  // null aaya to crash
// FIX: prefs.getInt('age') ?? 0
```

## 🎯 Interview Tips

1. **Q: SharedPreferences kab use karte ho?**
   *A: Small key-value persistent data — preferences, tokens, flags. Bade data ke liye SQLite/Hive.*

2. **Q: Async kyu hai?**
   *A: First call file I/O karta hai. Subsequent calls cached in-memory hote hain.*

3. **Q: Flutter web pe kahan store hota hai?**
   *A: Browser LocalStorage — but limited size (~5MB) aur cleared ho sakta hai.*

4. **Q: Sensitive data SharedPreferences me kyu nahi?**
   *A: Plain text store hota hai — rooted/jailbroken device pe access ho sakta hai.*
