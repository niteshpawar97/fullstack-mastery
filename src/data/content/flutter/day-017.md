# 🌅 HOUR 1 — CONCEPT

## Type-Safe Models — Kyu?

Day 16 me hum `Map<String, dynamic>` directly use karte the:

```dart
final posts = jsonDecode(response.body);
print(posts[0]['title']);  // typo possible: 'titel' → null at runtime
```

**Problem:** Strings hain, runtime errors. **Solution:** Type-safe class banao.

> **Socho Aise:** Map = ek **khula box** jisme kuch bhi rakh sakte ho. Class = ek **labelled folder** with fixed compartments. Compiler help karta hai galti pakadne me.

## Manual fromJson Pattern

```dart
class Post {
  final int id;
  final int userId;
  final String title;
  final String body;

  Post({
    required this.id,
    required this.userId,
    required this.title,
    required this.body,
  });

  // JSON → Dart object
  factory Post.fromJson(Map<String, dynamic> json) {
    return Post(
      id: json['id'] as int,
      userId: json['userId'] as int,
      title: json['title'] as String,
      body: json['body'] as String,
    );
  }

  // Dart object → JSON
  Map<String, dynamic> toJson() {
    return {
      'id': id,
      'userId': userId,
      'title': title,
      'body': body,
    };
  }
}
```

> **Yaad Rakho:** `factory` constructor zaroori hai — return type fixed nahi, har baar naya object create karta hai.

## Use Karna

```dart
// Single post
final json = jsonDecode(response.body);
```

## Nullable Fields Handling

API kabhi field skip kar sakti hai. Defensive parsing:

```dart
class User {
  final int id;
  final String name;
  final String? email;       // nullable
  final String? phone;
  final String? avatarUrl;

  User({
    required this.id,
    required this.name,
    this.email,
    this.phone,
    this.avatarUrl,
  });

  factory User.fromJson(Map<String, dynamic> json) {
    return User(
      id: json['id'] as int,
      name: json['name'] as String,
      email: json['email'] as String?,        // null OK
      phone: json['phone'] as String?,
      avatarUrl: json['avatar_url'] as String?,
    );
  }
}
```

> **Tip:** API field naam `snake_case` ho sakta hai. Dart me `camelCase` convert karna padta hai (`avatar_url` → `avatarUrl`).

## List Inside JSON

```json
{
  "id": 1,
  "name": "Ashutosh",
  "skills": ["Flutter", "Dart", "Firebase"],
  "posts": [
    {"id": 1, "title": "Hello"},
    {"id": 2, "title": "World"}
  ]
}
```

```dart
class User {
  final int id;
  final String name;
  final List<String> skills;
  final List<Post> posts;

  factory User.fromJson(Map<String, dynamic> json) => User(
    id: json['id'],
    name: json['name'],

    // List of strings
    skills: (json['skills'] as List).map((s) => s as String).toList(),

    // List of objects
    posts: (json['posts'] as List)
        .map((p) => Post.fromJson(p as Map<String, dynamic>))
        .toList(),
  );
}
```

## copyWith Pattern (Immutability)

```dart
class Post {
  final int id;
  final String title;
  final String body;
  final bool isLiked;

  const Post({required this.id, required this.title, required this.body, this.isLiked = false});

  Post copyWith({int? id, String? title, String? body, bool? isLiked}) {
    return Post(
      id: id ?? this.id,
      title: title ?? this.title,
      body: body ?? this.body,
      isLiked: isLiked ?? this.isLiked,
    );
  }
}

// Use
final updatedPost = post.copyWith(isLiked: true);
```

> **Why immutable + copyWith?** State management (Provider, Bloc, Riverpod) cleanly equality compare kar sakta hai — performance + bug-free.

```dart
part 'post.g.dart';

@JsonSerializable()
class Post {
  final int id;
  final String title;

  Post({required this.id, required this.title});

  factory Post.fromJson(Map<String, dynamic> json) => _$PostFromJson(json);
  Map<String, dynamic> toJson() => _$PostToJson(this);
}
```

## Task 2: Type-Safe Posts Screen (30 min)

```dart
import 'dart:convert';
import 'package:flutter/material.dart';
import 'package:http/http.dart' as http;
import 'models/post.dart';

class PostsScreen extends StatefulWidget {
  const PostsScreen({super.key});

  @override
  State<PostsScreen> createState() => _PostsScreenState();
}

class _PostsScreenState extends State<PostsScreen> {
  late Future<List<Post>> _postsFuture;

  @override
  void initState() {
    super.initState();
    _postsFuture = _fetchPosts();
  }

  Future<List<Post>> _fetchPosts() async {
    final response = await http
        .get(Uri.parse('https://jsonplaceholder.typicode.com/posts'))
        .timeout(const Duration(seconds: 10));

    if (response.statusCode != 200) {
      throw Exception('Failed: ${response.statusCode}');
    }

    final List jsonList = jsonDecode(response.body);
    return jsonList
        .map((j) => Post.fromJson(j as Map<String, dynamic>))
        .toList();
  }

  Future<void> _refresh() async {
    setState(() => _postsFuture = _fetchPosts());
    await _postsFuture;
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Posts (Type-Safe)'), backgroundColor: Colors.indigo, foregroundColor: Colors.white),
      body: RefreshIndicator(
        onRefresh: _refresh,
        child: FutureBuilder<List<Post>>(
          future: _postsFuture,
          builder: (context, snapshot) {
            if (snapshot.connectionState == ConnectionState.waiting) {
              return const Center(child: CircularProgressIndicator());
            }
            if (snapshot.hasError) {
              return Center(
                child: Column(
                  mainAxisAlignment: MainAxisAlignment.center,
                  children: [
                    const Icon(Icons.error, size: 60, color: Colors.red),
                    const SizedBox(height: 8),
                    Text('${snapshot.error}'),
                    const SizedBox(height: 16),
                    ElevatedButton(onPressed: _refresh, child: const Text('Retry')),
                  ],
                ),
              );
            }
            final posts = snapshot.data ?? [];
            return ListView.builder(
              itemCount: posts.length,
              itemBuilder: (_, i) {
                final p = posts[i];
                return Card(
                  margin: const EdgeInsets.symmetric(horizontal: 12, vertical: 4),
                  child: ListTile(
                    leading: CircleAvatar(child: Text('${p.id}')),
                    title: Text(p.title, style: const TextStyle(fontWeight: FontWeight.bold)),
                    subtitle: Text(p.body, maxLines: 2, overflow: TextOverflow.ellipsis),
                  ),
                );
              },
            );
          },
        ),
      ),
    );
  }
}
```

> **Notice the difference:** Ab `p.title` autocomplete kaam karta hai. Typos compile-time pakad ata hai.

## 📋 Quick Revision

| Pattern | Code |
|---------|------|
| Class | `class Post { final int id; ... }` |
| Constructor | `Post({required this.id});` |
| fromJson factory | `factory Post.fromJson(Map json) => Post(id: json['id']);` |
| toJson | `Map<String, dynamic> toJson() => {'id': id};` |
| Parse single | `Post.fromJson(json)` |
| Parse list | `(jsonList as List).map((j) => Post.fromJson(j)).toList()` |
| Nullable | `final String? email;` + `json['email'] as String?` |
| Default | `json['x'] as int? ?? 0` |
| Nested | `Address.fromJson(json['address'])` |
| copyWith | `post.copyWith(title: 'New')` |

## ❌ Common Mistakes

```dart
// MISTAKE 1: Type cast bhulna
id: json['id']  // dynamic, not type-safe
// FIX: id: json['id'] as int

// MISTAKE 2: Null safety
title: json['title']  // null aaya to crash
// FIX: title: json['title'] as String? ?? 'Default'

// MISTAKE 3: Field name mismatch
json['name']  // API "user_name" return karta hai
// FIX: name: json['user_name']

// MISTAKE 4: Nested parse bhulna
address: json['address']  // ❌ Map hi store ho gaya
// FIX: address: Address.fromJson(json['address'])

// MISTAKE 5: List parse galat
posts: json['posts'] as List<Post>  // ❌ direct cast fail
// FIX: (json['posts'] as List).map((p) => Post.fromJson(p)).toList()
```

## 🎯 Interview Tips

1. **Q: Type-safe models kyu zaroori?**
   *A: Compile-time errors > runtime crashes. IDE autocomplete + refactoring safe.*

2. **Q: factory constructor kya hai?**
   *A: Special constructor jo new object return kare. Caching, validation, fromJson — common use cases.*

3. **Q: copyWith pattern ka kya use?**
   *A: Immutable objects update karne ke liye — ek new object banake jisme kuch fields override.*

4. **Q: json_serializable manual se kab better?**
   *A: Bade projects me 50+ models. Initial learning me manual sikho — JSON structure understand hota hai.*
